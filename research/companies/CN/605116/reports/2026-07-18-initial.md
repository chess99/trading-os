# 奥锐特（CN:605116）初始深度研究

报告日期：2026-07-18
结论：观察
当前价格参考：19.43 元/股，市值约 77.7 亿元，PE TTM 约 19.7 倍（2026-07-17/2026-07-18 抓取，来源：搜狐证券行情页；实时行情存在刷新误差，以交易所成交为准）

## 一句话结论

奥锐特是从复杂特色原料药向“原料药+制剂+TIDES/小核酸 CDMO”升级的中小型药企，2025 年 TIDES 与女性健康放量使利润创高，但 2026Q1 利润下滑 46.47% 显示价格、产品结构、折旧和汇率会放大利润波动。按 2026 年归母净利润 4.3-5.0 亿元的中性区间、18-22 倍 PE，以及简化 DCF 交叉验证，合理价值约 21-26 元/股；19.43 元未贵，但离 15%-25% 安全边际不够，先列观察，18 元以下或 Q2/Q3 利润修复确认后再考虑买入。

## 业务画像

公司主营复杂原料药、中间体、制剂，并延伸至寡核苷酸药物 CRO/CDMO。官网研发中心披露的能力包括：上海研发中心负责寡核苷酸原料药工艺开发、分析验证和 AI 驱动小核酸药物发现；天津、杭州、天台、扬州分别覆盖小分子、合成生物学/流体化学、固体制剂、多肽及发酵等平台（来源：奥锐特官网研发中心页，2026-07-18 抓取）。

2025 年公司实现营业收入 16.97 亿元，同比 +15.03%；归母净利润 4.49 亿元，同比 +26.61%；扣非归母净利润 4.37 亿元，同比 +24.43%（来源：奥锐特 2025 年年度报告，2026-04-17 披露）。分品类看，心血管 4.85 亿元/+12.17%，TIDES 2.62 亿元/+766.59%，抗肿瘤 2.01 亿元/-4.89%，呼吸系统 1.83 亿元/-3.80%，女性健康 1.78 亿元/+40.97%，成品药 1.84 亿元/-16.19%（同源）。这说明增长已经不只是传统小分子 API，而是明显来自高附加值新品类。

2026Q1 公司收入 3.89 亿元，同比 -3.17%；归母净利润 0.64 亿元，同比 -46.47%；扣非归母净利润 0.59 亿元，同比 -48.16%；经营现金流 0.88 亿元，同比 +243.25%（来源：奥锐特 2026 年第一季度报告，2026-04-24 披露）。利润下滑原因，公司在季报中归因于原料药价格承压、产品结构变化、新项目转固后产能爬坡导致折旧和运营成本上升，以及人民币兑美元升值导致外销竞争力和汇兑损益受压。

## 行业与赛道

特色原料药行业的本质是“合规产能+工艺优化+客户认证+成本曲线”的复合竞争。普通 API 价格易受印度、中国同业扩产和下游客户议价影响；复杂 API、多肽、小核酸和高壁垒制剂则对工艺路线、杂质控制、GMP 合规、稳定供应和注册文件支持要求更高，盈利质量更好。

奥锐特的增量主要落在三条线：第一，TIDES 类产品，2025 年收入已到 2.62 亿元且同比高增；第二，女性健康/地屈孕酮片等制剂，2026 年 7 月公司公告地屈孕酮片新增进入《国家基本药物目录（2026年版）》，目录自 2026-09-01 施行（来源：公司公告转载页 CFI，2026-07-15；原交易所公告未在本次抓取中直接核验，置信度中）；第三，小核酸 CDMO，官网披露已有寡核苷酸工艺开发、分析验证、AI 小核酸发现等研发布局，但商业化收入规模和客户结构未拆分，现阶段不能按成熟 CDMO 平台给高估值。

## 护城河

已形成的护城河主要有四层。第一是多年复杂 API 工艺积累，覆盖心血管、抗肿瘤、呼吸、女性健康、TIDES 等多个治疗领域，降低单品依赖。第二是客户认证和质量体系，原料药企业切入国际客户供应链后，替换成本高于普通化工品。第三是从 API 到制剂的一体化，地屈孕酮片等制剂若放量，可以把部分原料药能力转化为品牌/渠道利润。第四是 TIDES 与寡核苷酸能力的期权价值，若小核酸商业化生产爬坡成功，估值体系有机会从传统 API 切到更高壁垒的 CDMO。

短板也清楚：公司规模仍小，2025 年收入不到 17 亿元；TIDES 高增长基数低，客户集中度、订单持续性、产品价格未充分披露；制剂端商业化能力仍在验证。护城河不是“稳态垄断”，更像“工艺和合规能力驱动的升级期优势”。

## 增长驱动

1. TIDES 放量：2025 年 TIDES 收入 2.62 亿元，同比 +766.59%，是最明确的新品类突破（来源：2025 年报）。需要跟踪其是否从单批/单客户订单变成可持续平台收入。

2. 女性健康和地屈孕酮片：2025 年女性健康收入 1.78 亿元，同比 +40.97%；地屈孕酮片进入 2026 版基药目录后，有利于医疗机构覆盖和基层渗透，但价格和集采风险也会上升。

3. 产能项目爬坡：2026Q1 公司明确提到项目陆续转固投产，短期拖累利润；若产能利用率提升，折旧摊薄后利润率可能修复。反过来，如果订单不足，固定成本会继续压制 ROE。

4. 小核酸 CDMO：官网显示公司在寡核苷酸工艺开发和分析验证上已有布局。该部分目前属于期权，收入、客户和产能利用率缺少可核验公开拆分，估值中只给有限溢价。

## 财务质量

2025 年净利率约 26.5%（4.49/16.97），在 API/制剂公司中较好；2026Q1 净利率降至约 16.4%（0.64/3.89），说明高毛利产品结构和汇率对利润弹性很大。2026Q1 经营现金流 0.88 亿元明显好于上年同期，但投资现金流 -1.75 亿元，仍处扩产投入期（来源：东方财富财务摘要抓取、2026Q1 报告；东方财富二次加工数据仅作交叉参考）。

资产负债方面，2026Q1 末总资产 42.54 亿元，归母权益 27.18 亿元，负债合计 15.36 亿元；应付债券 8.27 亿元，长期借款 0.98 亿元，货币/理财类资产口径未完整核验。可转债会带来财务费用、潜在转股稀释和回售/赎回管理要求。总体不是高杠杆危险资产，但扩产期现金流和债务匹配要持续跟踪。

## 治理与资本配置

公司实际控制人为彭志恩，控股股东为浙江桐本投资有限公司（来源：2025 年报及新浪主要股东页，2026-07-18 抓取）。新浪主要股东页显示浙江桐本投资有限公司持股 153,583,200 股、褚义舟持股 112,294,800 股、刘美华持股 16,513,200 股（来源：新浪财经主要股东页，抓取日 2026-07-18；是否为最新一期需以公司定期报告为准）。高管和创始股东持股较高，有利于长期绑定，但也要关注关联交易、控制权集中、可转债募投产能投放节奏。

分红/回购口径本次未完整核验，暂不把股东回报作为核心买点。更重要的是新增产能的 ROIC：如果扩产投入换来低价订单，资本配置质量会下行；如果承接 TIDES/小核酸高壁垒订单，ROIC 会改善。

## 竞争对手

普洛药业：大宗和特色 API、CDMO 综合平台，规模更大、产业链更完整，估值通常反映“稳态制造+CDMO”属性。与奥锐特相比，普洛抗周期能力更强，但 TIDES/小核酸弹性未必更高。

九洲药业：小分子 CDMO/特色 API 代表，客户和项目经验强。对奥锐特的启示是，真正的 CDMO 估值来自持续项目管线和大客户粘性，而不是单一新品高增长。

诺泰生物：多肽和小核酸相关能力更直接，是奥锐特 TIDES/小核酸叙事的重要可比。若市场给诺泰较高估值，奥锐特的 TIDES 放量也有估值扩张可能；但奥锐特披露颗粒度较低，不能简单平移。

圣诺生物：多肽 API/制剂/CDMO 可比，规模和订单波动也会影响估值。适合作为多肽产业链盈利波动参照。

皓元医药：分子砌块、工具化合物、CDMO 与特色原料药能力并存，研发服务属性更强。与奥锐特相比，皓元更偏前端研发服务，奥锐特更偏生产放大和制剂一体化。

可比公司实时 PE 由于本次没有接入 Wind/Choice，未核验；估值只采用“行业中枢区间+奥锐特自身财务”的方式，不把第三方二级行情 PE 当硬证据。

## 估值

基准股本：2026Q1 末股本约 4.0618 亿股（来源：2026Q1 报告）。
当前价格：19.43 元/股、总市值约 77.7 亿元、PE TTM 约 19.7 倍（来源：搜狐证券行情页，2026-07-18 抓取；行情数据存在刷新误差）。
TTM 利润估算：2025 归母净利润 4.49 亿元 - 2025Q1 1.19 亿元 + 2026Q1 0.64 亿元 = 约 3.94 亿元，和行情页 PE TTM 基本可相互验证。

相对估值：如果 2026 年归母净利润为 4.3-5.0 亿元，给 18-22 倍 PE，对应市值 77-110 亿元、股价 19-27 元。考虑 2026Q1 利润下滑，不能直接给 25 倍以上成长股估值；但考虑 TIDES 与女性健康结构升级，低于 18 倍也偏保守。相对估值中枢约 22-24 元。

绝对估值：用简化股权 DCF，2026 年归母净利润/自由现金流基准 4.5 亿元，2027-2030 年收入与利润年化增长 7%-10%，长期增速 2.5%-3.0%，股权折现率 10.5%-11.5%，并对扩产资本开支保持折扣，得到股权价值约 85-105 亿元，对应 21-26 元/股。该 DCF 对“高毛利产品能否持续”和“资本开支回报”高度敏感，置信度中。

情景估值：熊市情景，原料药价格继续下行、产能爬坡慢、2026 利润 3.5-3.8 亿元，给 15-17 倍，股价约 13-16 元；中性情景，利润 4.5-4.8 亿元，给 19-21 倍，股价约 21-25 元；乐观情景，TIDES/地屈孕酮/小核酸订单持续兑现，利润 5.5 亿元以上，给 23-25 倍，股价约 31-34 元。三种方法交叉后，合理价值区间取 21-26 元，买入区间取 15.5-18.0 元，减持区间取 27.5 元以上。

## 安全边际与交易计划

当前 19.43 元低于估值中枢，但还没有达到我要求的买入安全边际。观察名单中，等待两类信号：第一，价格跌到 18 元以下，且没有出现订单/合规/现金流恶化；第二，Q2 或 Q3 报告确认收入恢复增长、净利率从 2026Q1 的低位修复、TIDES 收入持续放量。

仓位计划：18 元以下可试探 1%-2% 组合权重；16 元以下且基本面未恶化可提高至 3%-4%；若三季报确认利润修复且价格仍低于 21 元，可把上限提高至 5%。若价格先涨到 27.5 元以上而没有利润上修证据，应减持或放弃追高。

## 主要风险

原料药价格风险：2026Q1 已验证价格压力能显著压缩利润，若行业新增产能继续释放，传统品类毛利率可能下台阶。

产品结构风险：TIDES 和女性健康增速快，但基数、客户和订单可持续性未充分披露；若高毛利品类占比回落，净利率会快速下行。

汇率风险：公司产品以外销为主且多以美元计价，人民币升值会削弱价格竞争力并形成汇兑损失（来源：2026Q1 报告）。

产能投放风险：转固后的折旧和运营成本已经拖累 2026Q1 利润，若新产线利用率不及预期，会形成“收入未到、成本先到”的压力。

监管和合规风险：API、制剂、小核酸 CDMO 均受 GMP、环保、安全生产、客户审计和药政监管约束，任何重大缺陷都会影响订单和估值。

基药/集采风险：地屈孕酮片进入基药目录有助于准入，但也可能带来价格约束和政策性降价。

## 跟踪指标

1. 2026Q2/Q3 收入同比是否恢复到 10% 以上，归母净利率是否回到 20% 以上。
2. TIDES 类产品收入是否继续高增，全年能否超过 3.5-4.0 亿元。
3. 女性健康和地屈孕酮片进入基药目录后的放量速度、价格变化和渠道费用率。
4. 新项目转固后的毛利率、折旧、产能利用率和单位成本变化。
5. 经营现金流是否持续覆盖研发和维护资本开支。
6. 汇兑损益、美元收入占比和套保策略。
7. 可转债余额、转股价修正、潜在稀释与财务费用。
8. 小核酸 CDMO 是否披露真实客户、订单、产能利用率和收入规模。

## 结论

奥锐特不是传统低端 API 公司，2025 年已经证明 TIDES 和女性健康能带来结构升级；但 2026Q1 也提醒我们，扩产期和价格周期会让利润波动很大。以当前 19.43 元看，估值不贵但安全边际不足，最合理动作是观察：等 18 元以下的价格，或等中报/三季报验证利润修复后再提高评级。

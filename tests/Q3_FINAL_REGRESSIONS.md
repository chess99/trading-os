# Q3 修正模型回归迁移

`q3-final-test-migration.json` 逐公司记录被替代的旧测试函数、新的已验收测试函数、函数 AST 摘要及读者文件清单。只替代经济模型已经被修正的公司；未列出的公司与通用代码测试不变。不使用跳过标记、失败白名单或放宽经济误差阈值。

- 新公司测试保留实际生产函数的反例、独立字面输入重建、全路径及单文件重生成断言。
- `test_q3_model_reproduction.py` 从正式模型目录复制单一 Python 文件重跑；修正模型主输出逐字节一致，同花顺另外核对全部 54 个 case 文件。
- `test_q3_final_publication_contract.py` 核对正式报告、结构化状态、已验收接口与所有相对读者链接；不把状态尚未同步当作通过。
- 少数原独立测试需要同目录结果包，`q3_final_fixture.py` 在临时目录以正式模型、正式报告、正式 JSONL 状态重建结果。候选接口来自小型独立验收快照，不是从结果复制；临时目录退出时清理。
- `q3_final_helpers/` 只保存独立数学脚本、小型接口/历史对照资料，不重复保存大型模型或输出。002315 历史全轨迹以 24 个端点/期限及默认路径的规范 JSON 摘要保留逐字段一致性要求；当前模型的完整独立重建与 96 个边界/期限路径仍实际运行。

运行：`PYTHONPATH=src python -m pytest tests -q`（需 pytest）。公司脚本和辅助脚本不访问网络，也不依赖研究工作目录。

# 1. 一句话结论

宁波韵升是国内高性能钕铁硼磁材的重要供应商，汽车、消费电子和工业客户认证、晶界扩散及低重稀土工艺构成可持续跟踪价值；2026年上半年量价齐升、扣非利润和现金流同步改善，但原料周期、材料销售毛利、低产能利用率及待定H股发行使8月28日11.70元已经隐含接近高位的持续利润。

# 2. 核心投资逻辑

公司经济价值来自把镨钕、镝铽等稀土原料加工成定制化高性能磁体和磁组件，并通过汽车、消费电子及工业客户的认证、联合开发和稳定交付获得加工利润。2026年上半年成品销量增长11.61%，主营收入增长40.35%，磁组件收入增长66.54%，说明量、价和深加工结构共同改善。

当前修复不能全部外推。上半年金属镨钕均价上涨约34%，主营隐含单位售价约上涨25.8%；其他材料销售贡献约1.21亿元毛利，而二季度总毛利率从一季度22.4%回落到19.5%。公司已有较多闲置产能和未投入募资，H股发行又可能改变普通股股数与资本结构。长期价值取决于高端订单、现金转化和新增资本回报，不取决于稀土价格单向上涨。

# 3. 商业模式与竞争优势

公司主营烧结钕铁硼永磁材料和磁组件，服务新能源汽车主驱、智能手机及声学器件、机械硬盘、工业伺服、家电、电梯、机器人和低空飞行器等领域。2026年上半年主营收入29.14亿元：新能源汽车15.03亿元、同比增长31.05%，占主营约51.6%；消费电子7.90亿元、增长46.27%，占27.1%；工业及其他6.21亿元、增长59.70%，占21.3%。国内新能源主驱配套172.84万套。

核心优势首先是认证和共同开发。汽车及工业客户对磁性能一致性、服役稳定性和批量良率要求高，更换供应商需要重新验证。其次是工艺，公司披露已形成成分控制、细晶粒、晶界扩散、材料利用率加工和表面防护体系，可量产低重或无重稀土磁体。再次是应用和组件能力，磁组件收入4.43亿元、增长66.54%，比单纯出售毛坯更贴近客户设计。

公司2026年上半年海外主营收入10.23亿元、同比增长66.79%，占主营35.1%，毛利率约24.2%，高于国内约17.2%；海外客户和高端产品构成差异化。但这一优势同时暴露于出口许可、海外供应链本地化和地缘政治。公司引用灼识咨询称2025年新能源汽车主驱用磁体销量全球第二，此为咨询口径，仍应以客户订单、复购和现金回款验证。

# 4. 行业与竞争格局

高性能钕铁硼兼具成长与周期属性。新能源汽车、电气化、工业自动化、数据中心硬盘、人形机器人和低空飞行器扩张，提升高性能磁材需求；但加工企业的利润还受稀土原料价格、客户议价、认证周期和产能利用率影响。2026年上半年国内新能源汽车产销同比增长6.7%和7.3%，工业机器人产量增长28%，需求仍增长但汽车增速已放缓。

供给约束不是名义产能。宁波韵升2025年末已有2.6万吨坯料产能，全年产量1.4856万吨、销量1.4197万吨，对名义产能利用不足六成。包头1.5万吨项目中首批5,000吨已于2025年投产，剩余1万吨从原定2026年6月再次延期至2027年末和2028年末各5,000吨。这既体现资本纪律，也说明行业竞争和订单消化没有紧张到必须立即扩产。

主要竞争者包括金力永磁、中科三环、正海磁材、大地熊和英洛华。金力永磁在新能源汽车、风电和节能家电规模更大，正海磁材在汽车磁材可比性较强，中科三环是老牌综合企业。宁波韵升的消费电子、机械硬盘和磁组件能力形成差异，但没有证据支持其脱离稀土价格和行业扩产周期。2025年4月以来中重稀土出口管制支撑战略属性和部分价格，也可能限制出口；2026年上半年中国稀土出口量下降6.4%。

# 5. 财务质量与股东现金收益

2023—2025年营业收入分别为53.69、50.41和54.64亿元，归母净利润为负2.27、0.95和3.31亿元，扣非归母为负2.01、0.98和2.79亿元，经营现金流为10.87、8.55和3.49亿元。利润与现金流跨年波动很大，符合原料和库存周期特征；2025年利润恢复时经营现金流反而下降，不能把单年利润当稳定复利。

2026年上半年收入33.367亿元、归母2.741亿元、扣非2.379亿元、经营现金流2.050亿元。总毛利率20.78%，上年同期16.55%；主营毛利率19.63%，上年同期17.51%。其中其他业务收入4.23亿元、成本3.01亿元，毛利1.21亿元，占总毛利约17.5%，且绝大部分为材料销售；这部分对稀土价格更敏感，不应获得与高端磁组件相同的估值。海外主营毛利率24.2%，国内17.2%，说明海外结构更好。

累计与单季口径显示趋势并非线性加速。第一季度收入14.984亿元、归母1.165亿元、扣非0.993亿元、经营现金流0.566亿元；第二季度由半年累计相减得到收入18.383亿元、归母1.576亿元、扣非1.385亿元、经营现金流1.485亿元。第二季度利润和现金均改善，但毛利率约19.46%，低于第一季度22.40%，表明高价原料、产品定价或结构已经压缩毛利。

# 6. 管理层、治理与资本配置

公司为民营控股，韵升控股持股29.15%，其全资子公司韵升科技投资持股3.28%，一致行动人宁波乾浩持股1.01%，实际控制人为竺韵德。控制权稳定有利于长期研发和客户投入，但持股集中度不算绝对，关联交易、管理层激励和融资摊薄仍需普通股股东视角审查。

资本配置存在正反两面。公司2022年定增净募资10.33亿元用于包头1.5万吨项目，截至2025年末累计投入4.80亿元、进度45.94%，未使用余额5.95亿元。延期避免在低利用率下盲目扩产，是纪律改善；但旧募资长期未投入、当前又申请H股融资，说明资本需求、项目回报和融资必要性需要更透明的解释。

2025年员工持股计划受让价7.03元，涉及最多1,179.63万股、约占股本1.07%，股票来自已回购库存股，不新增注册资本，但折价受让产生股份支付并把库存股重新送回流通。2026年新回购方案为0.5—1.0亿元、拟回购254—508万股，同样用于员工持股；截至7月31日仅回购26.4万股。激励可改善人才绑定，但这不是注销式资本返还。

# 7. 市场争议与隐含预期

乐观观点认为，公司在新能源汽车主驱、机械硬盘、消费电子和工业伺服拥有全球客户，销量与磁组件收入快速增长，稀土战略属性和机器人新需求会推动利润继续提升；H股上市可增加海外客户信任和融资能力。谨慎观点认为，上半年收入增长主要由售价驱动，其他材料销售贡献较多毛利，Q2毛利率已经回落；产能利用率偏低、存货高且H股融资会带来稀释。

8月28日11.70元对应市值128.59亿元、TTM归母PE约25.9倍、TTM扣非PE约30.0倍、PB约2.00倍。若给予21—24倍正常化PE，市场要求持续普通股利润约5.36—6.12亿元，接近或高于2026年上半年利润简单翻倍后的5.48亿元。也就是说，市场已要求高毛利和量增大体延续，尚未为原料回落、材料销售正常化及H股不利条款留下较宽余地。

市场可能低估的是海外高毛利、机械硬盘和磁组件增长的持续性，以及延缓扩产对现金的保护；市场可能高估的是将镨钕涨价带来的售价和材料毛利视作结构性盈利，并把机器人样品或协议当成大规模量产。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实层：现有总股本10.990亿股，库存股仍属于已发行股本，当前每股估值以总股本为分母。H股发行申请已递交但具体条款未定，当前价值不预先加入募资现金，也不假设零成本稀释。2026年6月末归母净资产64.20亿元，保守未受限净金融资产约11.72亿元；旧募投资金有指定用途。

经营层：TTM归母4.97亿元、扣非4.28亿元。考虑H1销量和高端结构改善、其他材料毛利约1.21亿元、Q2毛利率回落、汇兑和存货减值，以及全周期自由现金流弱于利润，普通股正常化利润取4.2—5.0亿元。保守情景为2.8—3.6亿元，较乐观情景为6.0—7.2亿元；较乐观情景要求磁组件和海外收入持续高增、产品涨价完整覆盖原料且现金转化改善。

方法一——正常化PE，为核心方法。4.2—5.0亿元利润给予21—24倍，权益价值88.2—120.0亿元，按10.990亿股约8.0—10.9元。倍数低于高成长龙头的市场估值，反映原料周期、产能利用率、H股稀释和现金转化；又高于普通材料公司，反映认证、工艺、海外和磁组件能力。保守情景用16—19倍约4.1—6.2元，较乐观情景用25—28倍约13.6—18.3元，均不替代核心区间。

方法二——PB交叉验证。BVPS约5.84元，正常化利润对应当前权益ROE约6.5%—7.8%；考虑净金融资产、客户认证和成长性，同时对库存、闲置产能及融资不确定性折价，取1.25—1.65倍PB，对应7.3—9.6元。PB中枢低于PE中枢约11%，差异来自PE计入未来订单增长，而PB更严格惩罚低资产周转和低ROE；PE是核心方法，PB用于限制上沿。

综合两种方法，核心合理价值区间：7.8—10.8 元。尚未量产的机器人和低空项目、未建成的一万吨产能以及未知H股募资用途不满额计入核心价值；H股正式条款、产能订单和现金回款得到验证后再更新。

# 9. 基准持有人回报模型输入

本次不提交结构化持有人回报模型。公司已递交H股发行上市申请，但新增股数、发行价格、超额配售、募资净额和最终用途均未确定，无法可靠冻结未来完全稀释股数和普通股权益桥。若直接使用现有10.990亿股，会忽略潜在新股；若先假设稀释比例，又会编造尚未披露的融资现金和每股价值。

已核验的分配事实只有2025年度每股现金分红0.10元。库存股1,196.41万股及2026年新回购用于员工持股而非注销，也不能视作持有人现金分配或确定的股数减少。待H股条款明确后，模型应以发行后A股加H股总数、净募资用途、A/H同股权益、库存股转让和未来分红政策，重新形成五项年度每股现金分配与独立第五年终值；当前合理价值区间不能代替未来终值。

# 11. 核心风险与证伪条件

1. 原料和库存风险。镨钕急涨而合同传导滞后会压缩毛利，急跌则会带来售价下调和存货跌价；材料销售毛利也可能逆转。若存货跌价和毛利率同时恶化，正常化利润必须下调。
2. 需求与产能风险。现有2.6万吨产能利用不足六成，若销量不能持续增长，包头后续产能会拉低ROIC。延期后仍缺少订单或新增产能投产两年利用率不足60%，将证伪成长假设。
3. 现金转化风险。TTM自由现金流仅约2.38亿元，低于4.97亿元归母；若经营现金流连续两个报告期低于扣非利润的60%，且存货和应收继续增长，应降低PE与PB。
4. H股融资风险。发行折价、规模过大或资金继续闲置会稀释普通股回报；只有募资投入形成高于资本成本的海外订单和利润，融资才创造价值。
5. 海外及客户风险。出口许可、贸易壁垒和海外磁材供应链可能减少高毛利订单；核心客户项目退出或认证切换会造成产能闲置。
6. 治理和激励风险。回购用于折价员工持股而非注销，若业绩门槛宽松、股份支付扩大或管理层在融资与扩产中忽视每股价值，会损害外部普通股股东。

# 科达利2026-Q3模型说明

金额采用十亿元人民币，股数采用十亿股；报告正文采用亿元。每股现金为元。文件只依赖Python标准库、相邻输入和当前结果，不依赖历史Git、下载缓存或旧的大型输出。

```text
python 2026-Q3.py
python 2026-Q3.py --details
python 2026-Q3.py --test
python 2026-Q3-independent.py
```

默认标准输出为`trading_os_research_result_v1`轻量结果。`--details`增加基准五年现金、主体分配约束、两种估值、资本结算桥和重要情景，结果保存于`2026-Q3-output.json`。独立入口生成`2026-Q3-verification.json`。

## 当前采用

当前核心价值88.3587783594—114.1103731214元/股，接口取88.4—114.1；第五年133.1614529131—167.4242395696元/股，接口保留两位小数。方法一为五年实际分配加第五年独立经营价值，方法二为立即成熟的利润资本化，后者只作辅助。当前价值、终值和价格分别处理。

首五年收入18%/15%/12%/10%/8%增长，税后普通股经营率9.8%—10.1%。每元增收投入0.60元新固定资本、0.20元经营营运资本；首两年明确抵扣已付款产能1.0、0.5亿元，另支付Q3存量资本结算10亿元与五年海外机器人权益资本3.8亿元。第1年末至第5年末利润增加13.50亿元、对应新增资本111.19亿元，预测端点增量回报约12.1%，该比率不构成项目成功的证据。

## 资本结算桥与预建能力

H1的设备工程应付款682960759.30元属于6月末，不能直接视为9月末同一批发票仍未付。模型采用Q3期末净资本信用预算，包含旧款清偿、新款形成及票据结算迁移。Q3实际现金购建555209644.33元已反映于期末现金，不在未来再次扣除。

H1至Q3，固定资产、在建、无形、长期预付、长期待摊和投资性房地产净额增加589012770.22元。以H1半年实际478437987.62元折旧摊销（不含使用权资产）约束Q3约2.2—2.8亿元，加处置报废净损失0—0.4亿元，再容许折算、税、费用分类与其他非现金差正负1.5亿元，可得期末资本信用约7.87—11.87亿元，研究采用约8—12亿元，中央10亿元。H1同样粗桥对实际应付款增量的未调残差1.0924亿元，支持保留分类容差，不能把资产净增直接当现金购建。

`capital_bridge`实际计算上述输入与结果。它不把租赁转入当现金购建，也不把总体其他综合收益全数视为固定资产汇率影响。季度未给固定资产完整变动表及资本应付细分，无法确定各类非现金结算的精确比例，故保留范围。

Q3在建加预付14.2502亿元。预留总部整个项目预算2.6344亿元，并假设中央估计资本结算10亿元全数先由这组资产承担，余约1.6158亿元；模型只条件抵扣1.5亿元已付款能力。实际应付未必对应在建，设备是否适配未来订单也未逐项目核实；1.5亿元是受量级约束的预算，数学检查不认证产能有效。0.60固定资本预算支付未来能力，预建抵扣对应已付款能力，资本结算支付开账未付能力。经营营运资本排除资本性供应商信用，避免与该结算重复。

仅改变未付预算8/12亿元，两端核心分别88.8780—114.6495元和87.8396—113.5712元。将低结算8亿元与3亿元预建抵扣、高结算12亿元与零抵扣配对，核心分别89.2710—115.0574元和87.4466—113.1633元；高组合借款峰值19.45亿元，仍在20亿元预算内。零预建抵扣另算为87.9658—113.7025元。

将开账资本信用完全归零的量级诊断为90.9549—116.8060元，比中央高约2.6—2.7元/股；该情况需要解释资产桥所指向的额外非现金资产增加或分类变化，未作为基准。
## 现金与权益守恒

每年集团满足：

`期初现金 + 普通股经营利润 + 金融收益 - 新增固定与营运资本 + 已付款预建抵扣 - 期初资本结算 - 额外项目资本 - 利息 - 普通股分配 - 激励回购 + 新借款 - 还款 = 期末现金`。

维护资本约等于折旧，在利润至现金桥中相抵；研发费用不加回。项目资金只支持项目支出，同步解除用途约束，不产生额外收益。保证金不计入随时可分配现金；集团10亿元运营备用计在经营资本，不再加入终值。基准第五年额外净现金为负10.1341亿元，即扣除尚存贷款；五年分红已从金融余额移除。

普通股经营率与额外项目资本按普通股经济归属估计，不把机器人合并营业收入全部归母。当前少数现金未细分，预留全部少数权益0.7797亿元作归属预算，量级约0.3元/股。已发行股本与可能在截止前行权但未单列登记的上界配对：最多60126股、6337881.66元。行权窗口已结束，不假设存在未来可行权期。激励回购扣钱、不缩分母、不列持有人现金。

母公司另受自身法定利润、法储、收现与必要投入约束。惠州和江苏宣派与母公司投资收益同年确认，延后到账记应收，收现不重复记利润；内部上划不创造集团收益。延迟时可借有限母公司过桥，债务和现金同时增加，随后先偿过桥再分红。资金地点及资本份额属于预算，另检验资本份额、旧亏损和上划延迟。基准不使用未知的历史子公司留存扩大分红。

## 独立复算与测试范围

独立入口不导入正式预算函数，用二分法求融资利息，独立重建五年分配及现金；独立展开七年利润、再投资和折现，分别核对两个核心端点。尾期增量回报12%降到10%时，独立低端82.8932861119元，较基准低端减少5.4654922476元。资本结算及预建能力敏感性经正式预算重算，未声称逐一独立复算。

生成正式尾值的同一`operating_value`函数接受两个手算例：100现金、10%折现、零增长，显性两期后仍值1000；100利润、5%增长、20%增量回报、10%折现，下一年现金105-5/20%=80，价值1600。逐年集团守恒、母公司现金和法定利润、五年接口、资本信用范围及预建抵扣均检查。1e-9十亿元容差用于计算误差，不表示预测精度。

资本系数再增20个百分点、收入不调的压力计划，在Y2需要24.39亿元债务，超出上限；降低扩产和收入增长、同时降低长期回报后重新形成完整可行路径，未沿用失败路径的利润或终值。常规复算没有重演长期逐节点轨迹或读取历史压缩档。

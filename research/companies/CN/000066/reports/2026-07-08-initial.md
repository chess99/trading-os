## 业务理解

中国长城科技集团股份有限公司（简称中国长城）是中国电子信息产业集团（CEC）旗下的核心上市平台之一，也是CEC"PKS"自主安全计算体系（飞腾Phytium CPU+麒麟Kylin OS+长城整机）的整机与系统集成整合方。

### 核心业务板块（基于公司公开信息和行业分类）

1. **自主安全计算/信创整机**：国产化台式机、笔记本、服务器、工控设备等整机产品的研发、生产和销售。以飞腾CPU为核心平台，适配麒麟OS，面向党政军及关键行业的信创替代市场。这是公司的核心概念和价值定位所在。
2. **电源业务**（长城电源）：服务器电源、PC电源、工业电源、通信电源等。长城电源是国内PC电源领域的老牌知名品牌，在DIY市场和服务器电源领域有一定份额。
3. **高新电子**：军工电子、网络安全设备、通信设备等。面向国防和关键基础设施领域的电子装备。
4. **数据中心/云计算**：数据中心解决方案、云基础设施服务。

公司营收在150亿左右但**净利润连年亏损**，表明核心业务毛利率极低、费用率极高，或者说存在着大量低毛利或亏损的业务（如低端整机代工或渠道型业务）。

### 股东背景

- 实际控制人：中国电子信息产业集团（CEC，央企）
- 中国长城是CEC"PKS"生态中整机/系统集成环节的核心承接方
- 公司持有**飞腾信息技术有限公司**部分股权（约31.5%，基于公开信息，置信度中），飞腾是国产ARM架构CPU的龙头企业之一

### 核心价值争议

中国长城的投资价值存在重大争议：
- **看多方认为**：信创/国产替代是国家级战略，飞腾CPU+长城整机形成绑定，作为央企平台有独特的市场准入优势；随着信创从党政向八大行业拓展，公司有望受益。
- **看空方认为**：公司连年巨亏，毛利率仅15%左右（且持续下降），经营现金流持续为负，核心业务（整机）是低毛利硬件组装业务，缺乏真正的护城河，飞腾股权的价值也被市场充分定价。

## 行业与竞争格局

### 信创行业

信创（信息技术应用创新）是中国政府推动的信息技术国产替代战略，涵盖CPU、操作系统、数据库、中间件、办公套件、整机硬件等全链条。

**市场规模**：根据公开行业数据（置信度中），2025年中国信创产业规模预计超过1.5万亿元，其中硬件（整机、服务器）约占30-40%。

**发展阶段**：信创已从党政试点进入全面推广期（2022-2027），目前处于：
- 党政信创：第一轮基本完成，进入常态化采购和升级阶段
- 行业信创：金融、电信、能源、交通、教育、医疗等行业正在加速推进
- 2025-2027年预计是行业信创的高峰期

**竞争格局**：
- CPU层面：飞腾（ARM架构）、鲲鹏（ARM，华为）、海光（X86，中科曙光系）、龙芯（LoongArch，自研架构）、申威（Alpha，超算）
- 整机层面：极其分散，主要参与者包括浪潮信息、新华三（紫光股份）、联想、中科曙光、中国长城、同方股份、百信等
- 操作系统：麒麟OS（中标软件+天津麒麟）、统信UOS（深度Linux）

**关键判断**：整机环节技术壁垒低，竞争激烈，毛利率天然低于15%。信创的真正价值在CPU、OS、数据库、中间件等高壁垒环节，而不是整机组装。

### 电源行业

长城电源在PC电源领域是国内知名品牌，但PC电源市场整体增长缓慢（甚至下滑），服务器/工业电源有一定增长但竞争也激烈。

### 高新电子

军工电子板块进入壁垒高，毛利率通常较好，但收入体量在公司的整体占比有限。

## 公司质量

### 优势

1. **央企背景**：中国电子（CEC）旗下，在信创市场有天然准入优势
2. **品牌价值**："长城"品牌在PC/电源领域有30年+历史，有一定知名度
3. **生态绑定**：与飞腾CPU、麒麟OS形成PKS体系，在信创市场有生态协同效应
4. **飞腾股权价值**：持有飞腾约31.5%股权，飞腾是国产CPU第一梯队，具有战略价值

### 劣势

1. **连续巨额亏损**：2023年归母净利润-9.77亿，2024年-14.79亿，2025年-0.56亿（减亏但仍在亏损）
2. **毛利率极低且趋势向下**：从2020年的22.6%持续下降至2025年的16.6%
3. **经营现金流连续为负**：2025年全年-3.26亿，2024年全年+1.82亿（但此前多年为负），2026Q1 -6.40亿
4. **自由现金流极差**：经营活动现金流持续为负+资本开支
5. **高负债率**：2024年资产负债率约56%（含大量有息负债）
6. **ROE持续为负**：2024年ROE -12.4%，2025年ROE -0.5%
7. **核心业务缺乏真正的护城河**：整机组装业务壁垒低，毛利率天然偏低
8. **利润质量差**：2025年上半年的盈利（1.38亿）的可持续性存疑，下半年又转亏

### 护城河评估

| 护城河类型 | 评估 |
|---|---|
| 品牌 | 中等，"长城"在PC/电源有一定知名度 |
| 技术/专利 | 偏弱，整机组装技术壁垒低 |
| 客户锁定 | 偏低，信创客户可切换供应商 |
| 规模效应 | 偏弱，毛利率持续下降说明规模优势未体现 |
| 监管壁垒 | 央企背景在信创市场有一定优势，但非排他性 |
| 网络/数据效应 | 无 |
| 转换成本 | 低（整机层面） |

**总体护城河评估**：窄或不存在。公司虽然有央企背景和品牌优势，但在核心业务（整机组装）上竞争壁垒极低，这也是公司长期盈利能力差的内在原因。

## 增长驱动

1. **信创行业beta**：行业信创从党政向金融、电信、能源等行业扩展，带来增量需求。这是最大的潜在增长驱动力。
2. **市场份额提升**：在信创整机市场中提升份额（但竞争激烈）
3. **产品结构升级**：从低端PC向服务器、AI服务器等高价值产品升级
4. **电源业务增长**：AI数据中心对服务器电源的需求增长
5. **飞腾股权增值**：飞腾CPU业务增长带来股权价值提升（间接）

**增长可信度评估**：信创行业beta是确定的政策方向，但公司能否真正受益存在疑问——公司连续亏损说明其业务模型本身存在问题，即使行业增长也可能无法转化为股东回报。

## 估值

鉴于公司连续亏损且EPS为负，PE估值和DCF估值意义有限。以下使用PB估值和情景分析为主。

### 相对估值（PB）

- **当前PB**：~5.5x（股价18.58元 / BPS 3.39元）
- **历史PB区间**：过去5年PB大致在2x-8x之间波动
- **行业PB对比**：浪潮信息~4x，中科曙光~6x，紫光股份~4x
- **信创整机公司合理PB**：考虑到公司连续亏损，PB应低于行业平均，合理在1-2x

### 净资产价值法

- 2026Q1 BPS为3.39元
- 考虑到资产质量（高应收账款、高存货），真实净资产可能低于账面值
- **保守合理价值**：BPS的0.8-1.5倍 = 2.7-5.1元
- **中性合理价值**：BPS的1.0-2.0倍 = 3.4-6.8元
- **乐观价值**（含信创战略溢价）：BPS的2.0-3.0倍 = 6.8-10.2元

### 飞腾股权价值（估算）

- 中国长城持有飞腾约31.5%股权（置信度中）
- 飞腾估值参考：未上市，参考同类国产CPU公司估值，可能在100-300亿区间（置信度低）
- 中国长城持股对应价值：约30-100亿
- 这部分价值可能部分反映在当前60亿市值中

### 综合估值区间

结合以上分析，**合理价格区间**为5-10元，对应市值约16-33亿元。

**当前18.58元价格**显著高于合理区间，说明市场给予了明显的"信创战略溢价"和飞腾股权溢价。

- 即使价格跌入买入区间，也需确认基本面边际改善（如毛利率企稳、经营现金流转正）

## 逻辑止损条件

- 2026年全年继续重大亏损（>5亿）
- 经营现金流进一步恶化（年度流出>10亿）
- 毛利率跌破12%
- 飞腾股权被剥离或大幅减值
- 信创政策明显转向或减缓

## 未来 1-3 年跟踪指标

1. **季度毛利率趋势**：是否企稳或回升（当前15-16%是底线还是仍有下行空间）
2. **经营现金流**：能否转正（连续6年多为负，这是最关键的跟踪指标）
3. **扣非净利润**：能否持续为正
4. **营收结构变化**：服务器/高毛利产品占比是否提升
5. **信创行业政策**：重点行业的国产替代推进速度
6. **飞腾CPU进展**：飞腾的营收增长、市占率变化和新产品迭代
7. **应收账款和存货周转**：营运效率是否改善
8. **有息负债变化**：债务是否在可控范围内
9. **关联交易/资产重组**：CEC是否有关联资产注入或整合

## 关键风险

1. **持续亏损风险**：公司已连续三年亏损，净资产持续被侵蚀。若不能尽快扭亏，存在ST或资产重组风险。
2. **现金流风险**：经营现金流持续为负，需要依赖外部融资维持运营，存在流动性风险。
3. **毛利率下行风险**：毛利率从22%持续下降到15%，信创整机市场竞争加剧可能进一步压低毛利率。
4. **竞争风险**：浪潮信息、新华三、联想等竞争者在服务器/整机领域有更强的产品能力和规模优势。
5. **资产减值风险**：存货和应收账款合计145亿（2026Q1），远高于货币资金33.9亿，存在潜在的减值风险。
6. **信创政策节奏风险**：信创推进速度可能受宏观经济和财政预算影响而放缓。
7. **应收账款风险**：67亿应收账款（2026Q1），占营收比例高，客户主要是政府和国企，回款周期长。
8. **关联交易和治理风险**：作为央企子公司，存在关联交易和利益输送的潜在风险。
9. **估值风险**：当前PB 5.5x对于一个连续亏损的公司偏高，股价存在大幅下跌风险。

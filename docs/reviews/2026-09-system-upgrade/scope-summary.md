## 边界核对

湖南白银、安宁股份、华电新能、南方传媒虽然列有半年报预约来源，仍未使用已披露半年财务，排除。中科曙光自身只有业绩快报，引用的正式半年报属于海光信息，排除。巨化股份只有半年经营量价、安迪苏只有半年业绩快报，均排除。国投资本、湘财股份和国网英大引用子公司半年财务，不能替代上市集团中报。

东鹏饮料已使用港交所正式中期业绩中的收入、利润、现金流、权益与分部信息，纳入；百济神州已使用SEC第二季度Form 10-Q中的半年度财务，纳入。国仪量子使用IPO上市公告中的未经审计H1主要财务数据，当前并非正式中报版本，按用户限定排除。

## 证据与遗漏风险

程序读取全部822份当前正文，定位财务期间、实际数字和来源，再核对标题变体、跨行链接以及上述边界；证据的line为基线原文一基行号。范围盘点没有逐份重新下载原始财报，也没有认定其数字正确或研究已通过质量验收。后续审核必须重新取证关键原件。

由于少数报告使用裸URL或省略期间的表格，单一正则会漏选；本次补查中期/Interim/10-Q标题、相邻链接与正文H1数据。清单判定针对基线版本，不会自动吸收并行任务新写入的报告。正式修订前应再次比对当前指针及原文；若指针或正文已变，暂停该家公司并复核，不能覆盖他人的更新。

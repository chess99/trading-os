# 财报周期报告与动态重点跟踪池迁移

完成日期：2026-10-15。

## 结果

- 公司完整报告统一进入 `research/companies/CN/{代码}/reports/`，删除 `legacy/` 目录和旧稿打捞入口。
- 文件名统一为 `YYYY-FY.md / YYYY-Q1.md / YYYY-H1.md / YYYY-Q3.md`；同一公司、同一财报周期只保留一份完整研究。
- 同周期重研由 `research complete` 覆盖原周期文件并重新验收；跨周期才新增文件。产品不提供同周期旧修订入口。
- 6,688 份原日期稿按“公司 × 财报周期”合并为 5,923 份周期报告，共去除 765 份同周期重复稿。迁移后为 5,541 份 `2026-Q1` 和 382 份 `2026-H1`。
- 同周期冲突优先保留结构化状态依据稿，其次保留现行验收稿，再其次保留原 `reports/` 中完成日期较晚的版本；不拼接正文。
- 原隔离稿的来源提交、原路径和对象 ID 继续以“迁移来源”保存在正文头部，但不再带有隔离或不可阅读提示。

## 状态与展示

- 状态 schema 升至 v4：`report_path` 改为 `basis_report_path`，并新增 `report_period`。该指针只说明结构化研究依据哪份报告，不决定网页范围。
- 价值质量池仍由 `screening/cn-a/value-quality/pool.json` 动态维护；成员增删和 A/B 分层变化不会移动或删除公司报告。
- 控制台默认显示当前重点跟踪池，数量从池文件现场读取，不固定为191家；全市场保留研究状态和报告入口。
- 研报库对公司直接打开最新财报周期，并在入口显示周期与最近更新时间；页内可切换其他财报周期。
- 现行兼容且有效的依据报告才加载行情、估值和持有人模型。其他周期只阅读正文，不回退旧估值。
- 不在当前证券状态表但仍有报告的5个代码以“仅历史档案”保留，不进入全市场状态、行情或研究进度。

## 验收绑定

报告级 acceptance 改用财报周期文件名。迁移只改变路径组织和结构化字段名，不重做公司经济判断；191份既有验收重新绑定迁移后的 `2026-H1` 正文和 v4 结构化摘要。同周期正文以后发生变化时，原哈希不再匹配，必须重新实质验收。

# 泰格医药2026-Q3计算说明

## 文件和入口

- `2026-Q3-inputs.json`：已核原始事实、日期、单位、来源位置，以及明确标为研究预算的经营和诊断假设。
- `2026-Q3.py`：使用标准库计算单季勾稽、服务经营DCF、第三年EBIT资本化、金融本金与未来权利诊断、集团资金量和股本桥。
- `2026-Q3-output.json`：当前简明再生结果，金额十亿元、股数十亿股，每股人民币元。总普通股价值及持有人输入均为null。
- `2026-Q3-check.py`：独立直接算式复算DCF核心端点与利润率扰动，并查单季、母股利余额桥、现金与债务守恒、注销和归属股数。

运行需要Python 3标准库，无外部模型、私有资料、历史Git对象或压缩包依赖：

```text
python 2026-Q3.py --output 2026-Q3-output.json
python 2026-Q3-check.py
```

## 结果边界

经营DCF的92.1—120.5亿元是合并服务企业价值，包含非控股经营份额、在融资前计量。辅助EBIT法132.6—171.8亿元共享经营假设且更依赖较长的高回报持续期，未取平均。两者均未冒充上市公司普通股总权益。

金融账面143.30亿元与减全部净少数权益后的107.06亿元只是资产分配算例，不能组成严格归属或公允价值区间。净NCI不能直接限定单项资产的毛额归属。按未来某年收到某比例账面金额的输出仅是现金时点诊断；会计公允价值已经含估计，不自动施加第二遍时间折扣。

未来60亿元缴款与新取得权益的回收一起进入净现值测试，没有将缴款全额解释为损失。第六年及0.5/1/1.4倍回收不被当成可采纳项目预测。真实逐项权益、期限和经济性尚不足以约束核心投资路径，故不据此发布每股区间。

资金测试采用集团合并最宽口径，现有债正常续作。三年各缴20亿元是集中付款条件；存单释放0至Q3其他非流动资产全额、投资退出0或每年5亿元均是量级条件。现金来源不代表可跨主体调用。留足10亿元现金、股利为零和不依赖员工条件缴款，是寻找融资边界的诊断设定，不是未来分配预测。需要融资时按真实新增债务、利息与偿还逐年守恒。

母H1应收股利余额桥隐含收现2.830亿元，但投资收益现金3.292亿元还有其他构成，不把两者相同化，也不把以前确认的股利再次加到本期利润。H1母现金扣当时应付分红仅为历史备考桥；正式Q3现金不重复扣7月已经实施的同一分红。

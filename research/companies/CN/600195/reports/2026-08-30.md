# 1. 一句话结论

中牧股份是具备兽用疫苗资质、央企信用和综合渠道的动物保健平台，2026年上半年扣非主业已从低谷恢复，但低ROE、营运资本占用和7.27亿元无业绩承诺收购仍要求折价；8月28日6.89元对应的市值已经计入较充分的利润修复，核心合理价值低于该价格。

# 2. 核心投资逻辑

公司价值来自三部分。第一，兽用生物制品的批准文号、菌毒种、GMP生产和批签发体系形成监管壁垒，央企信用及大型养殖客户渠道增加准入稳定性。第二，化药、饲料添加剂与贸易网络提供客户触点，2026年上半年化药恢复是利润回升的主要来源。第三，圣雪大成交易若完成，可补入发酵原料药、出口认证和上游制造能力。

这些资产尚未形成高资本回报。2026年上半年扣非归母利润1.02亿元，相对期末57.16亿元归母净资产仍低；生物制品收入仅3.41亿元，乾元浩继续亏损，贸易收入占比高而毛利低。收购的战略方向有合理性，但价格约为标的简单年化归属利润的22倍，没有业绩承诺，不能先把协同当成确定利润。

# 3. 商业模式与竞争优势

公司业务包括生物制品、兽用化药、饲料及添加剂、贸易四类。2026年上半年各板块收入分别为3.41、11.91、5.31和11.01亿元，对应毛利率约31.7%、22.6%、18.8%和9.5%。贸易提供规模、客户和供应链协同，但其低毛利决定了收入规模不能直接代表经济价值；真正影响利润的是疫苗、化药和高附加值添加剂。境外收入2.01亿元、毛利率约40.1%，胜利生物通过FDA现场检查说明部分化药具备出口资质。

疫苗的进入壁垒真实存在：产品研发、注册、生产质量体系及批签发均需要时间和合规投入，政府防疫及大型养殖客户也看重长期质量记录。央企背景、全品类产品及渠道复用能降低单品获客成本。弱点是常规化药和贸易容易价格竞争，疫苗资质也不等同于持续定价权；只有新品销售、复购和现金回款得到验证，研发批件才转化为普通股价值。

公司对主要养殖客户提供产品和综合服务，需求最终由动物存栏、养殖盈利、疫病防控和政府采购驱动。上游包括菌毒种、发酵和化工原料，原料及产品价格变化会通过毛利率传导。增长若伴随应收和存货更快增加，就会消耗资本；2026年上半年正出现这一迹象。

# 4. 行业与竞争格局

动物保健需求长期受规模化养殖、生物安全和监管升级支撑，但短周期跟随猪禽养殖盈利、疫病变化和招采节奏。行业利润向拥有产品注册、规模生产、渠道和研发能力的企业集中，同时常规疫苗及化药仍面对同质化和价格竞争。主要可比企业包括生物股份、瑞普生物、普莱柯、回盛生物和金河生物，各自在疫苗、宠物动保、化药或原料药上更聚焦。

中牧的优势是综合平台和央企信用，劣势是业务组合较杂、贸易占比高、子公司少数股东较多，集团收入和利润不能全部归属普通股股东。当前利润率更接近低位修复而非高点：2025年第四季度扣非亏损0.92亿元，2026年第一、第二季度扣非各约0.51亿元，显示经营止跌；但尚未恢复到2023年2.79亿元年度扣非利润的水平。

南非1型多价口蹄疫疫苗获三个临时批准文号，有效期至2028年7月，产品仍需批签发且没有销售数据。戊巴比妥钠为三类新兽药，仍需申请产品批准文号，公司也无法取得同类市场销售数据。两者是产品期权，不进入核心盈利。

# 5. 财务质量与股东现金收益

2023—2025年营业收入为54.06、60.17和62.05亿元；归母净利润为4.03、0.71和1.71亿元；扣非归母净利润为2.79、0.62和0.20亿元。2025年归母利润明显高于扣非，主要因金威可转债公允价值收益1.10亿元等非经常项目，不能作为持续经营收益。2025年经营现金流11.58亿元看似很强，主要来自经营应收回收5.37亿元和经营应付增加2.90亿元，也不是稳态自由现金流。

2026年上半年收入31.706亿元、归母0.498亿元、扣非1.018亿元，毛利率约18.44%，上年同期约17.20%。归母低于扣非主要因金威可转债公允价值变动损失0.414亿元，非经常损益合计负0.519亿元。以2025全年减2025上半年再加2026上半年计算，TTM收入65.83亿元、归母1.394亿元、扣非0.403亿元；8月28日6.89元对应市值70.36亿元、TTM归母PE约50.5倍、TTM扣非PE约174倍。

累计与单季必须分开看。2026年第一季度收入15.086亿元、归母0.242亿元、扣非0.510亿元、经营现金流负3.086亿元；用半年累计减第一季度，第二季度收入约16.620亿元、归母约0.257亿元、扣非约0.507亿元、经营现金流约0.665亿元。扣非主业两季稳定，并未继续恶化，但第二季度现金流转正仍不足以抵销上半年累计负2.421亿元。

# 6. 管理层、治理与资本配置

公司由中牧集团控制，最终控制人为国务院国资委体系。央企背景有助于长期信用、资质协同和融资稳定，但资本配置应以普通股回报检验，不能用平台地位替代ROE。低ROE和复杂子公司权益是治理关注点：乾元浩上半年收入1.40亿元、净亏损0.28亿元，公司直接持股27.21%，主要通过集团表决权委托取得控制，经济利益大量归少数股东；胜利生物收入3.78亿元、净利润0.62亿元，公司持股55%，仍有45%少数股东分享盈利。

圣雪大成收购是当前最重要的资本配置。5.566亿元收购河北圣雪大成51%，1.707亿元收购内蒙古圣雪大成72.7272%；河北另持内蒙古27.2728%，交易后中牧直接加间接持有内蒙古86.6363%。交易无业绩承诺，资金来自自有资金及银行贷款。2025年10月两标的对应被收购账面权益约4.00亿元，而支付7.27亿元，差额约3.27亿元可能进入可辨认资产重估或商誉，最终以购买价分摊为准。

河北标的2024年收入8.75亿元、净利润0.592亿元，2025年前10个月收入7.20亿元、净利润0.424亿元；内蒙古标的同期分别为收入3.72亿元、净亏损0.138亿元及收入3.42亿元、净利润0.080亿元。按直接购买权益粗算，归属中牧的2024年利润约0.20亿元，2025年前10个月约0.274亿元、简单年化约0.329亿元，交易价约为该年化利润的22倍。内蒙古标的2025年10月负债8.50亿元、资产9.74亿元，杠杆较高。评估最终采用资产基础法且评估机构说明经营预测可靠性不足，因此协同收益只能在实现后确认。

# 7. 市场争议与隐含预期

乐观观点是化药已恢复，疫苗批件和央企平台可在养殖景气改善时释放利润，圣雪大成补强原料药、发酵和出口能力。谨慎观点是2026年上半年归母只有0.50亿元、扣非ROE仍低，应收和存货快速增加，交易没有业绩承诺且可能形成商誉。两种观点的分歧不在收入能否增长，而在增长是否转成归属普通股的现金利润。

6.89元对应70.36亿元市值和约1.23倍2026年6月末PB。按2.3—3.1亿元可持续归母利润看，相当于约22.7—30.6倍正常化PE；若市场给18—22倍，当前市值要求正常化利润约3.2—3.9亿元。也就是说，价格不只要求上半年扣非水平持续，还要求收购贡献、产品结构改善或费用效率继续兑现。市场可能低估了平台资质和化药恢复的持续性，也可能高估了收购协同及新批件转化速度。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实层：总股本10.211亿股，2026年6月末归母净资产57.16亿元。圣雪大成未纳入半年报；截至截止点，反垄断审查、付款和产权凭证已完成，但公告清单未显示工商及控制权交割完成。交易价款的现金成本已经发生，标的资产、负债、商誉和少数股东权益仍须正式并表确认。

经营层：不含收购时，2026年上半年扣非年化约2.04亿元，考虑季节性、2025Q4亏损和营运资本压力，正常化利润取2.3—2.8亿元；收购完成后按当前可验证盈利可增加约0.25—0.40亿元归属利润，但工商及控制权交割尚未公告完成，核心估值只计入0.15—0.25亿元。合计基准正常化归母利润取2.45—3.05亿元，保守情景1.2—1.8亿元，较乐观情景3.5—4.2亿元。较乐观情景要求疫苗恢复、收购整合和现金回款同时兑现。

方法一——正常化PE，为核心方法。基准利润2.45—3.05亿元、20—21.5倍PE，对应权益价值49.0—65.6亿元、每股约4.8—6.4元；考虑资产法交叉及取整，核心区间下限取5.0元。保守情景采用1.2—1.8亿元及14—17倍，约1.6—3.0元；较乐观情景采用3.5—4.2亿元及20—22倍，约6.9—9.1元。悲观与较乐观情景不冒充核心价值。

方法二——PB交叉验证。BVPS约5.60元，当前主业ROE较低，交易后又可能新增约3.27亿元可辨认资产重估或商誉，因此给予0.9—1.15倍PB，对应约5.0—6.4元。若最终商誉较大、收购ROIC低于资本成本，应使用区间低端或更低；只有普通股ROE稳定恢复到6%—8%且现金转化良好，才支持上端。两种方法中枢接近，PE决定核心区间，PB只检查资产与低ROE约束。

核心合理价值区间：5.0—6.4 元。该区间是截至截止点的当前普通股经济价值，不是交易指令。未形成可核验收入的新批件、未交割完成的会计权益和未经验证的协同不按满额计价。

# 9. 基准持有人回报模型输入

模型采用annual_common_equity_irr_v1，五年一股持续持有人现金分配依次为0.06、0.08、0.10、0.12、0.14元，只包含现金分红，不包含公开市场回购、会计利润或未分配现金。分红假设从2025年约0.051元/股逐步提高，要求扣非利润恢复且并购不继续显著消耗现金。

第五年终值独立按第五年归属普通股正常化利润3.2—4.0亿元、17—19倍退出PE、10.211亿股完全稀释股数推导为5.3—7.4元/股。这不是当前价值区间的复制：它对应五年后的经营状态、较成熟的利润和单独的退出倍数。模型不提交机械推导的第三年终值。

普通股权益桥不把交易前现金重复加入终值。已支付价款使母公司简化净现金转为净债务，未来标的现金债务、商誉和少数股东损益以交割后报表更新；终值直接使用归属普通股利润的PE，不另加净现金，五年已经发出的分红也不再计入终值。未来完全稀释股数暂按10.211亿股，无已知自身可转债或股权激励稀释；后续若增发、回购注销或融资工具变化，模型必须重做。正文不计算任何依赖报告时点价格的回报率。

# 10. 公司、财务、治理和行业事件触发

优先跟踪：圣雪大成工商及控制权交割、购买价分摊、商誉、标的现金债务和少数股东权益；季度及年度扣非利润、应收、存货和经营现金流；收购后标的收入、归属利润、杠杆和现金回款；生物制品收入与毛利率、乾元浩亏损和胜利生物利润；口蹄疫疫苗批签发与销售、戊巴比妥钠产品批准文号；养殖盈利、重大动物疫病、兽药监管、原料药价格与出口认证变化。

# 11. 核心风险与证伪条件

1. 收购风险。若工商交割延期、购买价分摊形成较大商誉、内蒙古高杠杆带来额外融资，或交割后两年归属利润持续低于0.25亿元，交易可能摧毁价值。
2. 现金转化风险。若应收和存货继续快于收入增长，经营现金流连续两个报告期显著弱于扣非利润，正常化利润和分红能力都应下调。
3. 产品与竞争风险。疫苗招采价格、常规化药竞争或养殖低迷会压缩毛利；新批件若无法形成批签发、订单和回款，则产品期权归零。
4. 普通股归属风险。乾元浩继续亏损而胜利生物等优质利润由少数股东大量分流，会使集团经营改善不能等比例落到普通股。
5. 金融资产波动。金威可转债公允价值已造成归母利润大幅偏离扣非，若信用或估值恶化，可能进一步影响净资产和报告利润。

最重要的证伪条件是：收购完成后两年仍不能把归属利润稳定提升至至少2.45亿元，同时应收及存货持续恶化、经营现金流长期弱于扣非利润，并出现商誉减值或标的债务压力。届时应推翻当前基准正常化利润及继续覆盖的理由。

# 12. 最终判断

报告时点价格为6.89元/股（腾讯行情，2026年8月28日收盘），市值约70.36亿元；核心合理价值区间为5.0—6.4元/股。已形成可靠的五年return_model，最关键口径是五年每股现金分配0.06、0.08、0.10、0.12、0.14元，以及基于第五年3.2—4.0亿元普通股归属利润和10.211亿股的5.3—7.4元终值。

条件性上行来自收购后归属利润稳定高于0.40亿元、疫苗新品形成销售且营运资本受控；这些前提现阶段不进入核心价值。三个最重要正面变量是两季度扣非主业稳定、资质与综合渠道壁垒、圣雪大成对原料药和出口能力的补充。三个最重要负面变量是低ROE及贸易占比、应收存货与现金流压力、无业绩承诺收购及潜在商誉。最重要证伪条件是并购后两年普通股归属利润仍低于基准下限并伴随现金转化和资产质量恶化。

最终去向：covered。中牧股份值得因资质平台和利润修复持续维护，但当前价格已经反映了比现有扣非利润更充分的恢复，决定长期价值的是并购与新品能否转成普通股现金收益。

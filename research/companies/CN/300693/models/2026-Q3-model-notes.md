# 盛弘股份2026-Q3模型说明

金额为百万元、股数为百万股、每股金额为人民币元。`2026-Q3.py`读取相邻的`2026-Q3-inputs.json`，实际生成`2026-Q3-output.json`。常规运行只依赖Python标准库。正式附件仅需这三份文件、本说明及`2026-Q3-check.py`，合计远低于2 MiB。

## 入口与实际计算

```text
python 2026-Q3.py --check
python 2026-Q3-check.py
```

模型从分部收入和毛利推经营利润，正盈利子公司与亏损子公司不互相抵税，扣少数归属、必要资本及现金缓冲。前五年逐年核母公司直接利润、法定留存和现金付款门槛；长期存单到期是资产转换。第五年以后的业务现金继续推到第十五年，成熟期2%增长对应持续的营运、固定与现金投入；业务价值不含存款利息或既有额外本金。前五年45%分红预算不会被永久外推成无意义的现金积存；成熟后返还可用盈余属于明确的长期资本配置假设。

第五年额外金融本金在扣完五次分配、回购、还债和全部必要投入后估计，主要位于母公司，按两年实现、1%费用和净息形成价值。子公司少量额外本金采用75%实现比例，全部无法实现作为量级检查。公司没有承诺特别分配到期存单。

回购初始库存和新回购均计现金及股数；新回购均价35元仅为资本行动预算，第四年全部重新流通，不计未定价的员工转让回款。新授限制股按模型利润触发归属比例，认款扣此前股息并与股份同步入账。股份费用按预计公司归属比例、扣已确认费用后摊销；非现金费用不当现金税抵免。无行使的情景仍承担已经取得的员工服务费用。

## 关键假设与边界

- 核心估值23.989096—27.546417元，第五年终值34.166286—38.215444元；未来五次实际分配0.664119、0.995200、1.101989、1.174786、1.225718元。
- 正常化2026收入41.9亿元由累计27.71亿元、H1分部和交付季节性约束；分部Q3、同规格净价与订单毛利未披露。工业/PCS出海复制是增长判断，成熟工业52%、PCS29%毛利是竞争衰减预算。
- 初始营运资本约428.822百万元由公开科目复算，长期合同资产沿用H1明细；目标14%收入使第一年增加约253.552百万元。常规购建3.5%收入、折旧2.5%，另加120百万元建设承诺预算，已付在建资产没有重复收费。
- Q3母公司现金缺少披露，按H1母/集团现金等价比例分配Q3合并余额；正负100百万元都未改变核心付款。母现金支持主要经营法人，没有把集团余额当作当然可在母公司支付。此种支持是预算，须以合法经营往来或资本安排落实。
- 母15%税惠续期为预测，已知证书有效年度仅2023—2025；子正利润默认25%，纳税亏损不跨法人抵扣。单列失去优惠的完整资金和终值重算。
- 合并少数权益初始预留694.837万元；后续小额少数盈利采用税前经营利润0.5%、25%税后归属预算，并非把全部子公司经营利益扣除。该近似不能替代未来重大少数交易核验。
- 待实施盛弘新能源员工增资只属于该法律主体；其H1净亏1233.94万元，未把全部PCS机械视为该公司。新增员工认款约43.088百万元不计母利润，敏感性同步处理现金与21.5%未来利益归属。两种子利润识别路径都不额外抬高集团总经营利润。
- 结构弱和周转压力需提前解出部分定期存单。该路径明确以银行允许提前支取为条件，承担0.5%损耗，未宣称已经批准或无条件可得。未改变经营资产、已签建设与正常履约资本。没有使用未核实外部授信补足资金。
- 既有受限资金仍服务经营担保；额外金融资产与财务收益分开。已识别约22.074百万元非经营投资按80%回收、3%费用和回款25%税储备预算；全部损失检验影响约0.02元，真实税基未知并不主导估值。

## 已执行核验

1. 主模型内将100收入、40%毛利、20%费用、25%税、折旧等于维护支出且零增长的手算特例送入正式`operating_step`函数，得到现金15；正式付款门槛以现金12、底线5、目标10得到支付7；正式尾值函数对每年15、10%成本、零增长得到150。
2. 每年资金守恒实际覆盖本金到期转换、认款、回购、已付分配、还债、非经营投资和压力支取费用；检查前五年股数、库存重新流通、法定利润、集团与母资金约束。
3. 独立脚本不导入主模型，直接从必要输入用另一套循环重建前五年的经营FCF、实际付款、股份、集团/母现金和法定利润，重新计算两个DCF端点。得到23.989096与27.546417元。
4. 同一独立脚本用解析毛利变化重算第六年起毛利低2点的结果，再与主模型实际重新运行该参数后的输出比较，得到20.662618—23.612729元。该检查不是模型外恒等式自证，也未靠冻结端点通过。
5. 公开原始PDF重新下载；Q3全文，H1分部、母表、税、存单、受限资金、资本承诺，2025历史/分部/公积及资本表，限制股、实际权益分派、11月首次回购和子增资公告均核身份及相关完整上下文。主表关键页做图核；H1第28页使用Poppler渲染，另图核母表、存单/受限、Q3权益及现金表和首次回购页。通合与部分产业网页为已核发行人正文，未宣称逐页图核或审计全部附注。

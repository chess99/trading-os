# 双轨商业质量筛选规范（A 股全板块 + 港股）

本规范定义 Trading OS 的两轨深研入口，解决“单一静态白马筛选会系统性漏掉早期高复利成长股与强供需拐点股（潜在高赔率标的），同时又要避免对全市场五千家公司无差别深研造成 Token 浪费”的矛盾。

- **活跃个股市场**：**A 股（主板 / 创业板 / 科创板 / 北交所）+ 港股（港股通口径）**，A+H 合计建议控制在 **160–220 家独立发行人**。
- **独立性原则**：筛选只决定“哪些企业值得进入 AI 持久化深研底座”，严禁写入现价、PE/PB、估值区间、IRR 或买入线。

## 一、两条轨道的定位与准入尺子

| 维度 | 轨道一：复利质量池 (`compounder`) | 轨道二：产业拐点与成长池 (`inflection_growth`) |
|---|---|---|
| **目标规模（A+H 去重）** | **~120–160 家** | **~40–60 家**（动态换血） |
| **捕捉对象** | 商业模式成熟、护城河已跨周期验证、普通股现金丰沛的稳健复利及高股息核心资产 | ① **早期复利型**（新技术/新范式渗透率起步 + 工程/成本/渠道能力可跨产品或出海复制，如早期比亚迪）；<br>② **供需拐点型**（行业经历惨烈出清、产能收缩而颠覆性新需求爆发，如 AI 早期存储、算力互联、稀缺上游瓶颈） |
| **筛选启动方式** | 自下而上全市场财务与商业扫描 + 行业同行对比 | **必须由行业研究层自上而下触发**：优先从 `research/publications.json` 中标记 `industryState.inflectionCandidate = true` 或处于 `upcycle_tight` / `inflection_bottom` / 底部出清尾声的赛道中挑选 |
| **盈利与 FCF 容忍度** | 要求多年稳定正盈利、可靠 ROIC 与普通股现金转换 | **允许当期 FCF 为负或历史 ROE 处于周期谷底**，但须同时满足四项硬门槛 |
| **默认质量分层** | 核心护城河（A）或质量研究（B） | 初期通常入 B 层（质量研究），待商业验证与现金完整兑现后再升入 A 层 |

## 二、轨道二（`inflection_growth`）的四项硬准入门槛与排雷

绝不允许纯靠题材、概念或单一年度业绩暴涨进入轨道二。每家候选必须在判断卡中明确回答以下四问，缺一不可：

1. **客观需求或供给拐点证据**：
   - 早期成长型：存在客户认证通过、头部客户定点/量产放量、海外市场突破或核心单品渗透率跨过临界点的可核验公开证据；
   - 周期拐点型：存在行业资本开支大幅削减、库存去化尾声、报价/稼动率实质反转或新需求（如 AI 服务器/HBM/电网升级）拉动供需缺口的行业数据支撑。
2. **边际单位经济性改善**：即使集团总利润仍在爬坡或重投，核心产品的单位毛利额、订单净价、良率或人效必须呈现向好轨迹，而非纯靠补贴、赊销或价格战买份额。
3. **资产负债表生存底线**：在建投入与研发支出强度下，现有现金、银行授信与可承受稀释足以支撑公司穿过重投或底部出清期，不存在近期流动性断裂或毁灭性股权摊薄风险。
4. **全球标杆与终态赔率参照**：对照 [research/benchmarks/global-leaders.json](../../research/benchmarks/global-leaders.json) 或成熟海外龙头，说明若 3–5 年产业趋势兑现，公司在市占率、稳态盈利能力与增量资本回报上具备显著复利或倍增空间，且该优势能留在普通股手中。

### 轨道二动态退出与晋升规则

- **晋升轨道一**：若技术路线与份额已定型、资本开支高峰度过并开始稳定释放普通股现金，在半年度复核时将 `track` 切换为 `compounder`；
- **果断退出**：若产业渗透率停滞、核心客户验证失败、竞争迅速演变为同质化价格战、或行业扩产再次导致过剩而无成本护城河，及时移出池外（已完成的深度研报留存档案备查，不删除历史）。

## 三、A/H 发行人合一去重与行业关联

1. 港股池与 A 股池通过 `issuer` 字段绑定同一发行人（例如 `CN:000333` 与 `HK:00300` 共用 `issuer: "CN:000333"`）。全部市场口径按发行人去重计数，**深研队列只在主研究侧执行一次**，避免对同一家公司重复消耗 Token 写两篇报告。
2. 每家入池公司应尽量填写 `track`（`"compounder"` / `"inflection_growth"`）与 `industry_topic`（严格匹配 [research/industries/catalog.json](../../research/industries/catalog.json) 的 34 个标准主题 ID，或通过 [topic-routes.json](../../research/industries/topic-routes.json) 自动路由），以便自动继承行业周期与宏观顺逆风坐标。

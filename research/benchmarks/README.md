# 全球产业龙头参照表

本目录维护 [global-leaders.json](global-leaders.json)，收录 25 家跨越半导体、AI 基础设施、企业软件、医疗器械、消费零售、工业服务及金融基础的全球产业标杆企业。

## 使用边界

1. **只作对标参照，不作个股队列**：由于投资者账户不具备美股个股直接交易权限，美股配置统一通过国内美股宽基 QDII ETF（标普 500、纳斯达克 100）完成。本表不建立美股个股研究任务、状态或季度估值。
2. **服务两类研究场景**：
   - **行业商业模式上限对照**：研究 A 股/港股制造业、零售、软件、医疗器械或保险公司时，对照国际同行在稳态毛利率、增量资本回报、后市场/耗材比例及资本配置上的真实边界；
   - **轨道二（产业拐点与早期成长）天花板测算**：评估早期高成长或供需反转标的时，对照全球龙头验证商业模式终态盈利能力与行业集中度逻辑。
3. **动态更新**：仅在行业参照需要新增或删除时按需修订，不随季度财报批量刷新美股数字。

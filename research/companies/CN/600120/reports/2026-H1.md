信息截止：2026-08-30

# 1. 一句话结论

浙江东方是一家由信托、期货、人寿险、融资租赁、私募基金和大量金融资产组成的省属金融投资集团，2026年上半年利润翻倍主要是资本市场带来的投资收益和公允价值浮盈，而不是全部牌照经营同步翻倍；业务与隐藏资产值得持续跟踪，但普通股低ROE、投资收益波动、永续债和回购股拟出售意味着当前价格已接近甚至高于经审慎调整的资产价值。

# 2. 核心投资逻辑

1. 真正的价值基础是多金融牌照和净资产组合，而不是营业收入。截至6月末，信托资产2645.99亿元、公司金融资产管理规模3036.27亿元；浙商金汇信托、大地期货、东方嘉富人寿和国金租赁分别提供制度牌照、客户保证金与风险管理、长期保险资金和信用投放能力。
2. 2026H1盈利改善有真实成分，但周期性很强。上半年归母净利润8.77亿元、扣非8.42亿元，同比分别增长115.47%和114.68%；其中投资收益10.10亿元、公允价值变动收益3.52亿元，两项合计13.63亿元，已超过集团利润总额11.73亿元。
3. 二季度才是本轮利润跳升的主要发生期。半年累计减去一季度后，Q2营业总收入4.68亿元、归母7.24亿元、扣非7.02亿元、经营现金流16.97亿元；Q1的投资收益和公允价值变动分别仅2.38亿元和-0.01亿元，因此Q2大约实现7.72亿元投资收益和3.54亿元公允价值收益。
4. 四个核心牌照的经营方向改善，但对普通股利润的贡献需按持股比例还原。上半年信托、期货、保险和融资租赁分部净利分别为0.48、0.50、0.61和1.41亿元；上市公司持股比例分别为87.01%、100%、33.33%和70.981%，对普通股的按权益归属贡献远低于各子公司报表利润之和。
5. 公司拥有可量化的股权价值，但持股公司折价不能忽略。现有3.94%杭州联合银行股权，6月末账面价值16.96亿元；拟再以10.65元/股从控股股东购入4%，对价9.29亿元，尚待金融监管审批。永安期货股权6月末公允价值20.72亿元，但管理层已明确其与回购股都可能用于回笼资金，需考虑处置税费、折价与资本配置结果。

# 3. 商业模式与竞争优势

浙江东方的本质是控股型金融投资平台。信托收入来自资产服务信托、资产管理信托、财富销售和固有资产投资；期货收入来自经纪、风险管理、基差贸易、场外衍生品、资产管理和自有资金投资；保险同时承担负债端承保和资产端投资；融资租赁依靠资金利差、风险定价和资产周转；基金板块则依靠管理费、业绩报酬和自有资金投资回报。

可复核的竞争优势有三个。第一，信托、期货、保险、租赁与私募管理牌照的组合具有稀缺性，且背靠浙江省国资和长三角民营经济客户基础。第二，各牌照间已有信托产品、银保渠道、保险金信托、债券认购和医药设备租赁等协同，报告期新增协同项目30例、36.42亿元。第三，省属股东带来低成本融资和项目资源，合并加权融资成本为2.50%，同比下降41个基点。

这些优势还没有转化为高普通股回报。2025年归母ROE只有5.80%，2026H1年化ROE虽明显提升，却包含大量市场价格收益。牌照组合需要更多资本、风控和监管协调，各板块协同也容易变成关联资金循环；因此只有在不良率、寿险偿付能力、租赁回款、信托历史项目和普通股ROE上持续验证，综合金融优势才是真正的护城河。

# 4. 行业与竞争格局

信托行业仍在从通道和非标融资向资产服务、标准化资管和财富管理转型。浙商金汇信托上半年信托资产较2025年末增加380.75亿元，信托业务收入1.81亿元、同比增长45.03%，但利润总额只增长2.82%，说明新业务规模还未完全转化为利润率。信托行业的关键不是管理规模本身，而是管理费率、固有资产安全与历史风险项目压降。

期货行业的经纪佣金竞争激烈，差异化来自客户权益、风险管理品种、场外衍生品、资管和自营能力。大地期货上半年日均客户权益同比增长59.14%，风险管理销售额129.41亿元、增长77.08%，自有资金投资年化收益率9.82%。这些指标较强，但基差交易会将营收、存货、保证金与现金流同时放大，不能按传统商贸收入判断价值。

寿险行业在低利率环境下面临资产收益与负债成本匹配难题。东方嘉富人寿上半年总保费25亿元、同比增长11%，综合与核心偿付能力充足率为202%和101%，连续9个季度风险综合评级BB。负债端稳定，但利润受股债市场和保险合同计量影响较大。

融资租赁是目前最稳定的盈利板块。国金租赁6月末租赁资产137.94亿元，上半年收入3.54亿元、净利润1.41亿元，同比均增长44.44%，租金回笼率100%、拨备覆盖率284.21%。但租赁是杠杆业务，未来需要同时检验资产收益率、融资成本、城投与绿色项目集中度和真实不良。

# 5. 财务质量与股东现金收益

2023—2025年归母净利润分别为5.36、9.36和9.35亿元，扣非分别为5.14、2.60和7.91亿元；归母ROE分别为3.44%、5.99%和5.80%。会计政策调整使期货标准仓单交易从总额法改为净额法，2025年收入只有16.31亿元，与2023年162.11亿元不可直接比较；利润和净资产比营收更适合评价这家公司。

2026H1总资产667.69亿元、总负债459.82亿元、归母权益187.56亿元。归母权益中包含本期新发行的20亿元可续期公司债，分别是15亿元2.10%的“东方YZ01”和5亿元2.00%的“26东方Y2”。这部分属于其他权益工具，不属于普通股；扣除后普通股归属权益为167.56亿元。

# 6. 管理层、治理与资本配置

控股股东浙江省国际贸易集团持股41.14%，实际控制人为浙江省国资委。国资背景使公司在牌照、融资和省内项目上具有优势，也意味着普通股价值要服从国有金融平台的牌照补齐、产融协同和资本充足目标。董事长、总经理由王正甲一人兼任；这有利于战略执行，但提高了董事会制衡要求。

2025年年报获得标准无保留审计意见，内部控制审计未报告重大缺陷；2026H1也无控股股东非经营性占款或违规担保。但关联交易需持续审视：待审批的杭州联合银行4%股权来自控股股东，定价以经备案市场法评估为依据；评估的银行普通股全部权益232.21亿元，比不含60亿元永续债的账面净资产406.41亿元低42.86%。这个交易价本身比账面净资产保守，却也证明未上市银行股权不应直接按1倍净资产给予上市公司普通股。

资本配置的主线是“卖流动资产、补金融牌照”。公司拟出售永安期货股权和回购股，用于银行股权收购及后续重大项目；同时上半年新发20亿元可续期债，表面上降低资产负债率，却要先于普通股承担约2.0%—2.1%的年度资金成本。这一策略若能把低协同的上市股权换为稳定银行权益法利润，可改善收益质量；若持续增加杠杆和资本占用、而普通股ROE仍低于资本成本，则只是扩大资产而非创造价值。

# 7. 市场争议与隐含预期

乐观观点是，浙江东方已从传统商贸公司转型为多牌照金融投资平台，信托AUM、期货客户权益、寿险保费和租赁资产均在增长；杭州联合银行2025年净利润49.10亿元，现有3.94%持股可提供近似2亿元年度权益法收益，增持至7.94%后可提高稳定利润底盘。谨慎观点是，金融资产和基金投资造成利润与OCI大幅摆动，各牌照ROE并不高，持股架构、少数股东和永续债又稀释了对普通股的归属。

2026年8月28日收盘价4.94元，按外部流通33.47055891亿股计算的普通股市值约165.34亿元，与167.56亿元普通股账面权益接近，相当于约0.99倍当前外部股东口径PB。过去十二个月归母利润约14.05亿元，表观PE约11.8倍；但若用10—12亿元正常化普通股利润，当前价格隐含约13.8—16.5倍。

市场实际上在押注三件事：第一，H1资本市场收益的相当部分可持续；第二，杭州联合银行增持能通过权益法利润和协同改善ROE；第三，省属金融平台的牌照价值可以抵消持股公司折价。任何一项不成立，1倍PB都缺少安全边际。报告时点价格只用于解释隐含预期，不构成任何交易或资本配置指令。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实口径：6月末归母权益187.56亿元，减去20亿元可续期债后，普通股权益167.56亿元。总股本34.15381492亿股，回购专户6.8325601千万股，当前参与普通股经济权益的外部股数为33.47055891亿股。当前每股账面普通股权益约5.01元；考虑回购股出售后，完全稀释口径约4.91元。

正常化经营：2024和2025年归母净利润均约9.35亿元；H1删除3.52亿元公允价值变动收益并考虑税、少数股东与可续期债资金成本后，不宜把8.77亿元半年利润简单翻倍。结合信托、期货、保险、租赁按权益归属的经营利润，杭州联合银行现有持股权益收益、基金与自有金融资产的中周期回报，当前正常化归属普通股利润取10—12亿元。这对应普通股ROE约6.0%—7.2%，显著低于市场隐含的持续10%左右ROE。

方法一——调整净资产法，为核心方法。仧167.56亿元普通股净资产为起点，对重要板块单独定价：信托归属净资产约35.67亿元，按0.8—1.0倍PB；大地期货净资产14.85亿元，按1.0—1.2倍PB；保险归属净资产4.03亿元，按0.7—1.0倍PB；租赁归属净资产15.26亿元，按1.0—1.2倍PB。永安期货持股按8月28日市价机械更新约21.87亿元，再给予15%—25%处置、税费与大股东折价，取16.4—18.6亿元。现有杭州联合银行3.94%持股直接用本次评估10.65元/股定价，发9.15亿元，不用账面16.96亿元。扣除上述资产账面额后的其他净资产约60.1亿元，包含未上市基金、交易性资产、其他金融资产、商贸和总部净负债，按0.6—0.8倍账面价值。合计普通股权益价值约123—152亿元，除以当前外部股数对应约3.68—4.53元/股。

方法二——正常化权益利润法。对归属普通股正常化利润10—12亿元给11—13倍整体PE，低端反映低ROE、投资收益波动、历史信托项目和持股折价，高端反映省属牌照价值、租赁增长和银行权益收益，得到110—156亿元普通股价值，对应约3.29—4.66元/股。两种方法中枢差异约3%，调整净资产法更适合这种多牌照持股平台，利润法用来约束对牌照和账面资产的过度乐观。

综合两种方法，核心合理价值区间：3.7—4.6 元。待审批的银行4%股权未计入基准；若交割，9.29亿元现金与同等交易价值的银行股权互换不会自动创造经济价值，只有后续权益收益和协同超过资金成本时才构成上行。

# 9. 基准持有人回报模型输入

本次提交`annual_common_equity_irr_v1`五年模型，但不在公司研究中计算随价格变动的回报率。基准情形下，未来五年每股普通现金分配依次为0.09、0.095、0.10、0.105和0.11元，合计0.50元。起点是2025年已实施中期加年度0.084元/股分红，假设正常化普通股利润10—12亿元，分配率约30%并随普通股盈利小幅增长。回购股出售所收现金、会计利润、留存收益和市场回购均不视为持有人已收到的现金分配。

第五年末普通股每股终值为4.2—5.8元，并非复制当前合理价值。终值从当前完全稀释普通股净资产约4.91元/股出发，假设五年内普通股ROE约6%—7.5%、现金分配率约30%，留存增长使第五年末普通股净资产约6.0—6.3元/股；再按0.70—0.92倍终值PB，反映低ROE持股公司折价、牌照价值和届时的风险资产压降结果。终值用总股本34.15381492亿股的完全稀释口径，因公司已计划出售而非注销回购股；假设无额外普通股增发、可转债或股权激励稀释。未独立研究第三年末经营与估值状态，故不提交`year_3`。

# 11. 核心风险与证伪条件

1. 市场收益回撤。H1利润重度依赖股市、债市、商品期货和基金估值。若后续投资收益与公允价值收益回到2024—2025年低位，而牌照经营利润不能填补，正常化利润10—12亿元需下修。
2. 信托历史资产和责任风险。浙商金汇信托持有的三胞集团债权账面成本6.71亿元，已累计确认公允价值损失5.41亿元；另有信托计划交易对手违约诉讼。若历史项目再出现大额减值或受托责任，信托牌照价值将下降。
3. 金融杠杆和流动性风险。合并资产负债率68.87%，母公司现金远低于债务与待支付的银行股权款，永续债只是会计权益。若永安期货和回购股难以按合理价格变现，或信用利差上升，普通股分红和资本配置都会受限。
4. 少数股东和普通股归属风险。保险公司少数股东持股66.67%，租赁少数股东持股29.019%，信托少数股东持股12.99%。分部利润增长若主要归属少数股东，对上市公司普通股价值提升有限。
5. 租赁和商贸信用风险。国金租赁当前质量良好，但长期应收款123.52亿元；同时供应链、济海、乾睿等商贸子公司依赖借款、票据、信用证和担保。期末担保余额32.97亿元，全部指向资产负债率超过70%的对象，包含14亿元保险资本补充债担保。
6. 治理与资本配置风险。从控股股东购买银行股权、出售曾用于稳定股价的回购股、发行永续债和扩大管理资产可能同时发生。若资产规模增长而普通股ROE连续低于6%、分红率下降，则“综合金融协同”逻辑被证伪。

最重要的证伪条件是：未来四个季度剥离公允价值收益后的归属普通股利润明显低于10亿元年化水平，同时普通股ROE低于6%且母公司净债务继续增加。三者同时发生，将说明H1利润翻倍只是市场行情与扩表结果，而不是普通股结构性回报提升。

# 12. 最终判断

公司具备多牌照、省属金融平台、稳定租赁利润、增长的信托与期货业务，以及杭州联合银行和永安期货等可量化股权价值。这些变量使它值得持续维护，不应从覆盖中丢弃。

但H1利润翻倍的主体是投资收益和公允价值收益；普通股账面权益需先扣除20亿元可续期债，而杭州联合银行的官方市场法评估又比账面普通股净资产低42.86%。调整净资产与正常化权益利润两法给出核心合理价值3.7—4.6元/股，低于2026年8月28日4.94元收盘价。

已形成五年持有人回报模型：未来每股现金分配0.09、0.095、0.10、0.105、0.11元，第五年末普通股每股终值4.2—5.8元，终值按回购股出售后的完全稀释股数建模。上行来自牌照经营ROE提升、银行增持交割后权益收益超过资金成本和历史风险资产回收；下行来自市场收益回撤、信托减值、租赁/商贸信用损失和资本扩张。

最终去向：covered。持续覆盖的目的是核验多牌照与资产处置能否真正提高普通股ROE，而不是将H1投资浮盈外推为稳态利润。

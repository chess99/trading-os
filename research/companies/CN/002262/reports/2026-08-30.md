# 1. 一句话结论

恩华药业在麻醉、精神和神经专科形成了受控药品资质、产品矩阵和医院商业化网络，2026年上半年收入与扣非利润增长、二季度毛利率明显恢复，说明非集采新品正在部分覆盖集采损失；但经营现金流下降43%、研发资本化率提高，NH600001仍未获批，因此公司仍是具有创新期权的优质成熟CNS平台，而不是已经完成创新转型的高增长药企。

# 2. 核心投资逻辑

1. 真正的壁垒不是单个仿制药，而是长期聚焦中枢神经系统形成的受控药品合规资质、原料药—制剂一体化、专科销售网络和跨产品医学推广能力。麻醉与精神制剂仍是利润主体。
2. 2026年上半年麻醉类收入16.68亿元、增长2.08%，毛利率91.67%、提高0.87个百分点；精神类收入6.51亿元、增长4.88%，神经类2.22亿元、增长33.70%。羟考酮、瑞芬太尼、舒芬太尼、奥赛利定、阿芬太尼及BD产品的增长，初步覆盖集采成熟品种压力。
3. 二季度由半年累计减一季度得到收入16.08亿元、归母4.23亿元、扣非4.28亿元，分别同比增长约7.3%、5.9%和7.0%；单季毛利率约76.76%，高于上年同期约75.80%，也显著高于一季度70.97%。产品结构修复真实，但上半年综合毛利率仍同比下降约1.38个百分点。
4. 研发管线连续，但兑现仍早。NH600001已提交上市申请并通过注册现场核查，尚未取得生产批件；NHL35700于6月进入中国III期，NH302和NH130在8月取得临床许可，布瑞哌唑片仿制药在8月取得注册证。未获批创新药不进入基准利润。
5. 6月末剔除受限资金、借款和租赁负债后的净流动金融资产约36.1亿元，支持研发、资本开支和分红。8月完成281.516万股限制性股票注销，总股本降至10.12971423亿股；注销增厚每股口径，但幅度仅约0.28%。

# 3. 商业模式与竞争优势

公司主要收入来自高毛利工业制剂、低毛利医药商业、原料药及少量服务。2026年上半年工业收入26.97亿元、增长4.42%，毛利率83.29%；商业医药收入4.61亿元、增长17.20%，毛利率16.34%。工业贡献绝大部分经济利润，商业业务更多承担渠道和终端覆盖功能。商业收入占比由13.08%升至14.34%，是综合毛利率下降的重要结构因素。

分产品看，麻醉类收入16.68亿元，占收入51.83%，毛利率91.67%；精神类6.51亿元、毛利率76.54%；神经类2.22亿元、毛利率63.00%；原料药0.94亿元、毛利率48.40%。麻醉类毛利改善，精神和神经类毛利率分别下降3.76和6.77个百分点，说明增长中包含价格、代理品和产品结构变化，不能只按收入增速估值。

竞争优势有四层。第一，麻醉药品、精神药品和易制毒化学品的定点生产、储运、质量和安全监管构成准入壁垒。第二，公司核心品种拥有原料药到制剂的完整链条，降低对上游的依赖。第三，麻醉重症、精神神经、睡眠及院外零售团队覆盖医院、社区、民营医院、互联网医院、双通道药房和连锁药店，新产品可复用既有商业体系。第四，充裕金融资产使公司能在不依赖股权融资的情况下维持高研发投入。

这些优势并非垄断。集采、一致性评价和同类产品增加会压低成熟品种价格；创新药的临床成功、医保准入、医生接受和商业放量都存在不确定性。公司2026年上半年销售费用10.39亿元、增长7%，其中市场建设费用5.75亿元；高毛利同时依赖较重的学术推广和商业化投入。

客户集中度需要持续核验。上半年应收账款前五名合计10.74亿元，占期末应收与合同资产57.62%，其中前三名为国药、上药和重庆医药特殊药品分公司。强渠道有助于受控药品配送，但也使回款和渠道库存对现金流影响较大。

# 4. 行业与竞争格局

CNS需求具有长期性。精神卫生服务扩容、老龄化、抑郁焦虑和神经退行性疾病诊疗增加，为精神、神经和睡眠药物提供结构性需求。医院端的专科教育、患者依从性和受控药品供应能力，比普通慢病药更重要。

价格环境却持续承压。国家集采常态化，麻醉药品和第一类精神药品依法实行政府指导价。公司披露已纳入国家集采的主要产品包括利培酮、右美托咪定、奥氮平、氯氮平、西酞普兰、纳洛酮、拉考沙胺注射液等；部分省级集采涉及依托咪酯、齐拉西酮、丁螺环酮和戊乙奎醚。受控资质既提高进入门槛，也限制企业定价自由。

行业利润因此取决于产品结构，而非患者数量单边增长。成熟仿制品可能量增价降，差异化麻醉镇痛新品、创新精神药和专科代理品才能提高利润池。恩华目前处在旧现金牛仍强、新产品已开始贡献、创新药尚未完成接棒的阶段。

公司在CNS上市公司中具有稀缺聚焦度，但面对恒瑞、人福医药、京新药业、华海药业及跨国药企在不同细分品种的竞争。其优势在国内麻精受控资质和专科渠道，短板是创新产品尚无可验证的大规模商业收入，海外销售上半年仅0.07亿元。

# 6. 管理层、治理与资本配置

孙彭生、付卿、陈增良和杨自亮通过恩华投资及直接持股形成稳定控制。创始与管理层持股有利于长期投入，但公司仍需用关联交易、激励目标和现金配置验证外部普通股股东利益。半年报披露无控股股东非经营性资金占用和违规担保。

2024年限制性股票激励第二个解除限售期要求2025年剔除股份支付后的扣非利润较2023年增长不低于33%，实际仅增长4.72%，因此752名激励对象对应233.916万股及离职退休人员47.60万股在8月完成回购注销。考核未达标说明管理层早期增长目标不能作为估值假设；注销则清除了这部分回购义务和未来流通股。

财务总监李岗生因个人原因于8月辞任，公司聘任何竹子接任。公告没有披露财务报告争议或监管问题，当前不构成负面结论，但正值现金流下降和研发资本化上升，应持续观察会计政策、内控和信息披露是否保持一致。

资本配置整体稳健：净现金充足，研发、制剂和原料药产线持续投入，分红逐年提高；公司作为LP对德福基金的实际出资敞口仅0.20亿元。负面在于理财资产长期较大、TTM自由现金流偏低，若资金被投入低回报并购、基金或过度建设，而创新管线没有形成利润，净现金价值应打折。

贾汪分公司因安全隐患被罚49.17万元并已整改复核。金额不重大，但受控药品和化工生产的安全、GMP与精麻管理具有低频高损失属性；若类似问题重复发生，治理评价需要显著下调。

# 7. 市场争议与隐含预期

乐观观点认为，公司拥有国内稀缺的CNS专科网络和十亿元利润底盘，羟考酮、瑞芬太尼、舒芬太尼、奥赛利定等新品已覆盖集采损失，NH600001、NHL35700和NH102可推动创新转型，净现金还能支持研发和分红。谨慎观点认为，H1麻醉收入只增长2.08%，精神神经毛利下降，研发资本化率提高，创新药仍未商业化，而现金流和应收已经恶化。

8月28日收盘价22.04元，按注销后10.12971423亿股计算市值约223.26亿元，对应TTM归母PE约20.3倍、扣非PE约20.2倍，PB约2.66倍。剔除约36.1亿元净流动金融资产后，核心业务价值约187亿元，约为扣除金融收益后的正常化核心利润的17—19倍。

市场隐含未来成熟业务不再明显下滑、正常化利润恢复中个位数增长，并至少有部分新产品与管线成功。市场可能低估二季度产品结构恢复、神经类高增长和专科网络对新品的放大作用；也可能高估NH600001短期获批、把早期临床许可当成商业价值，并忽视现金转化与资本化研发风险。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实层：注销后总股本10.12971423亿股，剩余限制性股票已包含在总股本中，无需额外假设稀释；6月末归母净资产83.92亿元，按注销后股本BVPS约8.28元；净流动金融资产约36.1亿元。NH600001未获生产批件，布瑞哌唑为化药4类仿制药，NH302和NH130只是临床许可。

经营层：TTM归母10.98亿元、扣非11.04亿元。综合H1利润增长、Q2毛利恢复、集采压力、精神神经毛利下降、资本化研发和弱现金流，正常化普通股利润取11.2—12.8亿元；正常化股东自由现金流取7—9亿元，可持续ROE取13.5%—15.5%。未获批创新药只通过专科平台倍数体现有限期权，不直接加入利润。

方法一——正常化PE，为核心方法。11.2—12.8亿元利润给予18—20.5倍，对应普通股权益201.6—262.4亿元，按注销后股本约19.9—25.9元。倍数高于普通仿制药，反映CNS聚焦、受控资质、净现金和管线；低于成熟创新药平台，反映集采、资本化、现金转化和临床失败风险。

方法二——现金流与净资产交叉。以7—9亿元正常化股东自由现金流、约9%股权成本、3%长期增长和中个位数过渡增长粗略估值，再确认约28—31亿元真正剩余金融资产，得到约17—23元。该方法低于PE法，是因为TTM自由现金流仅4.21亿元且研发与营运资本仍需现金，不能把37亿元现金理财全额当作可分配冗余。

方法三——PB—ROE检查。BVPS约8.28元，正常化利润对应期末ROE约13.3%—15.3%；在高净现金、CNS壁垒与集采研发风险并存下取2.3—3.0倍PB，对应19.0—24.8元。PB中枢与PE中枢差异不足25%，用于约束估值上沿。

综合三种方法，核心合理价值区间：19.5—25.5元。保守情景约14—18元，要求成熟品种继续降价、现金流不恢复且创新审批延迟；较乐观情景约28—35元，要求NH600001商业化、NHL35700或NH102至少一项取得关键成功并使利润达到15—17亿元。创新药商业化上行在未验证前不进入核心区间。

# 11. 核心风险与证伪条件

1. 集采和价格风险。成熟麻醉、精神品种量增不足以抵消降价，会压低工业毛利和利润；精神神经毛利率已经下降。
2. 研发与资本化风险。临床失败、审批延迟或商业化不及预期会使高研发投入无法回收；更多研发进入开发支出和无形资产会推迟费用并带来减值。
3. 现金转换风险。H1应收、预付和存货增加，CFO下降43%。若滚动CFO连续两个完整报告期低于归母70%，且应收增速高于收入，利润质量优势被证伪。
4. 商业化风险。新品需要医院准入、医保支付和持续市场建设费用，收入增长可能伴随销售费用和渠道库存上升，无法转成高ROIC。
5. 合规与安全风险。受控药品生产、储运、销毁和化工安全任何重大违规都可能造成停产、资质、召回和声誉损失，影响远大于罚款。
6. 治理和资本配置风险。激励目标未达、财务负责人更替和大额理财需要持续审查；低回报并购、基金或建设会消耗净现金。

最重要证伪条件是：未来两至三个报告期成熟品种毛利持续下降、非集采新品不能覆盖利润损失，同时滚动经营现金流低于归母70%、研发资本化资产继续上升而核心创新项目延迟。三者并存将说明CNS专科网络没有转化为新的普通股现金收益。

# 12. 最终判断

报告时点价格为22.04元/股（腾讯行情，2026年8月28日收盘），按注销后股本市值约223.26亿元；核心合理价值区间为19.5—25.5元/股。已形成五年`return_model`：年度每股现金分配0.42、0.45、0.49、0.54、0.59元，第五年末终值24.5—31.0元，关键口径为注销后股本稳定、38%—40%分红率及第五年13.8—15.5亿元利润。

条件性上行来自NH600001获批放量、NHL35700或NH102取得关键成功，以及现金回款恢复。三个最重要正面变量是麻醉高毛利与二季度结构恢复、神经新品和CNS商业网络、约36亿元净流动金融资产。三个最重要负面变量是集采与精神神经毛利压力、现金流和营运资本恶化、研发资本化及创新不确定性。最重要证伪条件是成熟业务、现金转换和创新兑现同时低于基准。

最终去向：covered。恩华药业值得持续维护，因为其CNS专科平台能否承接创新药会显著改变长期价值；当前价格处于合理区间中部，既没有把创新药全部兑现，也已支付了明显高于普通仿制药的专科与管线溢价。

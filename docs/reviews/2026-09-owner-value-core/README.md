# 核心护城河池现行标准复核

本轮按 `owner-value-1.0` 对价值质量池中的 `core_moat` 层做方法与表达复核。范围共 34 家；宁德时代此前已经登记，本轮复核其余 33 家。

复核默认继承既有正式研究已经验收的事实、财报与来源底稿，不重复全量取证。只有长期商业判断或估值被关键事实缺口卡住时，才需要在后续重做中定向补查。本轮重点检查：

- 长期竞争机制是否真正落到单位利润、必要资本和普通股现金；
- 当前价值、未来终值和投资者愿付价格是否分开；
- 两种估值是否可复算、主次明确，关键资本成本、成长和资本回报有解释；
- 五年持有人模型是否与普通股权益桥、实际分配和第五年经营状态一致；
- 正文是否作出公司特定的取舍，而不是用旧目录、审计过程或风险清单代替判断。

# 恒瑞医药：研发平台值得拥有，但只有穿过全费用化和现金桥的管线才创造价值

信息截止：2026-08-30

## 一句话结论

恒瑞的长期拥有理由仍然成立：国内临床、注册、准入和销售网络能把新分子反复变成上市产品，GSK、BMS等交易又证明研发输出可以通过授权变现。但这个平台每年需要约90亿元以上研发现金，成熟肿瘤药和仿制药又在下滑；股东价值必须由新品收入、全费用化利润和可分配现金同时证明，不是由管线数量或最高里程碑额证明。按这一口径重建后，**核心合理价值区间：21.35—34.14 元**。报告时点47.32元已经要求代谢、ADC和多个后期资产以接近高端路径放量，同时高研发强度不再压低普通股现金；现有证据足以支持公司质量，不足以支持正向错价。

| 决定性问题 | 本次取舍 |
|---|---|
| 成熟业务下滑能否被抵消 | 可以，但基准要求瑞康曲妥珠单抗、艾玛昔替尼等已批新品先放量，再由瑞普泊肽、HRS-7535和后期ADC接力，不把所有项目同时成功当基准 |
| 当前全费用化盈利 | 约42—48亿元，而不是报表归母或旧稿50—60亿元；现金利息、公允价值和研发资本化都重新处理 |
| 主估值 | 十年普通股现金能力DCF，显式经过收入、研发现金、税、必要资本、分红、稀释和期末现金 |
| 辅助估值 | 成熟组合跑出价值+已批增量+代谢+ADC+其他后期资产+已签授权权益的资产群SOTP，不与主法相加 |
| 最大认知风险 | 公司有很多后期项目，但缺少单产品销售拆分；资产群放量及其对成熟业务的净抵消只能作区间估计 |

## 平台优势如何变成普通股现金

恒瑞的护城河不是某一个分子的独占期，而是一条重复运转的链条：靶点和分子发现→临床设计和入组→注册及生产→医保、进院和学术推广→国内销售或区域授权。公司已有26款国内获批的一类创新药、15个研发中心，上半年又有2款一类创新药、1款二类新药和4个新适应症获批，17项临床推进到III期、22项到II期。这些事实证明组织能力存在，但并不证明每个项目都能赚回资本。[1]

国内商业化是公司区别于纯研发企业的核心能力。瑞康曲妥珠单抗、艾玛昔替尼、夫那奇珠单抗和瑞卡西单抗进入医保后，能借助已有准入、医生覆盖和推广体系较快转化为销售。2026H1销售费用43.41亿元、同比下降1.10%，而非肿瘤创新药收入增长73.97%，说明渠道尚未因新品放量而失去效率。但销售费用仍约等于药品收入的31%，这不是低成本软件式扩张。[1]

平台价值也有清晰边界。单一创新药会受医保谈判、竞品、专利和安全性约束；成熟的吡咙替尼、阿帕替尼和硫培非格司亭已经表现出竞争或医保降价压力。海外终端销售尚小，价值主要通过首付款、周年付款、里程碑和分成回收；授权减少海外商业化资本，也同时让渡区域权益。BMS的152亿美元标题金额绝大部分仍依赖未来临床、注册和销售条件，不是现金或应收账款。[1][4]

最强的相反解释是，恒瑞同时拥有ADC、代谢、自免、心血管和神经后期资产，一个成功组合足以让收入和利润长期双位数增长。现有证据支持“组合可以抵消衰减”，却不支持“所有后期资产都达到重磅销售”。瑞康曲妥珠单抗已有三个国内适应症，SHR-A2009已申报NDA，瑞普泊肽减重NDA已受理，HRS-7535多项III期试验有积极顶线结果；另一面，同一ADC平台项目具有相关失败风险，代谢赛道还要面对疗效、胃肠道副作用、供应和价格竞争。[1]

## 成熟业务下滑与关键管线的抵消桥

2026H1药品销售139.48亿元，其中肿瘤创新药62.65亿元、同比只增2.58%，仿制药51.39亿元、下降16.07%；两者合计114.04亿元，是未来需被新品抵消的成熟收入主体。非肿瘤创新药25.45亿元、增长73.97%，已经构成真实第二曲线，但规模仍不足以单独承担全部抵消。[1]

下表是估值用的资产群商业化路径，不是公司指引。第五年收入是已采纳Base路径中的实际收入，不是概率乘销售峰值；已进入2026收入的部分只计后续增量。

这一桥对应第五年合并收入490—565亿元。低端表示成熟业务下际较快，已批新品和少数后期资产刚好抵消并带来约中单位数增长；高端要求代谢与ADC同时成为有规模收入。更早期的100多个产品和400余项试验不另加“平台溢价”；其价值只能在十年现金路径或稳态增长中出现一次。

## 财务质量：全费用化利润不是报表利润减一笔资本化研发

2026H1归母净利44.65亿元、扣非37.30亿元，经营现金19.87亿元。现金比利润差，主要因合同负债和经营应付减少、BMS首付款未到账，又有研发现金进入投资活动。因此单个半年CFO不能年金化，但它证明授权节奏和资本化会使利润与现金显著错配。[1]

本次先从税前利润复原经营口径，金额均为亿元：

| 2026H1全费用化桥 | 金额 | 处理 |
|---|---:|---|
| 报表利润总额 | 49.52 | 起点 |
| 减：公允价值收益 | -8.43 | 主要是Kailera上市重估，不是本期经营现金 |
| 减：资产处置收益 | -0.41 | 非持续药品经营 |
| 减：净现金利息 | -6.98 | 利息收入7.01、利息费用0.03；期末现金单独进入权益桥，所以经营利润不重复含利息 |
| 减：当期资本化研发 | -11.12 | 全部视为当期经济成本 |
| 加：前期资本化资产的当期摊销上限 | +0.91 | 报表无形资产摊销全部加回作上限；其中若含非研发资产，真实全费用化利润只会更低 |

这条桥的机械年化约41.3亿元。考虑下半年新品准入、收入季节性以及年化25—30亿元已签授权履约收入，当前全费用化、不含超额现金利息的正常化税后经营利润取42—48亿元。这个范围比旧稿50—60亿元低，主要是旧口径没有完整拆出现金利息，也没有把当期资本化、前期摊销和税后影响连成一条桥。

期末开发支出46.46亿元、无形资产33.17亿元，合计79.63亿元，是账面研发资产的宽口径上限，不是可分配现金，也不在SOTP中再按账面价值相加。管理层在III期或关键性临床后开始资本化；上半年资本化研发11.12亿元、结转无形资产13.44亿元、转损益0.31亿元。核心模型从未来每年普通股现金中全额扣除研发现金，因此不再因会计资本化增加利润，也不再因未来摊销重复扣减。[1]

## 估值：主法只有一条普通股现金路径

### 方法一（核心方法）：十年普通股现金能力DCF

第1—5年现金能力为50/58/67/77/87亿元至56/68/82/98/115亿元。第6—10年低端为97/106/114/121/127亿元，高端为132/147/160/171/180亿元。这一后半段要求代谢和ADC资产在第五年之后继续放量，也已全额扣除随规模提升的研发和商业化现金。

低端用9.6%股权成本和2.5%第十年后稳态增长，高端用8.8%和3.0%。股权成本由长期人民币无风险基准、市场系统风险与医保价格、研发失败、海外注册和信息透明度附加风险构成，不是个人目标回报。高端稳态增长仍显著低于前十年，意味着专利衰减和后续研发资本没有消失。

在第五年时点，第6—10年现金与第十年稳态值的业务权益现值为1,586.86—2,706.54亿元；加入已扣五年分红后的第五年超额现金517.86—615.80亿元，再除66.5亿股，得到独立第五年每股终值31.65—49.96元。把实际分配和该终值分别按对应股权成本折现，得当前21.35—34.14元/股。

**核心合理价值区间：21.35—34.14 元。**

终值现值占主法总值约93.7%—96.0%，是本报告最大模型风险，而不是可以忽略的技术细节。原因是公司当前分红极低，大量现金和研发回报只在第五年终值中归属给持有人。若现金长期不分配、被低回报投资吸收，或第6—10年现金未达预期，价值会向低端以下移动。

### 方法二（独立辅助方法）：资产群SOTP

辅助法不用平台PE配平DCF，而是把当前成熟组合和未进入当前稳态利润的增量资产分开。每个增量群均用上文的上市时点、第五年收入、终端现金率、后续研发和9.5%—11%折现约束；区间表示Base内可采纳路径，不是用主观成功概率乘峰值销售。

| SOTP部分 | 主要商业假设 | 当前普通股价值 |
|---|---|---:|
| 当前成熟药品组合跑出价值 | 剔除超额现金利息、已批增量的后续成长与未来授权；成熟产品收入下降、全额研发负担后有限寿命DCF | 700—880亿元 |
| 已批新品及新适应症的增量 | 第五年新增收入45—60亿元，税后现金率20%—24%，已进入当前收入的部分不再计值 | 140—210亿元 |
| 瑞普泊肽+HRS-7535代谢组合 | 第2—3年启动，第五年收入25—40亿元，峰值收入45—65亿元，现金率18%—22%，仅计公司保留权益 | 100—170亿元 |
| 后期ADC组合 | 第五年收入20—35亿元，现金率19%—23%，同平台失败和后续试验成本保留在资产群现金中 | 100—180亿元 |
| 其他NDA/III期资产组合 | 第五年收入15—25亿元，开发、生产和商业化成本全额扣除；早期数量不单列 | 80—130亿元 |
| 已签授权权益 | 只计已签项目的履约、阶段付款和分成，成熟年度现金8—14亿元；不计标题里程碑 | 100—170亿元 |
| 当前超额净现金 | 总现金387.34亿元，扣一年研发、营运、全球临床与已批回购储备；不含BMS未到款 | 270—285亿元 |
| 合计 | 除66.5亿完全稀释股 | 1,490—2,025亿元，即22.41—30.45元/股 |

资产群SOTP中枦约26.43元，主法中枦27.75元，相差约5%。差异主要来自主法允许第五年之后组合持续产生新现金，辅助法则对每个资产群使用有限商业寿命和更高的项目风险费。它们共享部分销售路径，不能互相证明输入正确；辅助法的价值是证明旧稿450—650亿元管线总值既缺商业化基础，又与平台利润重复，而不是为了机械配平主法。

2026年8月28日47.32元高于两法上限。价格可能在要求代谢和ADC收入超过Base高端、授权现金长期高于历史平滑水平，或研发现金增长明显慢于收入。这些是可能的路径，但尚不是已经证明的普通股现金。

## 基准持有人回报模型输入

未来五个完整年度一股持续持有人预算收到0.25、0.30、0.35、0.40、0.50元普通现金分红，合计1.80元。只计股东实际收到的普通或特别现金分红，不计会计利润、未分配现金、内部上划或用于员工持股的公开市场回购。按66.5亿完全稀释股，年度分配总额为16.63、19.95、23.28、26.60和33.25亿元，均低于当年低端现金能力，不依赖借债。

第五年末每股终值为31.65—49.96元。其中，第五年时点的持续经营业务权益为1,586.86—2,706.54亿元，来自第6—10年全费用化普通股现金及第10年后2.5%—3.0%稳态增长；第五年已扣分红的超额现金为517.86—615.80亿元。现金利息不在业务现金里重复，已分配现金也不在终值保留。终值是对第五年经营状态、后续现金和资本结构的独立估计，不复制当前21.35—34.14元价值。

模型不提交year_3。第三年瑞普泊肽、HRS-7535和多个ADC正处于上市与放量分化点，年度现金、保留权益和稳态研发负担没有足够独立端点；从第五年值插值反而会伪造精度。

母公司期末货币资金375.60亿元、未分配利润378.01亿元，近期分红不存在付款主体的法律或现金缺口。但长期分配仍取决于经营现金能力和资本配置意愿，不能因现金多就把账面现金和现金利息各计一次。[1]

## 情景、风险与改判条件

周期性弱路径是医院准入、医保上量或授权确认推迟1—3年，但关键临床数据、医生采用和研发生产率未受永久损伤；现金延迟而非消失。结构性不利路径则是成熟品下降后，瑞康、代谢和ADC无法形成替代收入，或每增加1元研发资本不能增加足够税后现金；此时应同时下调收入、利润、稳态增长和期末现金，不等待历史利润率自动回归。较乐观路径要求第五年收入超过565亿元、全费用化利润超过122亿元，同时研发现金不超过收入增量；这些事实出现前不进入核心区间。

最重要的风险如下：

1. **成熟产品衰减快于新品放量。** 肿瘤创新药已降至低单位数增长，仿制药双位数下滑。若新品增量不足以覆盖第五年45—65亿元衰减，平台优势不会自动变成股东价值。
2. **代谢与ADC的相关失败。** 瑞普泊肽、HRS-7535、SHR-A2009与其他ADC的疗效、安全性、生产、医保和供应可能不达预期；同技术平台项目不是完全独立期权。
3. **研发资本回报不足。** 诊断性经济研发资本从约250亿元增到353—384亿元。若获批、销售、授权现金和全费用化利润没有同步增长，高投入会成为永久损伤而非现金延迟。
4. **授权标题额与真实权益脱节。** 退权、终止、临床失败或销售门槛未达成会使后续付款消失；授权后不能按全球完整销售权再计一次。
5. **利润与现金质量。** 公允价值、首付款节奏、研发资本化、汇兑和合同负债可以让报表利润长期偏离可分配现金。
6. **海外注册、生产和合作执行。** 美国BLA曾因生产场地CGMP检查收到完整回复函，说明国内临床能力不会无摩擦地复制到全球。
7. **稀释和资本配置。** 回购股折价转给员工、新发H股或其他激励若未换来每股现金增长，总利润增长不会属于现有普通股。
8. **治理、合规和安全。** 销售推广、临床数据、生产质量、关联交易或研发会计的重大缺陷会同时推高资本成本并延误现金。

真正会改变判断的领先指标是：肿瘤创新药、非肿瘤创新药和仿制药的收入净抵消；瑞康、瑞普泊肽、HRS-7535和后期ADC的获批、准入、销售与安全性；全费用化税后利润与普通股现金能力；研发现金/收入和开发支出减值；已签授权的现金到账、履约、退权与分成；以及回购、激励和新股后的完全稀释股数。

最终维持covered，只表示恒瑞的研发与商业化平台值得持续维护研究。长期拥有价值、报告时点价格吸引力和可靠错价是三个问题：本次确认第一个，否定后两个。

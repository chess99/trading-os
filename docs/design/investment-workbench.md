# 价值投资研究工作台

## 定位与研究关系

工作台围绕“**慢变量持久化沉淀 + 快变量实时决策合成**”原则组织，服务 **A 股（全板块）+ 港股（港股通）+ 美股国内可投宽基 QDII ETF 与全球龙头参照** 的真实交易边界。研究结果留底首要服务于下游决策 AI 的快速调度，并向高层决策者呈现清晰、多维的商业与赔率线索；研究数量、更新频率与固定名单本身不构成目标。

| 板块 | 核心问题 | 留存成果（进 Git 慢变量） | 实时 / 即需层（不进 Git） |
|---|---|---|---|
| 个股研究 | 双轨视角下哪些企业值得深研；现金归属与商业天花板如何；四情景每股价值锚点在哪 | 双轨商业质量池、完整周期研报与模型、`decision_profile` / `scenarios` / `capital_return_profile` | 现价 IRR、港股通税后 IRR、四情景赔率比、A/H 实时比价 |
| 行业研究 | 供需与库存处于周期何阶段；利润与现金留在哪个环节；宏观变化如何传导；有无拐点机会 | 34 个中国行业完整报告、指标与结构化 `industryState`（`cycleStage`、`macroAlignment`、`inflectionCandidate`） | 日内新闻/订单跟踪、拐点信号即需排查 |
| 宏观与宽基 | 经营环境、信用利率与主要指数估值处于什么状态；如何影响 A/H 与国内纳指/标普 QDII 配置 | 跨市场环境与估值季度报告（`macroState`）、国内美股 QDII 名录及 25 家全球龙头参照表 | QDII 实时 IOPV 溢价核查、每日市场观察 |

中国基础行业和常设宏观主题按自然季度研究，季末主要数据披露后更新报告。结论延续时，列出本季度支持该判断的事实和仍需观察的问题。

三个板块双向检验：宏观解释需求和融资的共同约束，行业判断这些约束如何传到不同环节，公司提供实际经营和资本回报的证据。公司的订单、定价、库存或回款与行业判断背离时，研究者需要检查样本代表性、公司特有能力及原有行业解释；多个公司出现同类变化时，也应反查宏观假设。

跨层判断最终落实到销量、售价、成本、必要资本、融资或资金成本。宏观预测缺乏把握时，可以用有依据的情景检验行业和公司的承受力，继续形成对长期经济利益的判断。同一冲击在现金流、折现率或其他估值参数中的处理须相互一致。

个股流程保留初筛和完整深研。排期、校验、研报阅读属于执行环节。长期精选退出流程；公司之间的比较、机会成本和共同风险仍写入相关研究，不另设第三层名单。

## 行业研究的研究对象

优先按真实经济机制划界。白酒的不同价格带、动力电池与锂矿、晶圆制造与设备服务，可能需要分别研究；交易所一级分类只提供检索。上市公司之外的竞争者、进口、替代技术、渠道和客户均在必要范围内。

中国行业目录以[分类文件](../../research/industries/catalog.json)维护大类、主题及经济范围。大类只承担导航，基础报告围绕主题贯通产业链，分别解释各环节现状及利润分配。首轮覆盖中国经济与A股主要研究领域；宏观与跨行业专题独立发布，不重复占据行业位置。

地区按实际经营市场组织。中国行业研究纳入所有相关竞争者的中国业务，保留海外需求、进口成本和技术规则等外部驱动；美国、香港等地区的完整同业研究另行发布。中国研究与既有跨市场文章在阅读入口区分，历史版本保留当时范围与截止。

报告先解释行业为谁解决什么问题，各环节如何收费、投入资本并取得现金，再分别形成以下判断：

| 判断 | 需要解释的当前状态 |
|---|---|
| 需求 | 终端销量、渗透率、价格带和地域结构怎样变化，增长来自新增使用、替换还是政策提前释放；终端消费、渠道进货与公司出货分别核对。 |
| 供给与库存 | 有效产能、利用率、渠道和企业库存、在建项目及退出怎样变化，新增供给何时投产、旧供给为何难以退出。 |
| 盈利与现金 | 实现售价与成本如何变化，利润留在哪个环节，回款、必要投入和增量资本回报能否支持现金积累。 |
| 证券定价 | 相关证券价格已反映怎样的销量、利润和资本回报；估值采用何种盈利基准，周期顶部利润、负利润及资产构成怎样影响指标含义。 |

这四组变量可以处于不同阶段。IEA 记录2024年全球电动乘用车销量超过1,700万辆、同比增长超过25%，同年电芯制造产能超过3TWh、约为电动车和电池储能需求的三倍。需求扩张与供给压力并存，整车、电池和材料的利润仍需分别研究；名义产能与需求的比值也需要结合有效供给和技术、地域差异解释。[7][8]

选出决定结论的少数变量，沿“最终需求 → 供给与库存 → 实现价格和成本 → 利润与现金 → 再投资和退出”解释因果。对每项说明当前水平与变化、主要驱动及驱动的当期状态、传导方向和主要滞后，并区分上下游、竞争地位和地域差异。宏观变量按实际影响纳入：例如居民收入、信贷和购房交付怎样影响家电需求，原料、能源和汇率怎样影响不同厂商的成本与售价。图表和指标表与这条解释对应，数据缺口明确落到受限判断。

历史分析检验关键机制，至少包含一个不利时期及失败者、退出者；用当时可得证据解释为何形成预期、什么结果推翻过它。未来三至五年形成有依据的主要路径、替代解释和改判条件，区分库存修复、资本开支周期与长期竞争变化。行业下行先进入公司的销量、利润、资本投入、资金和普通股权益模型，检验恢复机制与永久损伤；个人要求的额外安全边际在投资决策层另行考虑，价值含义沿用[公司主规范](../../prompts/company/standard-deep-research.md#价值定义)。

成品应让读者复述最值得关注的变量、当前状态、变化原因、对不同环节和公司参数的传导，以及会改变判断的证据。明确哪类经营模式更有利、哪些共同风险值得检查，并收束下一次最重要的两三个问题。章节按论证需要组织，取证步骤和工具记录留在 `prompts/`、`playbooks/` 或临时目录。

固定覆盖以中国行业目录为准，额外专题按经济问题和认知缺口安排。旧 `research/industries/sectors/` 内容继续作为公司研究的内部框架，不自动取得正式行业报告身份。

## 宏观的适当边界

宏观层分别研究经营环境与证券定价。经营环境关注增长及名义需求、信用及资产负债表、利率通胀汇率、政策与制度；证券定价结合当前价格、正常化盈利、长期增长、资本成本和风险解释贵贱。宏观报告说明经济状态怎样改变盈利或资本成本，并与当前价格隐含的经营要求相互对照。

每个主题只保留能改变结论的少量变量，交代最新可得状态、主要驱动、传导滞后及受影响行业。CPI、PPI、M1、M2各自承担具体解释：价格下降可能来自需求或供给，货币增长还需结合融资结构及实际支出判断。序列变更需统一口径；M1自2025年1月扩入口径，人民银行已公布2024年可比回溯数据，跨期分析与历史信息集复盘分别处理。[4]

长期人口、技术与能源变化适合独立主题；短期库存和订单循环在行业报告中处理。康波等长波叙事可作历史假说，须与可检验机制、相反案例和样本不足一起阅读，不按固定年份预测资产拐点。BIS 对信用和地产金融周期的研究也不能直接替代股票周期分析。[3]

宏观报告按问题命名，例如“信用扩张怎样传到企业现金流”“美元资金成本对中国资产的传导”。每季完成跨市场环境综述与市场估值两项常设研究。综述只汇总决定性变化、相互矛盾的证据、受影响行业与需要重新检查的假设，不要求为每个市场给一个方向标签。

## 公司比较与慢快正交决策

单一的“5 年基准 IRR”无法承载高层投资决策：还需把公司放回宏观顺逆风、行业周期位置、商业质量等级、可预见性以及下行覆盖/上行赔率中进行综合对比。

为此系统严格实行**慢快正交解耦**：

1. **慢变量锚点持久化**：公司研究不得与写作当日股价耦合。每份完整报告除了保留 `value_range` 与基准 5 年模型，还进一步沉淀 `scenarios`（结构受损/周期偏弱/基准区间/较乐观四档每股价值锚点）与 `decision_profile`（轨道、估值方法分类、标准行业主题、质量/资本配置/可预见性/下行风险四维评定、共同风险暴露标签与可核验改判条件）。
2. **快变量运行态合成**：研究台（`dashboard/`）与下游 AI 决策副驾读取聚合的 `decision-index.json`，结合当前即时价格实时计算**上行空间、周期底下行空间、赔率比、港股通税后 IRR（20%/28% 分红税只扣分红不扣终值）**与多维决策视角过滤。当公司估值过贵时结论留存仓库，日后价格跌至理想赔率区间时即可立即浮现，不要求重做研报。

## 市场边界与交易制度差异

上市地、经营地域、融资币种、投资者准入渠道与税负分别记录。

- **A 股（主板/创业板/科创板/北交所）**：全板块覆盖；分清不同板块公司成长阶段与估值方法匹配（成熟现金牛分红模型 vs 成长期终态盈利能力矩阵 vs 周期成本曲线），关注股权再融资稀释、治理与政策传导；个人持股满一年分红税按 0% 处理。
- **港股（港股通口径）**：明确区分港币交易、人民币资产收益与美元利率资金面影响；A/H 双重上市发行人通过 [ah-southbound-bridge.json](../../research/markets/ah-southbound-bridge.json) 显式关联比价。港股通个人投资者H股及非居民红股默认按 20%、境内居民红筹按 28% 计提分红税（转让差价 0%）。
- **美股（国内宽基 QDII + 全球对标）**：无美股个股直接交易权限，已退役美股个股覆盖（归档见 `archive/retired-us-single-stocks/`）。美股资产仅保留**国内场内外纳指100 / 标普500 QDII ETF**（[qdii-catalog.json](../../research/macro/us-broad-etf/qdii-catalog.json)）的指数估值、汇率与场内溢价框架，同时保留 **25 家全球行业龙头**（[global-leaders.json](../../research/benchmarks/global-leaders.json)）作为 A/H 行业供需与技术终局的产业参照。

## 报告更新和存档

| 内容 | 更新方式 | 对外阅读方式 |
|---|---|---|
| 公司报告 | 沿用发行人 FY/Q1/H1/Q3 槽位；同周期重研按现行流程 | 最新周期优先，可读前期 |
| 行业、宏观正式报告 | 每季度发布常设主题的完整版本，重大变化可追加专题 | 主题默认最新，版本列表保留重要历史 |
| 指标定义、研究方法 | 同一文件持续修订，Git保留历史 | 明确标注“指标与方法”，与研究报告分开 |
| 日常观察、新闻摘要、自动日报 | 不入库 | 在对话或外部任务中消费 |
| 支撑报告的关键证据 | 报告目录中保存可分发的小型表格、数据说明与原始来源链接 | 随报告一起冻结，读者可复算 |
| 抓取缓存、原始大文件 | 临时目录或外部存储，遵守来源许可 | 不随日常观察积累进Git |

行业和宏观按实际发布日期保存各季度研究。稳定主题路径保持不变，正文使用 `reports/YYYY-MM-DD.md`。主题页由发布目录派生最近版本，避免再手写一份 `current.md`。同日实质更正使用 `YYYY-MM-DD-r2.md` 等独立版本，保留原判断和修正原因；最新版本被撤回时，主题显示撤回原因，读者可主动选择旧版本。

错字、格式与不改变论证的链接修复可原位修改。事实纠正若改变判断，应新发完整报告并交代旧判断为何变化；有错误的历史报告在发布目录标注撤回，不再作为最新结论。旧报告按当时已知资料阅读，不用事后修订数据悄悄替换当年的依据。

报告发布目录使用 `research/publications.json`，只登记面向读者的报告与参考文章。机器检查路径、日期、版本和明确状态，研究质量仍由完整阅读与证据核验判断。正文标题从文件读取，版本与摘要来自目录。详见[发布与阅读规则](../../research/README.md)。

## 数据与指标

采用“来源 → 口径 → 可复算指标 → 条件判断”的顺序。每项序列记录提供者、原始发布者、覆盖范围、单位、频率、观察日期、发布日期和数据版本。价格可比性、季度GDP年化、TTM利润、亏损公司处理、历史成分调整及复权方式须显式说明。

最小指标集合先考虑 PE/PB 与历史分位、盈利收益率减国债收益率、总市值/GDP及指数集中度；CAPE、隐含权益风险溢价等在数据与解释能力足够时再增加。历史分位明确窗口、采样频率、缺失处理和口径变化；默认并列五年与十年，不将五年当作完整周期的保证。

指标定义和市场差异的参考文章与当期宏观、估值报告分别发布。数据看板属于可再生视图；只有支撑正式报告的重要时点快照进入Git。历史分位必须来自完整且口径一致的序列；来源之间冲突或数据缺失时保留缺口，不拼接不同口径或从图形补出数值。

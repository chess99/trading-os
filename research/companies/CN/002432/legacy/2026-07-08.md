## 业务理解

九安医疗（Andon Health）成立于1995年，2010年深交所上市。公司核心业务分为三块：

**1. iHealth系列产品（海外家用医疗硬件）**
这是公司最核心、最有价值的业务。iHealth品牌主要面向美国市场，产品线包括：
- 新冠抗原家用自测试剂盒：2020-2022年疫情高峰期创造了历史性收入和利润（2022年收入达263亿元）
- 血压计、血糖仪、体温计等传统家用医疗硬件
- 其他OTC健康产品

iHealth系列产品收入已从2022年巅峰大幅下滑。根据同花顺F10数据，iHealth系列产品2024年营收22.50亿元，2025年仅披露了半年数据（无全年细分），但公司2025年总收入仅13.66亿元（同比下降47%），反映iHealth试剂盒收入已基本归零。

**2. ODM/OEM业务**
为国内外医疗健康品牌代工生产，包括传统硬件产品（血压计、血糖仪、体温计等）。这部分是公司的"老本行"，规模稳定但增速有限。

**3. 互联网医疗产品及服务（糖尿病照护）**
这是公司重点培育的新业务：
- 糖尿病诊疗照护"O+O"（Offline+Online）新模式
- 在中国和美国推动医疗服务闭环
- 2025年该业务收入约1.22亿元，占比8.93%
- 公司正在开发"AIoT糖尿病家庭医助"项目

**4. 金融投资业务（规模巨大）**
这是后疫情时代公司财务状况最重要但最被市场低估的特征。截至2025年末：
- 公司持有约73.6亿元交易性金融资产（股票/ETF/美债/基金）
- 另有约16.3亿元债权投资（持有至到期）
- 还有约33.3亿元货币资金
- 2025年公允价值变动收益21.14亿元、投资收益7.18亿元，合计28.32亿元
- 而公司同期营业收入仅13.66亿元，经营利润2.54亿元

换言之，2025年归母净利润22.67亿元中，金融投资收益贡献了主要部分（约28亿元公允价值变动和投资收益），经营主业实际是亏损或微利的。

已知证券投资组合（2025年报披露）：
- 小米集团（港交所）：期初6.51亿元 -> 期末7.23亿元（其他权益工具投资）
- 小鹏汽车（美股）：期初2.27亿元 -> 期末3.81亿元（交易性金融资产）
- QQQ（纳斯达克ETF）：期初10.36亿元 -> 期末14.66亿元
- SOXX（半导体ETF）：期初0.97亿元 -> 期末1.47亿元
- SPY（标普500 ETF）：期初11.23亿元 -> 期末16.31亿元
- 腾讯控股ADR + 港交所腾讯：合计期初约3.38亿元 -> 期末约4.13亿元
- 美国国债（三笔）：合计期初约3.37亿元 -> 期末约6.61亿元
- 加上其他投资，合计期初43.19亿元 -> 期末59.64亿元

**地区结构**：海外收入（美国为主）历史上占比极高（>95%疫情期间）。2025年客户一（新冠试剂盒客户）仍占42.68%收入，显示海外超大客户依赖严重。

**客户集中度**：2025年前五大客户合计占比67.1%（第一客户42.68%、第二8.33%、第三7.46%）。在疫情高峰期的2022年，前五大客户占比曾高达68%（第一客户45%对应当时约120亿收入）。客户集中风险较高。

## 行业与竞争格局

**家用医疗设备行业**：
- 全球家用医疗设备市场约300-400亿美元规模，增速5-8%
- 主要产品线：血压监测、血糖监测、体温监测、呼吸治疗等
- 行业特点：产品标准化、价格竞争激烈、渠道为王

**血糖监测（CGM/BGM）细分赛道**：
- 连续血糖监测（CGM）是增长最快领域，全球CGM市场约100亿美元，增速15-20%
- 德康（Dexcom）、雅培（Abbott Freestyle Libre）主导全球市场
- 中国CGM市场在三诺生物、鱼跃医疗等推动下快速增长
- 九安的糖尿病照护模式依赖于自己研发的血糖仪+App+远程医疗，缺乏底层技术壁垒，竞争优势不清晰

**抗原试剂盒赛道**：
- 已从疫情高峰急剧萎缩
- 辉瑞、雅培等巨头已退出或大幅缩减产能
- 九安iHealth的美国市场订单季节性极不确定

**行业阶段**：家用医疗是成熟消费品行业，增长不突出；CGM是高端增长赛道但九安非领导者；抗原试剂盒已过景气高点。

## 公司质量

**优势**：
1. **现金极度充裕**：账面货币资金33.3亿 + 交易性金融资产73.6亿 + 债权投资16.3亿 + 非流动资产中投资类大量资产，合计金融类资产超过150亿元，净现金超100亿元（剔除负债72.8亿元后）。资产负债率仅24.8%，几乎无有息负债净额。
2. **iHealth品牌在美国有一定认知度**：新冠期间建立的渠道和品牌价值有残余价值。
3. **管理层对股东回报较为重视**：2023年每10股派25元，2024年派3元，2025年派16.5元（2025年报已公告派发6.9亿元），持续分红；2023年回购10亿元（用于员工持股和注销）。
4. **公司积极布局科创投资**：参与阶跃星辰（AI大模型）、清智基金（AI高科技）、海河创投基金（国家创业投资引导基金）、海棠同慧基金（间接投资阶梯星辰）等，展现了一定的资本配置能力。

**劣势**：
1. **主业萎缩严重**：营收从2022年263亿元降至2025年13.66亿元（降幅95%），核心产品iHealth试剂盒失去疫情期间爆发需求后，尚无足够体量的替代产品。
2. **盈利能力严重依赖金融投资收益**：2025年公允价值变动+投资收益合计28.3亿元，已超过营业收入（13.66亿），主业经营利润仅2.54亿元。这与投资公司没有本质区别。
3. **研发投入与主业增速不匹配**：2025年研发费用3.24亿元（占营收23.7%），但研发成果转化为新产品收入尚不明显。
4. **管理费用大幅增长**：2025年管理费用4.75亿元（同比+17%），销售费用3.71亿元（同比-19%），费用结构需关注。
5. **财务总监为代职**：秦菲自2022年12月起代理财务总监，至今已超过3年未转正，治理上存在小瑕疵。
6. **公司创始人/董事长刘毅不直接持股**：通过石河子三和合伙持股25.06%，这种间接持股结构导致刘毅本身只拿107万年薪，缺乏直接经济利益绑定。

**护城河评估**：
- 品牌护城河：iHealth在美国有一定知名度，但正在快速消退
- 技术护城河：弱——血糖仪等产品技术门槛不高，CGM领域无显著突破
- 成本护城河：ODM业务规模边际萎缩，盈利能力不足
- 渠道护城河：疫情期间建立的美国渠道有留存价值，但需持续维护
- **整体：护城河窄且正在变浅**

## 增长驱动

1. **糖尿病照护"O+O"模式**：这是公司最值得期待的长期增长引擎。公司已在美国运营约一年，在中国也在推进。如果模式跑通，可从"卖设备"升级为"卖服务"，获得持续性收入。但2025年仅1.22亿收入，占比不足9%，且公司公告"未来该业务收入存在不确定性"，短期不构成主要增长来源。

2. **金融投资回报**：公司将利用巨额现金持续进行证券投资。2025年底批准了不超过100亿元证券投资额度，已使用约60亿元。但投资收益本质是波动的，2024年公允价值变动收益仅7.4亿元，2025年翻倍至21.1亿元主要受益于美股大牛市。市场回调时可能大幅缩水。

3. **iHealth新产品/新市场**：目前公司密集推进多个投资项目（AI、半导体、创业基金等），可能通过参股/孵化方式拓展新增长点。

4. **并购**：公司现金充裕，有并购能力，但管理层明确表示"非主业领域的收并购基本不会贸然尝试"。

5. **回购注销**：2023年回购10亿元（均价约36-38元），其中部分已注销，部分拟出售。2026年还可继续回购。此举对每股价值有正面作用。

**核心问题**：上述增长驱动中，最具确定性的只有金融投资和回购（但这些都是财务操作），真正经营层面的增长引擎（糖尿病照护）仍然太小、太早期。

   - 债权投资16.27亿（占6%）
   - 净资产220亿，资产负债率仅24.8%
   - 但存货仅2亿——远低于正常制造业水平，反映生产大幅收缩

6. **金融投资收益占利润比过高**：2025年公允价值变动收益21.14亿 + 投资收益7.18亿 = 28.32亿，而利润总额25.27亿——如果没有这些金融收益，公司将亏损约3亿元。

### 方法一：相对估值（PE/PB）

**当前估值**：
- PE(TTM)=12.1倍（基于2025年净利22.67亿）
- PE(2026Q1年化)=约20倍（基于2026Q1净利2.94亿*4）
- PB=1.36倍（基于净资产220亿）

但需调整：2025年22.67亿净利润中包含大量金融投资收益。

**正常化盈利假设**：
- 收入：假设iHealth稳定在10-15亿/年（ODM+品牌硬件），糖尿病照护增长至2亿/年 -> 合计12-17亿
- 毛利率维持60-65%，但费用（销售+管理+研发）仍需6-8亿/年
- 主业经营利润约1-3亿
- 金融投资收益：假设60亿投资组合年化收益5%（保守），即约3亿/年
- 合计正常化年利润约4-8亿

**正常化PE**：
- 当前市值为280亿 / 正常化利润4-8亿 = 35-70倍 PE
- 扣除净现金（100亿）后，EV=180亿 / 经营利润1-3亿 = 60-180倍 EV/OP

**结论**：相对估值显示当前股价对主业来说非常昂贵，支撑股价的是现金和投资组合价值。

## 情景分析

**乐观情景（概率~15%）**：
- 糖尿病照护模式在美国跑通，3年内收入达到5-10亿
- 美股维持牛市，证券投资组合年化回报8-10%
- 公司通过并购进入新的高增长领域
- 股价：65-90元

**基准情景（概率~55%）**：
- 主业维持10-15亿营收，糖尿病照护缓慢增长
- 金融投资组合年化回报4-6%
- 股价在40-55元区间波动
- 当前股价60元偏高

**悲观情景（概率~30%）**：
- iHealth海外需求进一步萎缩，营收降至8亿以下
- 美股大幅回调，投资组合亏损
- 管理层开始消耗现金储备
- 股价：25-35元

## 价格与仓位计划

基于资产价值的底线思路：

| 价格区间 | 操作 | 理由 |
|---------|------|------|
| <28元 | 重仓买入(5%) | 低于NAV折价30%+，安全边际充足 |

| >55元 | 不追高/减仓 | 概念炒作成分大 |

**当前操作**：**不买入**。当前60元价格已超出我们合理价值区间上限（45元），属于乐观情景才可支撑的价格，风险回报比不理想。

## 逻辑止损条件

- 金融投资组合发生重大亏损（单季公允价值变动亏损超5亿）
- 营收持续下滑至10亿以下且无明显止跌迹象
- 糖尿病照护业务被证伪或大幅延后
- 大股东大幅减持（石河子三和持股比例降至20%以下）
- 公司开始大幅消耗现金用于非核心投资/并购

## 关键风险

1. **估值风险（最重要）**：当前60元股价主要由市场对"科创投资+糖尿病AI"概念的炒作推动，2026年4月股价已从40元附近飙升至最高94.94元（距当前已回调约37%），仍远高于基本面支撑的合理区间。公司自己也发布了股票交易异常波动公告，提示"股票价格处于近年来历史高位，存在市场情绪过热、非理性炒作"。

2. **主业持续萎缩风险**：营收从263亿降至13.66亿，目前尚无清晰的止跌回升趋势。2026Q1营收3.01亿（同比-40.5%），下滑趋势未改。

3. **投资组合风险**：公司近60亿证券投资中，美股ETF（QQQ/SPY/SOXX）占大头，若美股牛市见顶，公允价值变动收益将大幅缩水，利润将骤降。

4. **大客户依赖风险**：2025年第一大客户占收入42.68%，主要来自新冠试剂盒尾单，一旦终止无替代订单。

5. **管理层专注度风险**：董事长身兼行业协会主席、大学院长等多种角色；公司投资涉足AI、半导体、汽车销售等，与主业关联度低。

6. **资产质量风险**：高额金融资产中的长期投资（握有至到期、基金LP份额等）流动性较差，退出路径不确定。

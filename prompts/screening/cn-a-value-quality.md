# 全 A 股价值质量池筛选规范

## 目标与隔离

以长期普通股所有者视角维护当前商业质量池，关注竞争优势、所有者现金和治理。池子回答哪些公司值得长期研究，不回答今天是否值得买。

- 唯一结果源为 `screening/cn-a/value-quality/pool.json`，只维护当前全量版本；历史通过 Git 查看。
- `current.md` 只能由命令确定性生成，禁止手改或另存日期化池。
- 不修改研究状态、研究队列、自选池、公司报告或研究日志，不创建研究任务。单公司研究也不得根据本池改变状态或结论。
- 可把正式公司报告当作普通参考，也可独立获取公开资料；研究状态、是否已有报告均不是入池条件。
- 证券身份参考嵌入池文件，独立获取，不从公司研究状态推导上市资格。不增设第二套研究状态系统、审批角色或证据账本。

## 分层与判断卡

`core_moat`（A）要求竞争优势已有跨周期或多年兑现记录、现金收益与普通股归属有依据、治理与资本配置风险可接受。必须说明现存反证为何尚未推翻核心资格。高毛利、高 ROE、龙头称号或单年现金好均不充分。

`quality_research`（B）要求存在可辨认且已商业化的优势，同时明确尚未解决的关键问题，如获客留存、技术代际、资本回报、普通股现金归属或治理。B 不是给所有成长故事的候补席；连优势本身都缺证据的公司暂不入池。

每家公司必须保存四项简短判断和 1—3 个公开来源，禁止用通用模板替代具体分析：

- `moat`：客户为何选择、竞争者为何难复制，优势落实到具体产品、网络或资产。
- `owner_cash`：经营成果如何转成普通股现金，必要投入、营运资金和权益结构的约束是什么。
- `risks`：最可能推翻优势或截留现金的反证。
- `tier_reason`：为何属于这一层；B 明确待验证问题，A 说明兑现记录和反证边界。
- `sources`：标题与公开 URL。优先定期报告、招股书及监管披露；应标明报告期间或发布日期，索引与分页入口如实标注。

来源是回查入口，并非逐句证据认证。执行者应读取支撑判断的经营与财务章节；只取到目录、首页或公告摘要不能声称已读全文。公司自述、公开事实与分析推断要分清；不能用本地报告路径代替公开来源。短上市历史不等于短经营历史，单品集中也不是自动否决，但必须记录例外依据与尚未验证的治理或复制风险。

可按需使用 `research/industries/` 的产业框架寻找材料与反例，但必须核验其资料截止和公司适用性，不根据公司研究状态派生池内资格。对子行业采用适合其经济学的尺度；比较毛利额、必要费用和资本回报，不能仅因毛利率不升否认价值创造，也不能因高毛利忽略投入。入 A 的关键是优势与普通股现金已由多年结果支持；对未知不作已证伪表述，待验证问题应具体且能够由后续事实检验。

## 商业判断与现金口径

逐家公司检验客户选择、复购、切换成本、网络密度、成本曲线、技术认证、牌照标准或稀缺资产，并追问行业停止增长后优势是否仍能创造高于资本成本的回报。规模、融资杠杆、普通牌照、补贴、商品高点与一次性收益不能单独证明护城河。

所有者现金检验须遵守：

1. 收入、利润、现金和资本支出的期间严格配对；缺年或缺项不得拿不同年份的分子分母凑比率。半年与全年分开，不能机械年化季节性现金。
2. 合并经营现金减资本支出仅是代理值。核对必要维护、增长投入、营运资金、租赁本金、非现金购建、受限资金、债务及少数股东；不能直接等同归母现金。
3. 联营利润需核实际分配与母公司可用资金；客户保证金、预收履约义务和财务公司成员存款不能当作可自由分配现金。
4. 银行和租赁看信用损失、监管资本留存、普通股权益与实际分配；保险看保险服务质量、资产负债匹配、偿付资本及可分配盈余。不得机械套用制造业现金公式。
5. 资源、公用事业、航空和基础设施须覆盖正常化商品周期、完整租赁及维护成本、特许期限、建设承诺、补贴和资本配置。
6. 好分部不足以证明好集团。检查跨业务投入、关联交易、稀释、收购和低回报资产是否持续消耗核心业务现金。

## 筛选与范围披露

1. 独立获取最新沪深北在市 A 股清单，分页、去重并核对总数，检查已知退市样本；停牌不等于退市。不得仅按简称含“退”或是否有成交排除。名称使用标准简称，不能带临时除权标记。
2. 在 `universe` 保存清单日期、来源和代码名称映射；数量由映射计算，不手填。遇到不同供应商范围冲突，先核对上市资格，不能把历史证券总表包装成当前全市场。
3. 整理商业描述、多年财务、资本强度、信用与治理信息。机械指标只发现异常，既不能自动入池，也不能决定人工能看哪些公司。
4. 质量分、候选门槛、排序与分层完全不使用证券价格、PE、PB 或收益率。旧的混合评分脚本必须先去除价格项、修复期间配对，才允许重新使用；旧分数不得作为本轮质量依据。
5. 反向遗漏检查覆盖品牌渠道、平台、金融、成本龙头、专业服务和长寿命资产。反向误入检查覆盖爆款、单一客户、周期高点、会计收益、并购和低回报扩张；同类公司采用一致尺度。
6. `review` 记录历史财务基线日期及总数、当前范围中缺该基线的代码、本版池成员及重点近邻的判断复看范围、实际工作深度和两类反向检查。必须说明哪些只是更新入口、哪些已重核财务；不得把身份清单完整或补齐判断卡写成全市场逐家深研完成。
7. 生成全量候选 JSON，经同一执行者语义自查后使用 `replace`。没有理由或来源不能入池；不足以判断时明确留在池外，不按目标人数增删。

未入选公司不需要建立逐家长期状态；重点近邻排除理由写在本版 `review`，具体变更可在提交说明或实施记录解释。工作底稿与抓取缓存留在临时目录。

## 维护约定

- 公司竞争、现金、治理或资本配置出现重要新事实时复看判断卡；不因证券价格或单季利润涨跌机械升降。
- 年报披露后复看全池判断；每半年结合新披露做一次行业反向遗漏与误入检查，优先补齐基线缺口及新上市公司的经营资料。
- B 升 A 需要未决问题获得持续证据；A 的现金兑现或治理确定性下降则降 B；优势不成立、普通股长期得不到现金或治理足以抵消优势则退出。
- 退出不表示永远否决；新事实解决反证后可重新入池。未充分证明的项目不要写成已证伪。
- 日常只维护本层判断，不复制公司研究的公告扫描、队列、状态机或自动调度。

## 禁止内容

池内不得保存现价、市值、证券估值或折溢价、价值区间、IRR、收益率门槛、仓位、交易建议、价格触发，以及研究状态、任务 ID、报告路径或 `return_model`。品牌溢价、产品售价、运价、贷款收益率等经营变量可以讨论，不能借此引入证券交易判断。


所有字段均必填，版本必须为整数 2。`baseline_count` 是历史基线总数，可能包含后来退市公司；缺口列表仅指当前证券范围中缺基线者，不能简单用两个总数相减。`reviewed_symbols` 在此表示本版判断复看范围，必须包括所有入池成员及重点近邻；实际材料深度由 `scope_note` 说明。

`tier` 只允许 `core_moat / quality_research`。`group` 只允许 `consumer_brand_network / healthcare_platform / technology_industrial / infrastructure_finance_resource`。代码唯一并与独立清单标准简称匹配，来源 1—3 个且 URL 不重复。允许空池，命令自动按层级、分组、代码排序。

```bash
python -m trading_os quality-pool replace --input <完整池.json>
python -m trading_os quality-pool validate
python -m trading_os quality-pool status
python -m trading_os quality-pool list --tier core_moat
python -m trading_os quality-pool rebuild
```

写入使用唯一临时文件和池级短写锁。JSON 原子替换是唯一提交点；Markdown 随后生成。如果投影写入失败，返回 `committed: true`、`projection_current: false` 和恢复提示，不能误报为名单未保存。此时 `status/list` 仍可读取 JSON，`rebuild` 只修复投影，`validate` 仍应报错直到一致。并发全量替换串行提交，后提交版本生效；维护者仍须避免不同草稿相互覆盖，提交前核对最新差异。

校验器检查合同、身份映射、显式禁用内容和投影一致性，不联网认证名单来源、上市资格或商业论据。独立身份参考自身必须由执行者核实；正则也不能替代语义判断。验收最后确认未改变公司研究层数据。

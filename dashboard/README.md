# Trading OS 可视化研究台

这是仓库研究资产的只读附属展示，不是 Trading OS 的主要产品。它不维护第二套研究状态，也不修改研究队列、自选池、研究日志或正式报告。

## 产品结构

- **赔率地图**：列出 active `covered` 公司，优先按实时价格对应的五年基准情景年化回报排序，同时保留现价与 `value_range` 的机械位置；
- **全市场状态表**：浏览全部公司的当前研究状态；
- **研报库**：搜索公司并阅读当前或历史正式报告。

`legacy/` 旧稿不会进入目录、排序或研报搜索。

## 价格展示边界

有合格 `return_model` 和实时行情时，默认排序使用研究模型的五年终值区间、五项逐年每股现金分配与现价现场求得的中枢 IRR。三年结果只在模型独立提供 `year_3` 终值区间时显示，并只使用前三项分配。`return_model_note` 解释模型口径；新研究无论能否可靠建立模型都必须填写。缺少模型、行情或无法求得有限解时显示 `—`。

`return_model` 是正式研究的结构化参数，页面只读取；实时价格和计算后的低、中枢、高 IRR 都不会写回仓库。页面仍机械展示：

```text
当前实时价格 / value_range.low
```

页面同时展示 `当前价格 / value_range 中枢` 和“低于区间下沿 / 区间内 / 高于区间上沿”的机械描述，作为合理价值位置的辅助信息。

这里没有概率、复核分数、关注价、深度复核价、收益率阈值、价格触发器、armed/hit/rearm、仓位或交易建议。基准情景年化回报与“低于区间下沿”都只是研究参数和实时价格的机械关系，不代表安全边际充分，也不授权资本投入。

## 行情策略

- 腾讯行情是实时价格主源；
- 腾讯缺失时使用东方财富备援；
- 两个外部源均不可用时显示 `—`。

行情不会写回仓库，也不会触发研究、修改研究状态或创建任务。仓库中没有可供回退的收盘价运行状态。

## 本地运行

在 `dashboard/` 目录执行：

```bash
npm install
npm run dev
```

启动和正式构建前会从仓库唯一事实源生成只读目录。`npm test` 会验证构建、页面和数据投影。

## Cloudflare Workers 部署

线上预览使用 Cloudflare Workers，不依赖 Sites。首次部署前先登录 Cloudflare，随后执行：

```bash
npx wrangler login
npm run deploy:dry-run
npm run deploy
```

构建产物中的 Worker 配置是唯一部署入口；行情 API 与页面由同一个 Worker 提供，研究数据仍在每次构建时从仓库事实源生成。

## 后续产品路线

可以继续增加公告变化收件箱、研究日志浏览、正式报告版本差异和个人筛选视图。它们都应继续读取现有仓库资产，不得反向引入第二套状态、组合动作或价格触发体系。

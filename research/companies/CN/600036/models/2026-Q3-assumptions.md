## 资本配置路径的取舍

核心支付比例为35/35/35/35/38/41/44/47/50/55/60/63/66/69/70%。第1年的现金对应2026盈利，后续现金为上一个盈利年度利润乘当年支付比例，避免把当年尚未形成的利润当作即期已收股息。

35%公开政策、33%至35%的实际提高、2025中期分红、资本目标与实际资本的余量，以及11月2日管理层对资本内生、适度RWA和持续提高股东回报的表述，支持随资本需求下降渐进提高。15年时间跨度及最终70%均为研究判断。公开资料不支持近期每年提高5个百分点，更不能确认具体提高年份。永久35%、只提高到50%均保留为竞争性治理路径。核心更相信长期资本配置会适应低增长，且没有把既有X作特别返还。若十年后仍无改善，应采用相应较低价值。

## 同一现金与普通股权益链

每年普通利润P=rK+sX，实际现金D=p×上一年P。K下一年为(1+g)K，X下一年为X+P−D−gK。故普通股总权益下一年恒等于本期权益+普通利润−实际现金。外部普通股融资为零。已支付现金不出现在终值本金中，永续与少数权益均已隔离。

期限结束后继续使用同一三变量关系，股利支付包含一个盈利年度的滞后。令V=aK+bX+cP，P为上年盈利，则

```
b = p*s / ((k-s)*(1+k) + p*s)
c = p*(1-b)/(1+k)
a = (b*(r-g) + c*r)/(k-g)
V = a*K + b*X + c*P
```

低端k=10.5%、r=10.5%、g=3%、p=70%、s=1.5%，a=0.897680764，b=0.095497954，c=0.572987722。第15年K=2,057,287.914、X=517,707.474、P=217,343.951，代入获得该时点终值，再与第1—15年现金折现至起点，除25,219.845601得到40.57790359元。独立验收可直接用这些数重算，不必运行模型。

仅将股权成本上移1个百分点，其他经营不变，得到34.9762—42.95元。仅把第15年后的经营资本ROE下降1个百分点，前15年冻结，得到38.9518—48.85元。这两个是诊断敏感性。完整永久损伤另改经营ROE、资本增长/密度、分配及终值，不能用孤立敏感性代替。

额外资本的系数约0.10明确体现持续低收益和迟缓分配的成本。这里没有声称本金按面值被计入，也没有把所有可依法提高分配的可能性都视作必然发生。总普通股资本的远期ROE由增长、现金滞后和分配共同决定。稳态X/K为

```
(r-g-p*r/(1+g)) / (g-s+p*s/(1+g))
```

低、高端分别约14.45%、27.17%，整体期初普通股ROE均约9.36%，满足滞后支付下g=[1−p/(1+g)]×ROE。不能将10.5%—11.5%的K回报与全部普通权益混淆。

## 付款母行与资本可行性

母行承担全部上市普通股派现。前5年母行普通利润取集团88.5%，依据Q3母行与集团普通利润比例。第6—10年逐步升至90%、91%、92%、93%、94%，第11年起95%，体现成熟子公司提高正常上划，集团利润不增加。无须向母行转移全部子公司权益。按母行份额逐年滚动权益和未分配利润，法定公积持续按母行净利润10%计提，永续票息加回只用于母行法定利润计提基数，一般风险准备余额随业务规模增长。这是准备需求代理，未把监管RWA当财政部1.5%风险资产基数。

集团及母行分别检查高级法12/13/15%的核心一级/一级/总资本研究缓冲，权重法10/11/13%，杠杆率5%。法定要求8.25/9.25/11.25%、杠杆4.375%，公司2026—2030规划10/11/13%分别在来源中。研究缓冲不冒称法定标准。账面到核心资本扣项按业务增长，AT1和二级资本随业务资本规模正常续作及补充，普通股ROE采用融资成本之后的口径。母行权重法二级资本与高级法分开，未将高级法附加拨备错误带到权重法。

三季度母行未独立披露杠杆分母，采用集团16,408,227乘母行/集团资产比例为代理。付款使用母行已披露现金等价物549,073及集团HQLA3,092,780、30日净流出1,717,944作量级约束。预测在正常客户存款和市场融资续作下使流动性随业务增长，付款后保留母行50%现金等价物及集团140%LCR研究缓冲。其含义是分配规模可由正常银行资金管理承受，未来母行现金余额及流动性路径仍是预算。没有把集团HQLA认定为母行随时可调用资金。

如当年利润池、资本或流动性容量小于拟分配额，生产函数会压低实际股利并增加X，再重算后续利润和权益。全部采用路径未触发减分红或普通股融资。核心15年母行高级法CET1最低约14.62%，权重法最低约12.04%，集团付款后LCR最低约175%。假定没有同时发生系统性资金市场冻结，该情形不能仅由年度模型排除。

终态继续核对母行。以母行获得95%集团普通利润、70%上年利润派现，低/高端母行普通资本相对K的稳定比率约0.9659/1.0732，母行高级法CET1约15.26%/17.05%，集团约16.78%/18.69%。子公司留存5%集团利润对应稳定子公司资本，既不凭空增加母行收益，也不要求将全部子公司盈利上划。持续10%法定公积及一般准备增长后，母行当期可分配利润仍大于计划现金，现有未分配利润不用耗尽。AT1/T2续作与现金工具不是普通股价值增量。

## 情景传导与验证

- 周期性弱路径从第1年起，集团和母行同步受损。前3年K回报降至9/9.5/10.8%，前2年业务增长降至2/3%，风险密度每年额外升1个百分点，之后恢复基本机制。可对应息差额外低约10bp、信用成本先升至约1.1%—1.2%再回落。成本不因收入下降同步大幅消失。资本缓冲吸收损失，次年股息跟随利润降低，永久损失为错失利润及较小业务基数。
- 结构性不利从第1年开始，K回报逐步降至6.5%—7.5%，业务增长降至2%，前4年风险密度累计上升4.5%左右，分红提高计划取消并限35%。这可对应负债优势收窄、NIM长期约1.55%—1.60%、费用率33%、信用成本约1%和收费低个位数增长。完整重算利润、母行利润池、资本、实际股息、低收益额外留存和尾部，没有自动恢复。
- 较好经营路径K回报提高约1个百分点，终态再增加约1.5个百分点，业务资本和核心分配时间表不变，依赖息差约1.85%—1.90%、信用成本约0.65%、净收费持续改善。它仍保留低收益额外资本和治理约束。

生产函数包含无增长全分红100元手算、5%增长及现金滞后100元手算、同一step的现金/权益守恒与非平凡三变量的一年Bellman验证。所有路径另以干净盈余剩余收益恒等式复算。辅助PB—ROE方法以当前47.5591元、整体稳态ROE9%—10%、增长3%、股权成本9.5%—10.5%得到38.05—51.22元，忽略过渡期的不同经营回报与现金时间。它与主法共享长期经济假设，不能独立验证资本配置判断。

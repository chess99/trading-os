# 赛伍技术（603212）初始深度研究：周期修复已出现，但还没到可以买确定性的价格

## 结论先行

赛伍技术是薄膜形态功能性高分子材料公司，核心能力是胶粘剂配方、树脂改性、界面复合和涂布工艺，历史优势在光伏背板，近年扩展到光伏胶膜、光伏运维材料、半导体/电气/交通运输工具材料（SET）和消费电子材料。我的结论是：**观察，不买入**。原因不是公司没有修复，而是当前修复仍处在“亏损显著收窄、Q2边际转正”的早期阶段，且估值已经反映一部分困境反转预期。

截至 2026-07-17，英为财情历史行情显示赛伍技术收盘价约 10.22 元；新浪盘中行情曾显示 2026-07-17 11:30 价 10.33 元、总市值约 45.19 亿元。行情源并非公司公告，按**置信度中**处理。以 2026Q1 归母权益 23.91 亿元估算，当前 PB 约 1.87-1.89 倍；公司仍未恢复稳定盈利，PE 不适合做主估值。

**投资决策**：观察。
**安全边际买入区**：8.0-8.6 元，对应约 1.46-1.57 倍 2026Q1 PB，要求 2026H2 继续盈利修复。
**合理价值区间**：8.8-12.5 元。
**减仓/回避区**：13.5 元以上，除非半年度/三季度财报证明光伏材料毛利率持续回正、SET 放量且经营现金流同步改善。

## 业务与商业模式

公司商业模式是把胶粘剂、薄膜、涂布和复合工艺组合成定制化功能材料，再卖给组件、电子、电气、交通和半导体客户。它不是单一化工品公司，更像材料解决方案公司；但收入端目前仍高度依赖光伏材料，尤其胶膜和背板，因此盈利弹性仍取决于光伏产业链价格秩序。

业务分为四类：

1. 光伏材料：背板、封装胶膜及新技术组件配套膜材。2025 年仍是收入主力，但毛利承压，是亏损核心来源。
2. SET 材料：半导体、电气、交通运输工具材料。2025 年增长较快，是公司从光伏周期里“长出第二曲线”的主要观察点。
3. 3C/消费电子材料：规模较小，当前不是估值主驱动。
4. 光伏运维材料与发电：规模较小，更多是补充业务。

## 行业判断

光伏装机量仍在高位，但中游材料不是最舒服的位置。2025 年中国新增光伏装机 317GW，说明终端需求不差；问题在于组件、胶膜、背板等环节供应过剩，价格压力沿产业链传导到材料企业。对赛伍技术而言，需求增长不能自动转化为利润增长，关键是产品结构、客户质量、成本曲线和行业出清速度。

胶膜环节竞争对手强、规模效应明显。福斯特是行业头部，海优新材、鹿山新材、天洋新材、斯威克等也参与竞争；背板/复合膜材料还会遇到明冠新材、激智科技等对手。赛伍技术的差异化产品如 Raybo Film 光转膜和非光伏 SET 业务，是它摆脱同质化价格战的关键，但这些产品需要用订单、毛利率和现金流验证，而不是只看技术叙事。

## 护城河

公司有三层护城河，但都不是绝对壁垒：

- 技术与产品积累：背板、胶膜、光转膜、SET 功能材料体现出平台化研发能力。官网和投资者记录均强调专利布局与差异化膜材。
- 客户验证门槛：光伏组件和汽车/电气/半导体材料都需要长期认证，供应商切换成本高于普通耗材。
- 海外与多基地能力：2025 年资料显示海外收入约 6.18-6.19 亿元，越南胶膜产能已经形成一定本地化供应能力；该点来自年报二次整理及公开资讯，**置信度中**。

但弱点同样明显：光伏材料毛利率在 2025 年为负，说明护城河抵挡不了行业大周期；公司规模小于福斯特，成本与议价能力未必占优；SET 和光转膜仍需证明能成为足够大的利润池。

## 增长路径

未来 2-3 年增长主要看三条线：

1. 光伏材料修复：若胶膜和背板价格企稳，叠加成本优化，2026 年利润可从低基数改善。2026H1 预告已显示明显减亏，Q2 转正是积极信号。
2. 差异化光伏膜材：Raybo Film 光转膜等若随 HJT、TOPCon、xBC 等新技术组件渗透提升，有机会拉高毛利率；但当前量价、客户集中度和持续性仍需更多财报证据。
3. 非光伏 SET 放量：2025 年 SET 收入约 6.85 亿元且毛利率为正，是最重要的结构改善点。若 2026-2027 年 SET 收入占比继续提升，公司的估值逻辑才可能从光伏周期股转向平台型材料公司。

## 财务质量

2025 年是低谷年：收入 26.22 亿元，归母净亏损 2.68 亿元，经营现金流约 0.68 亿元，减值对利润形成拖累。毛利率低和资产减值说明库存/固定资产/应收链条承压。

2026Q1 有改善但未完全转正：单季收入 6.03 亿元，归母亏损 1,153 万元；毛利率 9.77%，较 2025 年低位明显恢复；经营现金流仍为 -918 万元。2026H1 预告指向 Q2 盈利转正，但半年归母仍预计亏损 300-600 万元，扣非仍亏损 500-900 万元。

资产负债率约 39.94%，不算高；归母权益 23.91 亿元提供了一定账面安全垫。真正需要跟踪的是：毛利修复是否带来经营现金流改善，而不是只靠减值减少或费用节制让利润表变好看。

## 治理与股东

2026Q1 报告显示控股股东为苏州高新区泛洋科技发展有限公司，持股 26.51%；实际控制人为吴小平、吴平平夫妇，合计持有苏州泛洋 100% 股权。前十大股东中吴江东运创业投资有限公司持股 6.23%。公司 2025 年年报披露不存在控股股东及其他关联方非经营性占用资金、违规担保等重大治理问题。

治理风险主要不是明面违规，而是周期下行时资本开支、产能布局、客户信用和库存管理的执行质量。2025 年不分红合理，但也说明股东回报当前依赖股价修复而非现金分红。

## 竞争对手

1. 福斯特（603806）：光伏胶膜绝对龙头，规模、客户和成本优势强，是赛伍技术在胶膜业务上的主要标杆。
2. 海优新材（688680）：光伏胶膜竞争者，周期压力同样明显，适合作为行业景气敏感度对照。
3. 明冠新材（688560）：光伏背板和复合材料竞争者，与赛伍技术在背板/功能膜材料上有交集。
4. 鹿山新材（603051）：热熔胶膜、功能胶膜及光伏封装材料参与者，反映中小材料厂商的竞争压力。
5. 斯威克（私有/非独立上市主体，未核验最新主体状态）：光伏胶膜重要玩家，因公开可比财务有限，只作为产业竞争参照。

可比估值宜以 PB、PS 和正常化利润能力为主。当前赛伍技术仍亏损，直接用 PE 会失真；福斯特若维持盈利，理应享受更高质量溢价。赛伍技术只有在 SET 占比持续提高、光伏材料毛利率稳定转正后，才有资格向头部材料平台估值靠拢。

## 估值交叉验证

### 1. 相对估值：PB 主估

以 2026Q1 归母权益 23.91 亿元、总股本约 4.37 亿股估算，BVPS 约 5.47 元。周期亏损但资产负债率不高，合理 PB 区间给 1.6-2.2 倍：

- 1.6 倍 PB：约 8.8 元，对应只给账面资产和轻度修复。
- 1.9 倍 PB：约 10.4 元，接近 2026-07-17 市价，已反映 H1 减亏。
- 2.2 倍 PB：约 12.0 元，要求 Q3/Q4 证明持续盈利、毛利率和现金流同步改善。

相对估值给出的合理区间约 **8.8-12.0 元**。

### 2. 绝对估值：正常化利润能力

若行业回到中性状态，假设公司收入 28-32 亿元、净利率 2.0%-4.0%，正常化净利润约 0.56-1.28 亿元。由于业务仍有周期性，给 18-22 倍正常化 PE，则股权价值约 10.1-28.2 亿元，折合每股约 2.3-6.5 元。这一结果明显低于现价，说明若只看已证明的盈利能力，当前并不便宜。

但该方法低估了周期反转和 SET 放量期权。把 2027-2028 年 SET 成长、光转膜放量作为期权另加 15-25 亿元，对应每股约 3.4-5.7 元，则综合价值约 **5.7-12.2 元**。绝对估值提示：上行需要新业务兑现，否则现价缺乏厚安全垫。

### 3. 情景估值

- 悲观情景：光伏价格战持续，2026-2027 年仍微利或亏损，PB 回到 1.2-1.4 倍，价值约 6.6-7.7 元。
- 基准情景：2026H2 扭亏，2027 年净利 0.7-1.0 亿元，SET 占比继续提升，PB 1.7-2.2 倍，价值约 9.3-12.0 元。
- 乐观情景：光伏材料毛利率稳定两位数、SET 高增长、光转膜放量，2027 年净利 1.5 亿元以上，价值可到 14-18 元；该情景当前证据不足，**置信度低**。

三种方法交叉后，合理价值区间取 **8.8-12.5 元**，买入必须低于 8.6 元并看到经营改善证据。

## 风险

- 光伏胶膜/背板价格继续下行，毛利率重新转负。
- 组件客户降本压力继续向材料环节传导。
- SET 和光转膜放量低于预期，平台化叙事无法转化为利润。
- 存货、应收、固定资产或在建产能继续减值。
- 海外贸易壁垒、关税、客户本地化要求影响出口与海外产能利用率。
- 股东减持或市场风格变化压低亏损修复类公司的估值。

## 跟踪指标

1. 2026 半年度正式报告：归母/扣非是否落在预告上沿，Q2 毛利率和经营现金流是否同步改善。
2. 光伏材料毛利率：连续两个季度为正且高于 8% 才能确认基本修复。
3. SET 收入和毛利率：收入占比是否超过 30%，毛利率是否维持 10% 以上。
4. 存货跌价和信用减值：若仍大额计提，说明价格和客户质量未企稳。
5. 经营现金流：盈利修复必须落到现金流，单看利润表不够。
6. Raybo Film 光转膜订单：客户、量产规模、价格和毛利率需要公告或财报验证。
7. 行业价格：EVA/POE 胶膜、背板、组件价格是否企稳。

## 安全边际与操作计划

当前价格约 10.22-10.33 元处于合理区间中部，不是深度价值位置。我的操作计划：

- 8.0-8.6 元：若 2026H1/H2 财报确认 Q2 后继续盈利，可建立 2%-3% 观察仓。
- 8.6-10.5 元：只观察，除非 SET 放量和现金流改善同时出现。
- 10.5-12.5 元：等待三季报，已有修复预期，不追。
- 13.5 元以上：没有超预期财报前降低收益风险比评价。

最终判断：赛伍技术值得进入跟踪池，但当前更像“困境反转早期证据”而不是“确定性买点”。先等正式半年报和三季报验证，比急着为反转付钱更重要。

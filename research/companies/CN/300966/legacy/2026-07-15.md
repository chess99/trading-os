# 共同药业（300966）初始深度研究

日期：2026-07-15
结论：观察，不买入。
置信度：中。核心经营拐点正在出现，但当前价格已隐含高端 API 放量和利润率显著修复；在 2026 年中报未确认持续盈利能力之前，安全边际不足。

## 1. 结论先行

共同药业是 A 股少数专注甾体药物起始物料、中间体、原料药一体化的公司，主线是从 AD、BA、9-OH-AD 等上游起始物料向性激素、孕激素、皮质激素、熊去氧胆酸等更高附加值 API 延伸。公司 2025 年收入 6.06 亿元，同比增长 12.97%，但归母净利润 -0.73 亿元，主要受产品价格下降、新项目转固后折旧及利息费用、研发投入、减值等拖累。2026Q1 收入 1.62 亿元，同比增长 16.32%，归母净利润 319.85 万元，同比扭亏改善，但单季 ROE 仅 0.39%，利润恢复仍处早期。

我的判断是：这是一家“产能和技术储备有期权、财务兑现仍不足”的公司。若甾领药业高端 API 审批、国际认证和商业化放量顺利，公司利润中枢可能从 2025 年亏损修复到 2027-2028 年 6000 万-1.0 亿元区间；但在当前约 30 元/股附近的市场价格下，对应总市值约 34-36 亿元（按公开行情页 2026-07-15 附近报价推算，非交易所官方收盘价，置信度中），已经接近甚至超过乐观情景定价。合理观察区间为 14-20 元/股；只有跌入 10-14 元/股且中报验证改善时，才具备初始仓位安全边际。

## 3. 业务

公司主营甾体药物原料，产品覆盖三层：

1. 起始物料：AD、ADD、BA、9-OH-AD 等，是糖皮质激素、性激素、孕激素、胆酸类等下游药物的基础原料。
2. 中间体：性激素、孕激素、皮质激素及其他甾体中间体，产品矩阵超过百种。
3. 原料药：性激素系列、孕激素系列、非激素系列，重点包括地屈孕酮、熊去氧胆酸等高端 API 方向。

经营模式上，公司以直销为主，客户为境内外甾体药物生产厂商。2025 年前五大客户销售额 2.02 亿元，占收入 33.39%，集中度可控但仍需跟踪新增客户质量。公司 2025 年自产收入占比提高至 90.43%，境外收入增长 46.59%，这说明新产线释放和海外客户拓展已有收入端反映；问题在于成本、折旧、利息和产品价格压制了利润。

## 4. 行业

甾体药物用于抗炎、免疫抑制、生殖健康、危重症抢救、慢病管理等场景，需求具有医药刚需属性。行业并非高速新药赛道，而是“稳定需求 + 工艺降本 + 产品结构升级”的制造型赛道。中国是全球重要甾体原料药生产基地，但高附加值制剂和高端规范市场 API 仍有升级空间。

行业的核心变量不是总需求是否存在，而是：

- 上游植物甾醇、能源、环保成本波动；
- 起始物料和常规中间体价格竞争；
- 高端 API 审批、认证和客户导入速度；
- 产能利用率爬坡后，折旧和财务费用能否被更高毛利产品摊薄。

共同药业处在产业链中上游，商业模式更接近精细化工和原料药制造，不应按创新药估值。它的合理估值锚是“正常化利润 + 产能利用率 + 高端 API 成功概率”。

## 5. 护城河

护城河中等偏弱到中等，尚未达到强壁垒。

正面：

- 技术路线：公司掌握植物甾醇生物转化、酶催化、绿色合成等工艺，年报披露截至 2025 年末已申请专利 138 项、授权 82 项。
- 产业链一体化：从起始物料到中间体再到 API，有机会降低成本、提升质量一致性，并增强供应链稳定性。
- 客户基础：年报提及公司服务津药药业、仙琚制药、CHEMO、SUNPHARM 等国内外客户。
- 产能基础：共同生物 2700 吨/年产能，募投项目转固后具备规模化基础。

限制：

- 2025 年毛利率仅 13.77%，且同比下滑，说明工艺和规模优势尚未转化成强盈利能力。
- 行业仍处自由竞争阶段，普通起始物料和中间体存在价格竞争。
- 高端 API 需要审批、认证、客户审计和稳定订单，壁垒兑现滞后。

## 6. 增长路径

可验证增长来自三条线：

1. 产能利用率修复：2025 年生产量 1,951.89 吨，同比增长 64.05%；销量 1,106.857 吨，同比增长 26.78%；库存 556.42 吨，同比增长 24.21%。如果 2026 年销量继续追上生产，单位折旧和固定成本摊薄会改善毛利。
2. 产品结构升级：境外收入 2025 年同比增长 46.59%，毛利率 28.23%，明显高于境内 5.27%。海外与高端产品占比提升是利润率恢复的关键。
3. 甾领药业商业化：公司与华海药业相关方布局高端 API。2026 年 7 月 IR 记录称部分车间已投产、2026 年起逐步商业化放量，但审批进度、订单规模、毛利率均未给出量化数据，必须等中报和后续公告验证。

## 7. 财务质量

2025 年财务表现偏弱，2026Q1 边际改善但尚未证实持续性。

- 收入：2023-2025 年分别约 5.66 亿、5.37 亿、6.06 亿元，2025 年恢复增长。
- 利润：2023 年归母净利润 2300.5 万元，2024 年 -2759.1 万元，2025 年 -7335.9 万元；盈利波动显著。
- 毛利率：2025 年 13.77%，较 2024 年下降 5.90pct；境内业务毛利率仅 5.27%，说明低端产品竞争压力大。
- 费用：2025 年研发费用 6985.1 万元，占收入 11.52%；财务费用 4921.6 万元，同比增长 118.26%，是利润修复的重要阻力。
- 资产负债：2025 年末总资产 28.51 亿元、归母净资产 8.26 亿元；短期借款 2.30 亿元、长期借款 6.21 亿元；存货 4.74 亿元，占总资产 16.62%。2026Q1 存货进一步升至 4.87 亿元。
- 现金流：2025 年经营现金流转正至 4103.6 万元，但投资现金流 -1.66 亿元，仍处资本开支消化期。

关键判断：公司不是资产负债表濒危型，但“重资产 + 高财务费用 + 低毛利”组合意味着利润弹性必须靠高端产品和产能利用率兑现，否则净资产回报率难以覆盖资本成本。

## 8. 治理

公司实控人和管理层稳定。2026Q1 前十大股东中，系祖斌持股 31.72%，李明磊持股 11.91%，丹江口共同创新投资合伙企业持股 4.43%；系祖斌、丹江口共同创新、张欣为首发时一致行动人。浙江华海药业股份有限公司持股 1.74%，与公司高端 API 布局存在产业协同观察价值。

治理风险主要不在控制权，而在资本开支和战略执行：过去扩产已经带来折旧、利息和转固压力；若继续扩张但订单和毛利率未跟上，股东回报会被稀释。2025 年分红方案为每 10 股派 0.45 元，按扣除回购股份后的股本测算现金分红约 514 万元，力度有限但在亏损年度仍有回报姿态。

## 9. 竞争对手

1. 浙江仙琚制药（002332）：国内甾体激素制剂和原料药龙头之一，下游制剂能力强，品牌和医院端更强；共同药业更偏上游原料和中间体。
2. 津药药业（600488）：皮质激素原料药和制剂重要企业，是共同药业年报提及的下游客户/行业参与者；其优势在皮质激素品类积累和终端产品。
3. 赛托生物（300583）：同处甾体原料和中间体链条，业务相似度较高；行业价格竞争和产能利用率问题具有可比性。
4. 奥锐特（605116）：特色原料药和中间体企业，部分甾体类产品与共同药业存在交集；盈利能力通常更能体现高端特色原料药的估值锚。
5. 普洛药业（000739）：综合 API/CDMO 平台，不是纯甾体对标，但在客户认证、合规制造、CDMO 能力上是共同药业向高端制造升级的参照。

相对位置：共同药业的优势在甾体上游一体化和产能，短板在利润率、资产周转和下游制剂/终端能力。与仙琚、津药相比，它更像供应链平台；与赛托相比，它的高端 API 叙事更强；与奥锐特相比，它的当前盈利质量较弱。

## 10. 风险

- 产品价格风险：2025 年年报明确提到部分产品市场价格下降，毛利率同比下滑。
- 产能爬坡风险：募投项目转固后固定成本上升，若销量和价格不达预期，利润继续承压。
- 高端 API 审批与认证风险：甾领药业产品审批、FDA/CEP 等国际认证进度未量化，商业化收入节奏未核验。
- 存货风险：2026Q1 存货 4.87 亿元，若产品价格继续下降，存在跌价压力。
- 财务费用风险：2025 年财务费用 4921.6 万元，较 2024 年大幅增加；若利息资本化减少后费用继续高企，会吞噬经营改善。
- 客户与回款风险：2025 年末应收账款余额较高，年报提示部分下游客户回款周期延长。
- 估值风险：当前市值已按显著修复预期定价，一旦中报未延续 Q1 改善，估值回撤空间大。

## 11. 跟踪指标

必须跟踪：

- 2026H1 收入是否达到 3.2 亿元以上，归母净利润是否达到 1000 万元以上；
- 综合毛利率是否回到 16%-18%以上，境内业务毛利率是否修复；
- 存货是否从 4.8 亿元高位下降，存货周转是否改善；
- 财务费用单季是否低于 1200 万元并逐季下降；
- 甾领药业高端 API 审批、国际认证、正式订单和收入披露；
- 境外收入占比及毛利率是否继续维持高于境内；
- 经营现金流是否连续两个季度为正；
- 可转债转股、借款规模和资产抵押变化。

## 12. 估值

估值基准：总股本 115,281,113 股。当前市场价按 2026-07-15 附近公开行情约 30 元/股估算，对应市值约 34.6 亿元；该行情非交易所官方收盘价，未核验，置信度中。

### 12.1 相对估值

由于 2025 年亏损、2026Q1 年化净利润仅约 1280 万元，PE 当前失真，不能用静态 PE 支撑买入。用 PS 和正常化 PE 交叉：

- 保守 PS：成熟原料药制造且利润率低，给 2.0x 2025 收入，对应权益价值约 12.1 亿元，约 10.5 元/股。
- 基准 PS：若 2026 收入 7.0 亿、毛利率修复，给 2.5x 收入，对应约 17.5 亿元，约 15.2 元/股。
- 乐观 PS：若高端 API 放量明确，给 3.5x 2026 收入，对应约 24.5 亿元，约 21.3 元/股。

相对估值合理区间：约 13-21 元/股。

### 12.2 绝对估值

DCF 简化假设：

- 2026-2028 年收入分别为 7.0 亿、8.5 亿、10.0 亿元；
- 净利率从 2.5%、6.0%、8.0% 逐步修复；
- 自由现金流约等于净利润的 60%-80%，因仍需资本开支和营运资金；
- 折现率 11%，永续增长率 2.5%。

在该基准下，权益价值约 16-22 亿元，对应 14-19 元/股。若高端 API 放量导致 2028 年净利率达到 10%以上，DCF 上沿可接近 25-28 元/股；但这属于需要公告验证的乐观情形。

### 12.3 情景估值

- 熊市情景：收入停留 6.0-6.5 亿元，毛利率 13%-15%，净利润长期低于 2000 万元。合理市值 10-14 亿元，约 9-12 元/股。
- 基准情景：2026 年扭亏，2027 年净利润 5000-7000 万元，给予 25x 正常化 PE，合理市值 12.5-17.5 亿元；结合 PS，约 14-20 元/股。
- 牛市情景：2027-2028 年高端 API 商业化顺利，净利润 1.0-1.2 亿元，给予 28-32x PE，合理市值 28-38 亿元，约 24-33 元/股。

当前 30 元/股附近价格已经接近牛市情景，留给执行失误的空间很小。

## 13. 安全边际与操作计划

安全边际要求：只有在价格低于 14 元/股，或公司披露连续两个季度收入、毛利率、净利润和现金流同步改善后，才考虑小仓位。当前不买入。

建议：

- 10-14 元/股：若 2026H1 已确认盈利修复，可建 1%-2% 观察仓。
- 14-20 元/股：只观察，不追高；等待高端 API 订单和毛利率证据。
- 26 元/股以上：若无明确利润上修，不应新增；已有仓位应减仓或等待兑现。
- 30 元/股以上：需要牛市情景支撑，若中报低于预期应规避。

最终评级：watch。投资决策：观察，不买入。

# 市场估值：盈利、利率与历史位置

市场估值帮助判断价格已经包含了多少乐观或悲观预期。结论需要同时考虑盈利基准、行业组成、资金成本与股东现金归属。便宜的历史位置可以持续很久，盈利下行也可能让表面低估值消失。

## 股债比较先统一符号与单位

采用直观的“盈利收益率利差”：

**盈利收益率利差＝1 / PE − 同币种长期国债收益率。**

PE为倍数，两边收益率都先写成小数。假设PE为20倍、国债收益率为3%，则盈利收益率为5%，利差为2个百分点。也可以将差值乘100，以“百分点”展示；不能把3直接与0.05相减。

有些资料使用相反符号，即国债收益率减盈利收益率。这时越低代表股票账面盈利相对债券利息越高。两种写法描述同一关系，历史序列必须保留相同方向。原始利差与经过排序的“股债性价比分位”也要分开：2个百分点和20%历史分位是两种量。[1]

盈利收益率是会计利润相对于价格的比率，利润还要支付必要再投资，部分收益可能无法分配给普通股。国债收益率则有期限、币种和信用条件。因此利差既不等于未来股票超额收益，也不等于通过现金流模型推导出的隐含权益风险溢价。

使用TTM、预测或正常化利润会得到不同结果。总利润非正时PE不具有同样意义，保留缺失或另外分析亏损结构。指数盈利收益率应遵循指数提供者的汇总算法；简单平均个股PE的倒数通常无法重建指数口径。

## 估值百分位衡量历史位置

本工作台采用明确的经验分位定义：历史有效样本中低于当前值的数量，加上等于当前值数量的一半，再除以有效样本总数。历史窗口截止当前观察日前一日，避免把当前观测重复放入参照样本。

例如历史样本为10、15、20、25倍，当前为20倍，则分位为(2＋0.5)/4＝62.5%。其他提供者可能采用不同排名或插值方法，比较时应读清定义。

解释一个百分位至少需要知道：

- 比较对象与估值指标，使用滚动利润、预测利润还是净资产。
- 时间窗口与采样频率，例如五年或十年的月末值；两者并列可以识别窗口敏感性。
- 有效样本数、缺失和非正利润的处理。删除亏损期可能让历史分布显得更稳定。
- 行业构成、会计准则、指数调样与权重是否改变；采用历史成分序列还是把当前成分回填。
- 原始数据是当时版本还是事后修订。历史判断须尽可能恢复当时可获得的信息。[2]

低百分位说明相对该样本的定价位置。增长、利率、监管或竞争格局发生变化后，历史中枢也会变化。五年未必覆盖完整周期；更长窗口也未必具有更好的经济可比性。

## 总市值与GDP的比较范围

总市值/GDP通常被称为巴菲特指标。分子是某一时点的权益价格存量，分母是一定期间的经济增加值流量；用途是观察长期比例关系。应明确总市值或流通市值、上市企业覆盖、名义GDP期间、币种和汇率时点。

A股上市范围随IPO、退市和产业结构改变，中国企业还有港股、美股等上市证券。多地上市和股份类别的总市值不能简单相加。美国上市公司的海外经营，与美国境内GDP也有范围差异。港股包含大量境外经营主体，香港本地GDP难以代表其利润来源。三个市场之间共用70%、100%之类阈值，缺少一致的经济基础。

季度GDP如果是季调年率，不能再机械乘四；如果采用过去四季名义GDP，则应记录每季数据的发布日期。观察日尚未公布的GDP不能提前用于历史回测。[2]

## 多个估值视角交叉检验

| 视角 | 能帮助理解的内容 | 主要限制 |
|---|---|---|
| PE及盈利收益率 | 为现有或预期利润支付的价格 | 周期利润高点、亏损排除、一次性项目、不同汇总算法 |
| PB与ROE | 账面资本定价与持续回报的关系 | 资产减值、无形资产费用化、回购改变净资产 |
| 股息及净回购 | 实际返还股东的现金与股数变化 | 分红可持续性、融资回购、员工股权稀释 |
| 正常化利润与CAPE | 平滑暂时盈利波动 | 会计、利润率及行业结构变化；CAPE通常采用十年实际盈利均值 |
| 盈利收益率利差 | 当前利率环境中的相对定价 | 期限与现金流风险不同，利差不能锁定 |
| 总市值/GDP | 股票市场价格与经济规模的长期关系 | 上市覆盖、海外收入、重复上市与数据修订 |

指数集中度和行业权重与估值一起阅读。少数大公司变化可能驱动整体倍数；等权与市值加权结果可能不同。用于比较指数投资时，还要区分价格指数和包含分红的总回报指数。

本页定义研究口径，不提供当期市场读数。任何实际估值结论都需附观察日期、来源、覆盖范围及可复算输入。

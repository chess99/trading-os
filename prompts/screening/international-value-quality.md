# 港美股商业质量筛选

## 研究目的

从长期普通股所有者角度识别值得持续研究的企业。优先考虑可理解的客户价值、持续竞争优势、合理必要资本、现金归属和管理层资本纪律。第一层采用经营机制与关键指标初筛；完整经营预测、估值与公司报告属于公司研究层。

质量判断沿用 [A股规范](cn-a-value-quality.md) 的A/B定义与普通股现金纪律。指标用于揭示矛盾和验证经营判断，不以单一ROE、毛利率、增长率或机械评分决定入选；证券价格和证券估值不参与质量分层。

## 候选范围与取舍

从主要行业中的成熟企业和可辨认商业化优势出发，参考大型指数并补充专业服务、细分工业与医疗等指数外企业。覆盖消费品牌、渠道、网络平台、金融、工业、医疗与长寿命资产，避免只挑熟悉的少数大公司。

对范围内候选明确给出入选或未纳入理由，逐项记录关键问题。未纳入可源于优势不足、现金归属不清、结构转型过重或证据不足；不得以未读材料暗示企业已被证明低质。同业采用相同标准，比较优势机制、必要资本与周期暴露。

- A · 核心护城河：优势与普通股现金具有多年兑现支持，说明现存反证的边界。
- B · 质量研究：优势已经商业化，同时存在影响长期现金或治理的决定性问题；写清需要验证的事实。

初筛可使用公开财务摘要、标准化财务指标和经营描述。对入选核心企业补查多年资本效率，对决定性争议查原始披露。只有读到相关章节才能声称核查该章节；摘要、数据服务和完整年报分开标注。记录实际财务期间、数据访问日与来源，明确标准化数据与公司自定义指标的区别。

## 现金与资本口径

1. 非金融企业先看多年经营质量、资本回报、现金转换和债务；FCF通常只是经营现金减购建的代理，仍需核租赁、股权激励、营运资金和必要留存。
2. 大额回购会缩小权益，净现金会缩小投入资本，负权益和极高ROIC不直接代表新增项目效率。并购商誉与新增资本不能从回报评价中随意移除。
3. 银行看普通股回报、信用损失与监管资本；保险看承保或保单兑现、自由盈余与子公司上划，不用工业企业FCF率进行排名。
4. 公用资产投资公司须穿透权益法利润、项目债务和实际股利；合并收入无法代表所有被投资资产，不能机械计算全组合FCF率。
5. 半导体、云与制造须计足研发、设备和融资租赁；资源须扣储量接续及弃置；地产与零售须区分重估、库存结算和维持资本。
6. TTM、财年、自然年与单季分别标识，不混用币种或期间计算比率。不把供应商口径的差异解释为确定的商业差异。

## 数据合同

港股与美股分别保存于 `screening/hk/value-quality/pool.json`、`screening/us/value-quality/pool.json`。JSON为唯一结果源，`current.md`由命令生成，历史由Git保存。筛选事务不修改研究状态、队列、报告或持有人模型。

v3向下兼容A股v2数据。基础公司字段保持四项判断、行业、分层、分组和1—3个公开来源，v3增加：

- `issuer`：发行人身份。A/H等不同证券共用同一标识，全部市场按发行人合并计数；单一市场仍保留证券身份。US代码表示上市市场，可包括海外发行人。
- `research_question`：影响长期判断的首要研究问题。
- `metrics`：核对日期、口径、1—6个指标、年度历史和口径说明。每项指标保存名称、值、实际期间及对应的来源序号；年度历史另绑定来源。缺失值不填零，不能制造不可比指标。
- `review.exclusions`：当前范围内未纳入证券及具体理由，与入选公司互斥且完整覆盖 `reviewed_symbols`。

`universe.securities`保存实际候选身份范围，不代表所有上市证券；`baseline_count`记录取得财务基线的条目数，缺口列入 `missing_baseline_symbols`。来源包含公开数据服务时应明确访问日期；不将标准化快照表述为逐家公司完整审计或深研。

```bash
python -m trading_os quality-pool --market hk status
python -m trading_os quality-pool --market us validate
python -m trading_os quality-pool --market hk replace --input <完整池.json>
python -m trading_os quality-pool --market us rebuild
```

默认市场为 `cn-a`。原子写入、锁与投影恢复沿用既有机制；机械校验验证合同和关联，不替代商业判断。

## 产品展示

公司池提供市场、行业、层级和关键问题检索，列表支持横向比较，详情提供指标期间、年度记录、判断与来源。入选理由与关键问题优先于长篇方法说明，范围和口径放入可展开区域。

产品内容服务研究者的比较与阅读任务。资料时点、范围与重要限制应明确；聊天约定、模型身份、执行步骤和交付汇报留在对话。判断直接陈述依据和结论，避免预设读者持有相反观点。

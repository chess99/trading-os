# 1. 一句话结论

国药一致是国药体系内两广医药分销与全国国大药房的上市平台，分销牌照、仓配和信用仍能产生低波动利润，2026年二季度利润和经营现金流也较一季度改善；但零售毛利继续下降、联营工业收益转弱、应收占用和低ROE尚未改变，因此低PB主要是经营回报偏低的结果，而不是未经识别的高质量净现金。

# 2. 核心投资逻辑

1. 分销是价值底盘。2026年上半年分销板块收入265.39亿元、净利润4.60亿元，分别同比下降0.91%和4.56%；公司在广东21个、广西14个地级以上城市全覆盖，国药体系品种、合规信用、冷链和医院仓配形成真实壁垒，但医药批发毛利率只有5.70%，并不具备高定价权。
2. 零售仍是待修复资产。国大药房收入102.27亿元、净利润0.13亿元；行业披露口径的零售收入113.12亿元、毛利率19.35%，同比下降2.65个百分点。关店和费用收缩令业务避免亏损，却尚未证明全国网络能稳定产生高于资本成本的回报。
3. 上半年利润质量尚可但增速偏弱。归母6.06亿元、扣非5.99亿元，非经常损益仅0.07亿元；累计减一季度后，二季度收入184.43亿元、归母3.19亿元、扣非3.19亿元，均较一季度改善，但仍未建立利润增长趋势。
4. 现金流下降主要是主动减少供应商融资，不等于经营崩塌。供应商融资相关负债由年初40.49亿元降至27.80亿元，H1经营现金流-15.19亿元；Q2由累计相减已转正14.17亿元。不过，应收账款账面价值227.71亿元，占总资产47.27%，长期回款风险仍是普通股价值的核心约束。
5. 公司还拥有国药现代、国药致君、致君坪山和万乐药业等联营工业权益，H1权益法投资收益1.24亿元、同比下降30.90%。这些资产提高业务质量，也会随制药行业周期和政策波动。

# 3. 商业模式与竞争优势

分销业务从制药和器械企业采购，通过两广物流中心、配送中心、冷链和信息系统向医院、基层医疗、药店及其他分销商供货，并提供院内物流、库存管理、创新药准入和专业药房服务。收入规模大、毛利薄，经济价值来自周转、供应商账期、回款控制与合规服务，而不是药品本身的品牌利润。

竞争优势主要是国药集团信用和品种资源、两广全覆盖的仓配网络、医院端长期履约记录以及特殊药品、冷链、港澳药械通等资质。上半年国谈产品销售增长23%，港澳药械通品种数量增长53%，两广专业药房增至160家，双通道品种销售增长，说明公司仍能在低增长行业中获得结构性增量。壁垒的边界也明确：集采、医保控费、DRG/DIP和医院资金压力会将降价与账期传导给分销商，规模未转化为高利润率。

国大药房覆盖18个省区市，6月底有7975家门店，其中直营6562家、加盟1413家；6107家直营店具有各类医保定点资格，双通道279家、医保统筹4032家。统采和自有商品占比提升、直营DTP销售增长26%，但DTP毛利率偏低，零售总毛利率下降。上半年新增直营51家、关闭180家，直营净减少119家，总门店净减少246家；增长当前主要来自收缩提效与品类调整，而非高回报扩张。

联营工业权益提供抗分销低毛利的第二利润源。公司持有国药现代12.46%，并持有国药致君、致君坪山、致君医贸各49%以及万乐药业35.19%。权益法利润属于普通股股东，但不等于上市公司可自由支配现金，现金分红和股权治理需单独观察。

# 4. 行业与竞争格局

医药流通处于低增长、控费与集中度提升并存阶段。两票制和全程追溯提高合规门槛，创新药、DTP、双通道、专业药房与冷链服务为龙头提供结构性机会；集采降价、医保直接结算、多层分销压缩和医院账期则降低收入与利润。行业并非传统周期低点，而是长期以效率换增长的成熟阶段。

分销竞争者包括国药控股体系、上海医药、华润医药商业和九州通。国药一致在两广深度与集团信用上领先中小企业，但客户和供应商议价权仍强。2026年上半年医药批发收入同比下降4.03%、毛利率下降0.11个百分点至5.70%，当前利润率接近低增长稳态，不能把政策压力简单视为可逆周期。

零售行业同时受到门店过剩、线上平台、价格竞争、医保个人账户监管与基层医疗分流。国大药房的医保和专业服务网络具备资产价值，但其经营效率弱于优质市场化连锁。2026年上半年零售行业口径收入增长5%，成本增长8.57%，毛利率下降2.65个百分点；DTP放量虽然增强患者服务，却会继续稀释毛利。

医保直接结算可能缩短分销回款，是最重要的制度性改善变量；但若结算主体由医院转向医保而支付纪律没有实际改善，不能仅凭政策宣布提高估值。

# 5. 财务质量与股东现金收益

2018—2025年收入由431.22亿元增至734.16亿元，归母利润从12.11亿元波动至11.36亿元；2023年曾达15.99亿元，2024年因零售商誉和无形资产减值降至6.42亿元。同期ROE从约11%降至2025年的6.26%。收入增长没有同步转化为每股利润与资本回报，说明历史零售并购和营运资本投入的回报偏弱。

2026年上半年收入362.66亿元、同比下降1.44%；毛利率10.04%、下降0.65个百分点；销售费用22.20亿元、下降8.87%，费用压降部分抵消毛利损失。营业利润8.34亿元、下降9.94%；归母6.06亿元、下降8.97%；扣非5.99亿元、下降6.84%。合并净利润6.48亿元高于归母，少数股东损益0.42亿元，估值必须使用归母口径。

累计与单季需要分开。一季度收入178.23亿元、归母2.87亿元、扣非2.80亿元、经营现金流-29.35亿元；二季度由累计相减为收入184.43亿元、归母3.19亿元、扣非3.19亿元、经营现金流14.17亿元。二季度利润和现金均环比改善，说明Q1不是全年运行水平；但H1整体利润仍下降，不能据此定义新增长周期。

H1经营现金流-15.19亿元、购建长期资产现金支出0.59亿元，简化自由现金流-15.78亿元。补充表显示，经营性应收增加11.94亿元、经营性应付减少13.76亿元，合计吞噬25.70亿元现金；存货增加仅0.47亿元。供应商融资余额半年减少12.69亿元，解释了大部分应付下降。去融资化提高负债透明度，却也证明账面经营现金流高度受付款安排影响，应跨完整年度判断。

6月末货币资金59.33亿元，其中6.36亿元受限，现金及现金等价物52.97亿元；短期借款18.28亿元、一年内到期租赁负债6.91亿元、长期租赁负债8.33亿元。若把供应商融资安排全部视作融资，期末相关负债27.80亿元，较年初40.49亿元下降。现金表面高于计息负债，但医药流通需要维持约227.71亿元应收、81.58亿元存货和大额票据结算，不能把现金全额作为可分配剩余资产。

应收账款余额231.73亿元、坏账准备4.03亿元、账面价值227.71亿元，半年增加12.33亿元。1—2年应收由10.58亿元增至19.21亿元，组合坏账计提比例由1.19%升至1.28%，总准备率由1.65%升至1.74%；H1信用减值损失0.36亿元，同比减少，主要因应收增量小于上年同期。改善的是增量，不是存量账期，1年以上应收上升仍需警惕。

# 6. 管理层、治理与资本配置

国药控股持有3.35326736亿股，占送股后总股本约54.77%，国药集团为实际控制人。集团信用、品种、融资和合规体系构成竞争优势，也使业务边界、关联采购与资金安排需要治理折价。公司上半年无股权激励或员工持股计划，董事和管理层利益主要来自央企任职与考核，并非通过显著持股与外部普通股股东完全绑定。

2026年上半年向国药集团及附属公司采购商品44.00亿元、接受劳务0.28亿元，向其销售商品2.48亿元、提供劳务0.17亿元；交易在年度批准额度内，但规模足以影响采购和现金流判断。公司在国药财务公司存款0.22亿元、应付账款融资1.51亿元，财务公司截至6月底资本充足率16.16%、流动性比例58.03%，公开指标合规；关联金融机构风险当前可控，不代表普通股股东无需关注资金归集和交易定价。

供应商融资从40.49亿元降至27.80亿元，是资本配置的正面变化：公司用现金降低短期外部融资，结构更透明。负面是过去零售并购留下16.05亿元商誉、大量关店和持续低ROE；国大药房仍托管集团体系外零售资产，同业竞争解决期限可自动顺延，业务边界尚不完全清晰。

H1非经营性资金占用汇总表未发现控股股东、实际控制人及附属企业非经营性占用。零售子公司历史财务资助和关联保理仍需单独监控，不能仅凭无占用结论消除治理风险。

# 7. 市场争议与隐含预期

乐观观点是央企信用和两广分销提供稳定利润，医保直接结算改善回款，国大药房关店提效后具备全国网络修复价值，0.65倍左右PB过度悲观。谨慎观点是低PB恰好对应6%左右ROE、应收回款变慢、供应商融资依赖、零售低效和关联交易复杂，账面净资产不能按高回报资产定价。

2026年8月28日A股收盘价19.98元，按6.1222亿股同权普通股口径对应约122.3亿元权益价值，约0.65倍6月末归母净资产。H1归母简单年化约12.12亿元，对应约10.1倍；以10.5—12亿元正常化归母利润计，对应约10.2—11.6倍。

当前价格隐含可持续ROE约6%左右、收入低增长、约30%分红率、零售长期仅微利，并对现金和联营资产保持折价。市场并未要求明显增长。它可能低估医保直接结算和国大网络修复，也可能正确地认为分销利润率、工业联营收益和现金周转继续承压。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实层：送股后A、B股合计6.12221584亿股，普通股经济权利相同；无库存股、优先股、永续债或现存稀释工具。6月末归母净资产188.73亿元、少数股东权益30.21亿元、商誉16.05亿元、长期股权投资32.57亿元。合并现金包含子公司营运资金，不全部属于可自由分配的普通股剩余现金。

经营层：H1归母6.06亿元，分销和零售经营利润下降，联营投资收益下降约31%，但Q2较Q1改善且非经常损益很小。结合2018—2025利润、当前分销中枢、零售微利、工业联营资产和回款风险，正常化归母利润取10.5—12亿元，可持续ROE取5.8%—7.0%。长期增长取1%—2%，与成熟行业、约30%—33%过渡分红率及剩余留存用于应收、数字化和门店改造相匹配；长期若ROE仅6%，高留存本身不会创造高价值。

方法一——PB—ROE，为核心方法。BVPS约30.83元，取5.8%—7.0%可持续ROE、9%—10%股权成本和1%—2%长期增长，稳态与过渡分红率共同支持约0.54—0.72倍PB，对应约16.6—22.2元。上沿要求ROE稳定接近7%、回款不再恶化且留存资本回报改善。

方法二——正常化PE交叉。10.5—12亿元正常化归母利润给予9.5—11倍，对应权益价值约99.8—132亿元，即每股约16.3—21.6元。该倍数反映央企分销稳定性和联营工业资产，也因低增长、零售商誉、少数股东与营运资本风险维持折价。两种方法中枢差异不到3%，普通股口径一致。

综合两种方法，核心合理价值区间：17—22 元。保守情景约13—16元，对应分销利润跌至8亿元附近、零售再亏并增加减值、应收坏账率上升；较乐观情景约23—27元，要求分销净利润稳定增长、医保直接结算实质缩短账期、国大药房形成3%—4%归母ROE且联营工业利润恢复。条件性上行不进入核心区间。

# 9. 基准持有人回报模型输入

本次形成`annual_common_equity_irr_v1`五年模型，但不计算任何随市场价格变化的回报率。未来五年每股普通现金分配依次为0.56、0.57、0.59、0.62、0.65元，合计2.99元，只包含持续持有人实际收到的现金；送红股、会计利润和留存现金不算现金分配。

年度分配以2025年度送股后等效0.56元现金股利为起点，假设普通股利润约10.8、11.1、11.5、11.9、12.3亿元，分红率约31%—32%。A、B股经济权利相同，B股实际以港币折算兑付，模型统一用人民币每股表达。完全稀释股数按6.12221584亿股稳定，假设无新增送股、增发、回购、可转债或期权。

第五年末普通股每股终值为18—24.5元，独立基于第五年11.5—13亿元正常化归母利润、9.5—11.5倍整体PE和稳定完全稀释股数，对应约17.8—24.4元后取整。整体PE已经包含届时现金、供应商融资、营运资本、联营权益和少数股东影响，五年已分配的2.99元不在终值中重复计算。没有足够必要性独立研究第三年经营与权益桥，故不提交year_3。

# 10. 公司、财务、治理和行业事件触发

优先跟踪季度及年度财报中的分销净利率、医院回款和单季扣非利润；应收账龄、坏账准备率、经营现金流、应付票据和供应商融资；国大药房同店、门店数、毛利率、经营利润与商誉减值；广东和广西医保直接结算实际范围与账期；国药现代、国药致君、致君坪山和万乐药业的利润与股权；集团零售资产整合、托管及同业竞争安排；现金分红、送股、稀释、财务公司和关联保理规模。

# 11. 核心风险与证伪条件

1. 分销利润率风险。集采降价、医保控费、医院议价和竞争可使5.70%的批发毛利率继续下降。若分销净利润连续两个完整年度低于8亿元，利润底盘假设需要重建。
2. 应收与坏账风险。应收账款占总资产47.27%，1—2年账龄余额半年增加8.62亿元。若应收周转继续拉长、准备率显著上升且经营现金流跨年度低于归母利润，会造成永久资本损失。
3. 零售价值陷阱。DTP增长拉低毛利、门店过剩和线上竞争持续。若国大药房重新经营性亏损并新增大额商誉或无形资产减值，全国网络应按更低折价资产估值。
4. 供应商融资和流动性风险。相关融资虽降至27.80亿元，仍是付款周期的重要工具；若融资突然收缩、成本上升，同时医院回款延迟，现金缺口会快速扩大。
5. 联营工业收益风险。H1权益法投资收益下降约31%。药品集采、产品竞争或关联资产治理变化会降低普通股利润和分部资产价值。
6. 治理与少数股东风险。体系内采购、财务公司、关联保理和托管安排提高复杂度；30.21亿元少数股东权益意味着合并利润与现金不能全部归属上市公司普通股。

最重要证伪条件是：分销净利润持续低于8亿元、应收账龄和坏账率同步恶化，同时国大药房回到经营性亏损并新增减值。三者并存将使低PB变为持续价值损耗，而非稳定分销资产的折价。

# 12. 最终判断

报告时点A股价格为19.98元/股（腾讯行情，2026年8月28日收盘），约为0.65倍6月末BVPS；核心合理价值区间为17—22元/股。已形成五年持有人回报模型：年度每股现金分配0.56、0.57、0.59、0.62、0.65元，第五年末终值18—24.5元；关键口径是股本稳定、普通股利润缓慢增长、分红率约31%—32%，终值采用第五年利润而非当前价值区间。

条件性上行来自医保直接结算缩短账期、零售毛利与同店恢复、联营工业利润回升。三个最重要正面变量是两广分销网络与央企信用、Q2利润现金环比改善、稳定现金分红和联营制药权益。三个最重要负面变量是分销与联营利润下行、零售毛利下降和商誉、223亿元级应收与供应商融资依赖。最重要证伪条件是分销利润、应收质量和零售经营同时恶化。

最终去向：covered。国药一致仍值得持续维护，因为医保结算、分销效率、零售修复和联营制药利润都能实质改变普通股价值；当前价格大致反映低增长与低ROE，尚未显示市场明显忽略经营风险。

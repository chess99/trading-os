# 恒立液压 2026Q3：模型说明

证券 CN:601100；法定名称江苏恒立液压股份有限公司。模型只依赖 Python 标准库，不连接任何服务、不取得报价。

## 重算

将 `2026-Q3.py` 单独下载至空目录，运行：

```sh
python 2026-Q3.py
```

它在脚本所在目录生成完整 `2026-Q3-output.json`、`2026-Q3-years.csv`、`2026-Q3-summary.json`。也可使用 `python 2026-Q3.py --output ./recreated`。未压缩、未舍弃任何场景或年度；所有17场景、10年度与终值字段保留浮点精度。JSON禁止NaN/Infinity；不可行值使用null。

## 单位、时间和接口

模型总额单位为人民币十亿元（与报告亿元相差10倍）；每股为人民币元；股数为十亿股。Y1–Y10从2026-10-26起逐年满12个月。分红为税前公司向同等普通股分配，不代入个人税收。公开市场回购、会计净利润、FCF和存量应收股利均不是新持有人分配。

`cases`包含核心base/core_low/core_high，cyclical/structural/upside三条完整替代经营路径，collection_delay/permanent_wc/treasury_loss/upstream_lag/no_upstream10/parent_settlement/tax25/project_overrun/deposit_delay/release_early诊断及funding_failure不可行反例。各情景参数与全部年度同时给出；`description`说明生效机制。

`annual`含经营收入、税前利润、现金税、NOPAT、折旧、资本开支、全部净营运资本组成、经营资本、少数利润及资本份额、旧工程与旧股利、集团开/闭现金、财务本金/收益/税、债务提款还款/利息/缺口、母公司利润存量/自身利润/科技宣派与收到/应收余额/内部结算/母现金、计划与实际新分配。项目EBIT为包含于集团的预算解释，不是额外加值或独立法定资金池。

`terminal_bridge`含下一年归母经营NOPAT、增量资本回报、增长再投资和维持实物资本再投资较大值、持续经营现金、经营价值、过剩现金本金、实现年份/成本和利润上划条件。核心当前价值由D1–D10加TV10折现；TV5独立由D6–D10和TV10折回。方法二共享经营现金预算，但改以第11年NOPAT14–16倍；其倍数是辅助判断而不是行情比较或另一个精确认证。

## 六项经济边界

1. 法人：上市母公司、100%恒立科技和82.86%上海立新分别识别。墨西哥/印尼制造/海外销售最终权益用H1直接+间接权益核对。产品项目、CIP、其他合并业务不是虚构法律储备池。恒立气动及南京恒立为体系外关联方，不归上市公司。
2. 权益/利润：母公司已披露盈余公积6.70410496亿元等于股本50%；未以注册资本或母投资成本冒充可返资本。没有资本返还预测。未来母公司利润份额27%、科技65%是经济分配预算，不是法定单体税基；科技最多派当期正利润50%且不超过可用现金，不依赖未核旧储备。实际批准、单体亏损和当地税须在执行时确认。墨西哥已识别亏损不立即抵扣其他主体现金税。
3. 股利：9月末20.2082578357亿元应付股利主要欠控股股东，扣10月中期4.022462976亿元后的16.1857948597亿元首年付旧权利人。旧债付款不增加普通股D、不再次扣利润。新子股利宣派才增加母公司利润，滞后到账只增加母现金；集团收益无重复增加。
4. 金融本金：103.31亿元货币资金含定存和保证金；期限不是永久价值归零。基准第一年保留11.1257亿元受限额度，第二年释放；延迟测试将H1全部非等价物71.5818亿元锁至第三年。经营现金保留收入12%，正常收益计价。超额资金在Y10分配受母利润及现金约束，余下本金在Y12按2%成本实现，不要求关闭工厂。该路径依赖未来上划批准和存款回收，不是承诺。
5. 融资/资本：初始工程预付、CIP和资产在65.8637亿元长期经营资产中，不二次付款；独立旧工程应付1.3770亿元首年结清。未来资本开支同时含维护和成长。融资20亿元上限为压力预算而非公司授信或担保授权已经到款；债务提款和利息、还本完整入账。资本和利润共同处理上海立新17.14%少数份额：其全体资本占比按(少数净资产/17.14%)/集团权益约1.92%估计，不能把0.33%少数占比再乘17.14%两次。初始少数金融资产0.34亿元为同口径估计。
6. 开账周转：43.6195313297亿元净营运资本包括账款、全部票据、库存、预付及其他经营资产，减去物料采购/票据、预收、工资税及其他经营负债。工程应付单列；递延税不重复当现金资产，现金税采用正常化率；递延补助不视作必须归还债务，其历史购置资产已在开账资本，未来普通经营利润不继续添加一笔补助年金。少量商誉未单独加值。联营和其他小额投资按账面成本预算Y2收回；交易性金融资产按15%利得税预算，未对存款本金或小额投资账面成本征税，不把权益法利润同时资本化。交易资产具体税基未知，零税基是保守界限，小额投资假设账面税基。未来全部wc_*余额随收入增长，压力额外占款落入应收，其回收不增加会计利润。

## 开账与未知

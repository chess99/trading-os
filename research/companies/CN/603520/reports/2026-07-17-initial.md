# 司太立（603520）初始深度研究：造影剂一体化的修复期，先观察安全边际

## 结论先行

**投资结论：观察。** 司太立是国内少数同时覆盖碘造影剂原料药、关键中间体和制剂的企业，2025 年收入已恢复到 24.46 亿元，2026Q1 收入 7.11 亿元、归母净利润 0.21 亿元，同比继续改善。逻辑上，公司从“扩产投入期”进入“产能释放和利润率修复期”，若碘价回落、上海制剂工厂 EU GMP 认证推进、原料药新产能爬坡和制剂销售兑现，利润弹性可能明显高于当前表观利润。

但当前买点并不厚。按 2026-07-17 新浪财经显示的收盘/最新价 9.73 元测算，总市值约 42.66 亿元；2026Q1 末归母权益约 25.75 亿元，PB 约 1.66 倍；但 TTM 归母净利润仅约 0.17 亿元，表观 PE 失真偏高。公司仍有短债、长债、应收票据/账款和存货压力，2025 年经营现金流为负。我的基准公允价值区间为 **9.5-13.5 元/股**，理想买入区间为 **8.0-8.8 元/股**；现价只接近保守价值下沿，尚未给足“高杠杆制造业修复股”需要的折价。

**一句话 thesis：** 司太立的核心不是当期盈利，而是“碘造影剂 API 规模优势 + 制剂国际化/国内集采放量 + 碘价回落”三件事能否把已投入资本转化为现金利润；验证前应观察，跌到 8.8 元以下才有较舒服的赔率。

## 业务与商业模式

司太立主营 X 射线造影剂原料药、关键中间体、制剂及部分 CMO/CDMO 类业务。公司官网产品中心显示，其制剂端覆盖碘海醇、碘帕醇、碘克沙醇、碘美普尔、碘佛醇、碘普罗胺、钆贝葡胺等产品；公司 2023 年公告/官网信息显示，碘佛醇注射液获批后，公司碘对比剂制剂已覆盖多个主流品种。2025 年年报披露的收入结构中，造影剂系列仍是核心。

商业模式的关键是“原料药规模化 + 下游制剂化”。原料药端卖给国内外制剂客户，特点是工艺、质量体系、环保和安全生产要求高，固定资产和营运资本占用大；制剂端面对医院采购、集采、注册认证和渠道准入，价格更受政策影响，但如果自产 API 能稳定供给，毛利和供应链可控性更好。

这家公司过去几年最重要的变化，是从偏 API 供应商向全产业链公司推进。这个变化提高了天花板，也抬高了执行难度：产能利用率、质量认证、注册进度、客户验证周期、应收和存货周转都会决定利润最终能否落地。

## 行业判断

造影剂需求来自 CT、血管造影等医学影像检查，长期受人口老龄化、影像设备渗透、临床诊断需求支撑，需求属性偏刚性。但行业不是纯消费品，量价主要受三类因素制约：

1. **集采与医保控费。** 制剂端价格存在持续压缩压力，企业要靠规模、品种组合和成本控制换取份额。
2. **碘原料价格。** 碘是碘造影剂的重要成本项，碘价高位会压制毛利；碘价回落则对 API 和制剂均有修复弹性。未来碘价路径无法完全核验，置信度中。
3. **质量与注册壁垒。** 造影剂关系用药安全，欧美 GMP、客户审计、杂质控制、环保安全生产都会拉开供应商差距。

行业长期不是高爆发赛道，而是“高质量体系、强制造管理、规模化降本”的制造赛道。对司太立这类公司，核心不应只看收入增速，而要看产能释放后 ROIC 和经营现金流是否改善。

## 护城河

**1. 品种和产业链完整度。** 司太立覆盖多个主流碘造影剂 API 和制剂，品类齐全有利于共享质量体系、客户资源和工艺经验。公司官网和公开公告显示，制剂产品已覆盖多种主流碘对比剂。

**2. 规模化制造与认证积累。** 造影剂 API 属于复杂精细化工/药品制造，工艺路线、杂质控制、环保安全、客户审计和 GMP 体系构成进入门槛。券商对公司产能份额的测算显示其是国内重要头部供应商，但该类全球份额数据来自第三方测算，置信度中低，不能作为硬事实。

**3. 原料药到制剂的一体化成本优势。** 如果 API 自供稳定、产能利用率足够高，制剂放量时公司可获得成本和供应链优势；若产能低利用或认证延迟，则一体化反而会体现为折旧、财务费用和营运资本压力。

护城河的弱点同样明显：造影剂不具备强专利独占，集采环境下价格权弱；公司规模相对跨国药企和恒瑞等综合药企仍小，融资成本和抗周期能力较弱。

## 增长驱动

**短期（2026）：** 看产能爬坡、碘价变化、国内制剂销售和费用率控制。2026Q1 收入仅同比 +3.70%，但归母净利润同比 +45.91%，说明利润端已有边际修复迹象；不过 Q1 经营现金流仍为负，修复质量尚需验证。

**中期（2026-2028）：** 看三个变量：第一，新增 API 产能利用率提升；第二，碘美普尔、碘佛醇、碘普罗胺等制剂品种能否持续放量；第三，上海制剂工厂 EU GMP 结果及后续海外注册/客户导入。2026-06-17 投资者关系活动记录显示，EU GMP 现场检查已开展，但结果不确定，这是重要事件催化也是风险点。

**长期：** 若公司真正形成“API 全球供应 + 国内制剂份额 + 海外制剂准入”的结构，利润中枢可能显著高于 2025 年；若只停留在低毛利 API 和国内集采制剂，估值应按周期制造业而非医药成长股处理。

## 财务质量

2025 年公司营收 24.46 亿元、归母净利润 0.10 亿元，扣非净利润 0.03 亿元，盈利仍处低位。2026Q1 单季营收 7.11 亿元、归母净利润 0.21 亿元，单季利润已高于 2025 全年，但不能简单年化，因为产能爬坡、产品结构、碘价和费用确认可能季节波动。

资产负债端需要重点警惕。2026Q1 末货币资金约 3.08 亿元，而短期借款、一年内到期非流动负债、长期借款合计约 29.66 亿元；2025 年经营现金流为 -0.87 亿元，2026Q1 仍为 -0.06 亿元。公司表面 PB 不高，但债务和营运资本占用使股权价值对经营改善高度敏感。

我的判断：财务报表正在从“投入期”向“回收期”过渡，但还没有完成验证。只要经营现金流没有连续转正、应收和存货没有改善，就不能把利润弹性完全资本化。

## 治理与资本配置

公司为民营控股制造药企，治理上优点是主业聚焦、产业链战略连续；风险是资本开支和关联交易需持续跟踪。2026 年 4 月公司公告拟以 3500 万元自有资金增资浙江健立化学，交易涉及关联方共同投资，公告披露公司增资后合计持有健立化学 19.5271% 股权。金额相对公司资产规模不大，但关联交易定价、后续业务协同和资金回报需要跟踪。

2026 年 7 月公司披露控股股东胡锦生解除质押 1800 万股。解除质押本身降低一部分质押压力，但控股股东后续质押、减持、资金安排仍应跟踪。治理结论是“可接受但需盯紧资本开支和关联交易回报”。

## 估值

估值基准日：2026-07-17。股价 9.73 元，总股本 4.3841 亿股，总市值约 42.66 亿元。由于 TTM 净利润过低，静态 PE 没有参考价值；更适合用“正常化利润 + PB/PS + 现金流情景”交叉验证。

### 1. 相对估值

医药制造/特色 API 修复股在盈利稳定、现金流转正后可给 18-28 倍正常化 PE；若仍是高杠杆周期制造，合理倍数应压到 12-18 倍。司太立 2026-2027 年合理归母净利润中枢我估为 1.5-2.5 亿元，取 20-24 倍，对应股权价值 30-60 亿元，即 **6.8-13.7 元/股**。考虑公司有制剂国际化期权，基准可上修至 9.5-13.5 元/股。

### 2. 绝对估值

以股权自由现金流简化测算：假设 2026-2030 年经营现金流从 0.5 亿元修复至 4.0 亿元，资本开支较扩产期回落，股权自由现金流中枢逐步到 2.0-3.0 亿元；折现率 10.5%-11.5%，永续增长 1.5%-2.0%。在该假设下，股权价值约 38-58 亿元，对应 **8.7-13.2 元/股**。若经营现金流继续被存货和应收吞噬，该估值不成立。

### 3. 情景估值

| 情景 | 关键假设 | 估值结果 |
|---|---|---:|
| 悲观 | EU GMP/海外推进延迟，碘价和费用压力仍高，2027 正常化净利低于 1 亿元 | 5-7 元/股 |
| 基准 | API 产能释放、制剂稳步放量，2027 正常化净利约 2 亿元，现金流改善 | 10-12 元/股 |
| 乐观 | 海外认证顺利、产能高利用、利润率接近优质特色 API，公司 2028 净利 3.5 亿元以上 | 16-19 元/股 |

综合三种方法，我给出公允价值区间 **9.5-13.5 元/股**，买入区间 **8.0-8.8 元/股**，减持/卖出观察区间 **14.5-16.5 元/股**。当前 9.73 元不是贵，但也不是足够便宜。

## 安全边际

买入这类公司需要至少 25%-30% 的安全边际，因为利润弹性尚未被现金流证明，且债务放大了经营波动。若以 11.5 元/股作为基准价值中枢，8.5 元附近才有约 26% 折价；当前 9.73 元的折价不足。更稳妥的做法是先建立观察仓或不建仓，等待两类信号：价格跌入买入区间，或经营现金流和 EU GMP/制剂放量同时验证。

## 主要风险

1. **现金流风险。** 2025 年和 2026Q1 经营现金流均为负，若应收账款、票据和存货继续增加，利润改善可能无法转化为股东价值。
2. **债务风险。** 公司短期和长期有息负债规模较大，利率和再融资环境变化会影响净利润和估值。
3. **认证和质量风险。** EU GMP 结果不确定；质量体系若出现问题，会影响海外客户和制剂进度。
4. **集采降价风险。** 制剂端若以价换量不及预期，利润率可能低于估值假设。
5. **碘价波动风险。** 碘价高位或供应扰动会压制毛利；碘价趋势数据未能通过单一权威实时来源完全核验，置信度中。
6. **安全环保风险。** 精细化工和原料药生产对环保、安全生产要求高，事故或停产会造成重大影响。
7. **关联交易和资本配置风险。** 对外投资和关联交易需验证回报，避免资本继续沉淀。

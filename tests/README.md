# 测试范围

`PYTHONPATH=src python -m pytest -q` 检查当前状态流转、周期与证券口径，以及轻量研究交付合同。测试使用当前源码和必要输入，在浅克隆和没有 `.git` 的源码包中均可运行。

实际模型的移植样本按其保留周期的采用输出复算，不要求公司最新研究状态永远停留在该周期。

存储检查：`python scripts/check-research-artifacts.py`。它检查研究模型文件预算和可读文本边界，不执行模型、不认证商业结论。

当前三季报交付核对：`python research/pilots/2026-Q3/verify-models.py`。加 `--recompute --symbol CN:代码` 才隔离执行指定公司的当前计算入口；不指定公司会执行该周期全部有数值模型的公司。无可靠数值模型的公司单独报告 `numeric_model_unavailable`，不计入数学复算通过数。

旧分支的全字节快照比较、压缩包还原、固定历史 Git 对象回放及旧接口断言已退出日常测试。研究修订后，历史接口不再代表当前正确答案；这些测试的删除不表示原失败已通过。需要调查某次历史计算时，在完整保全的旧版本独立重演，明确其输入、结果和限制，不把旧重演接回当前构建或默认测试。

公司数学的实质核验仍按研究规范完成：使用实际计算链的可手算特例、独立核心端点和支配性参数复算。文件合同、状态校验或本目录测试通过均不能替代该核验。

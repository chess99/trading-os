# 行业运行指标更新

行业指标回答需求、结构、竞争及单位经济性处于什么位置。完整研究回答这些变化为何影响长期利润。指标按原始发布节奏更新；新月数据不自动生成完整报告，也不触发公司重研。

## 取证与比较

先读主题完整报告和 `research/industries/<topic>/indicators.json`。从列明的原始发布机构取得最新正式全期资料，逐项记录观察期、发布日期、定义、单位和公开URL。尚未公布的月份保持缺失；周度预估、厂商快报与正式全月统计不拼接。转载可用于核对，但须标明原发布者，不能伪装为政府统计。

保持分母和统计对象一致：国内零售与含出口批发、乘用车与全部汽车、单月与累计、动力装车与含储能出货、全球与中国分开。优先保留同口径时间序列。原来源修订历史值时，使用 `revisionNote` 说明修订范围和原因，保留Git历史。无法解释的口径冲突不强行归一。

数值核对包括比例、单位换算、累计转单月及份额合计。累计差分仅在两期覆盖和修订一致时使用，并在点位说明；春节移动、工作日、补贴时点和基数效应不能用环比替代解释。排名表保留原机构份额，不用不同范围的总量重算。

## 新能源汽车来源

- 中汽协《汽车工业产销情况》：全国汽车及新能源汽车产销、国内销售和出口，核对乘用车/商用车与批发边界。
- 中国汽车流通协会乘用车市场信息联席分会的月度分析：国内新能源乘用车零售、渗透率、纯电/插混及终端结构；同一月份不与周度预估混用。
- 中国汽车动力电池产业创新联盟：装车GWh、化学体系和企业份额；明确锂离子电池榜单与全部动力电池总量的差异。
- SNE Research：全球装车电量与企业份额，其EV/PHEV/HEV统计范围须单列。
- IEA等年度资料：全球销量和历史结构，年度数据不冒充月度现状。

## 发布

候选保持完整序列，先校验，再原子更新：

```bash
node dashboard/scripts/update-industry-indicators.mjs --input /tmp/verified-indicators.json
node dashboard/scripts/update-industry-indicators.mjs --input /tmp/verified-indicators.json --apply
node dashboard/scripts/build-research-data.mjs
```

`checkedOn`仅在实际检查来源后推进，`reviewAfter`表示建议再次核验的日期。解释性文字仅在有新证据时调整。脚本校验结构与部分算术，来源质量和商业判断仍需人工核验。更新后检查页面、来源链接和移动端，提交本次指标变更；构建产物不手改。

当新证据改变需求路径、利润归属、技术替代或竞争判断时，另发一篇完整行业版本并复盘旧判断。旧报告日期和正文保持当时的信息集。日常新闻、下载缓存和抓取日志不入库。

# 港美股长期价值质量筛选

本规范沿用 [A 股筛选规范](cn-a-value-quality.md) 的商业、普通股现金、A/B 分层及隔离要求。差异只在覆盖范围、证券身份和跨市场口径。第一层回答是否值得长期研究，不给出证券定价结论；本轮不开展正式公司深研，也不创建研究任务。

## 范围与事实源

港股与美股分别维护 `screening/hk/value-quality/pool.json`、`screening/us/value-quality/pool.json`，采用同一 v2 合同。A 股原池保持独立；三池在界面聚合，不能把港美股写进 A 股研究状态或排期队列。可读投影只由命令生成。

港美股采用主动收窄的样本，`universe.securities` 是本轮选定证券身份范围，不代表全市场。必须在 `review.scope_note` 写明选择理由、实际读到的材料、期间及缺口。`baseline_count` 只统计本轮已读财务基线；不以取得证券身份或搜索摘要替代复核。未覆盖不是排除结论。

代码使用 HK:五位数字、US:交易所 ticker，保留类别后缀；同一发行人的 A/H、ADR/本地股和双柜台不重复当作独立公司。本轮港股使用港币主柜台，美股使用普通股；跨市场重叠将来须明确发行人映射后再汇总公司数。不得根据 ticker 推断注册地、经营地或会计币种。

## 五至十年的检验

每张判断卡需要回答：行业增速降低后客户为何仍选择它，必要投入如何变化，哪些经营事实会推翻长期优势。优先读连续多年经营及现金记录，检查最近可得披露中的重要变化。复核日不是资料截止；来源标题写明财务期间和已读章节，未读更新必须披露。

- A：优势与普通股现金已由多年记录支持，解释现存反证为何未破坏基础机制。
- B：优势已经商业化，但长期现金转换或治理有决定性问题；明确升级需要观察的结果。
- 不足以辨认优势时留在池外；不为凑数量入 B。每轮记录近邻遗漏和热门公司误入风险，未读近邻不得写成已经完成排除研究。

## 跨市场现金纪律

美股核股票薪酬及稀释、客户激励、租赁和购买承诺；现金回购不等于净股数下降。港股核母子公司上划、少数权益、VIE 与跨境分配、关联交易、双重股权和控股股东。币种和财年单独辨认，不把人民币、港币、美元金额合并相加，不把财年标签当同一自然年。

云平台须把设备购建、融资租赁、算力承诺与折旧寿命一起看；保险用新业务投入后的净自由盈余及母公司上划，不能拿保费流入作自由现金；交易所客户保证金及清算资金不属于股东；零售须检验会员续费、供应商信用及开店维护投入。经营现金减购建只是代理，不能直接宣称全部可分配。

## 维护与使用

```bash
python -m trading_os quality-pool --market hk replace --input <完整港股池.json>
python -m trading_os quality-pool --market us validate
python -m trading_os quality-pool --market hk status
python -m trading_os quality-pool --market us list --tier quality_research
python -m trading_os quality-pool --market hk rebuild
```

默认 `cn-a` 保持兼容。`research enqueue-period` 仍仅读取 A 股池；港美股的财年、报告频率、货币及报告接口须在以后正式深研阶段单独实现，不会因筛选入池而自动排队。网页第一层只读三池判断卡，不加载行情、不生成回报模型。未来扩池优先补行业与相反案例，不能降低证据要求。

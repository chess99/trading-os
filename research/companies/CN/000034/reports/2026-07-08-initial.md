## 业务理解

神州数码（Digital China）是中国最大的IT分销和服务商之一，前身为联想科技、神州数码控股旗下。公司核心业务分为三大板块：

1. **IT分销及增值服务（核心收入来源）**：
   - 消费电子/企业级IT产品分销（笔记本电脑、服务器、网络设备、软件等）
   - 代理品牌包括：华为、微软、IBM、思科、惠普、联想、三星等数百个品牌
   - 收入占比约85-90%，毛利率仅2-3%（典型的通道型分销业务，靠规模效应和资金周转赚钱）
   - 客户结构：覆盖数万家渠道合作伙伴（中小企业经销商、系统集成商）

2. **云计算及数字化转型（战略增长业务）**：
   - 云管理服务（MSP）：帮助客户迁移、管理多云环境（阿里云、AWS、Azure、华为云等）
   - 数字化解决方案：数据治理、IoT、AI平台
   - 收入占比估计约5-8%，毛利率明显高于分销（约10-20%）
   - AI算力相关：2024-2025年大模型/AI算力需求爆发，公司作为英伟达/华为等AI芯片分销商参与其中

3. **自有品牌及信创（自主可控产品）**：
   - 神州鲲泰系列服务器、PC、存储等信创产品
   - 基于华为鲲鹏/昇腾生态、飞腾等国产芯片的整机产品
   - 收入占比估计约3-5%，但增长较快，毛利率显著高于分销

**关键特点**：
- 公司本质是一家"大渠道 + 小产品"企业。营收巨大但利润极薄（2025年净利率0.39%）
- 2025年营收1438亿，利润5.23亿，净利率0.39%。意味着每卖100元货，只赚0.39元
- 资产结构中有大量应收账款（135亿）和存货（190亿），资金占用严重
- 高负债经营（资产负债率79.4%），主要是应付账款和短期借款构成的运营资金

## 行业与竞争格局

**IT分销行业**处于成熟甚至衰退阶段：

- **行稳但不增长**：中国IT分销市场增速已放缓至低个位数或个位数，与GDP相关度较高
- **传统分销面临去中间化压力**：厂商（华为、联想等）越来越倾向直接接触终端客户或通过自建渠道出货
- **头部集中化**：分销市场向头部3-5家大企业高度集中（神州数码、中电港、深圳华强三家占大部分份额），小分销商持续出清

**云计算和信创**处于成长阶段：

- **中国云计算市场高速增长**（约20-30% CAGR），但竞争激烈，阿里云、华为云、腾讯云均直接面对客户
- **信创（国产化替代）**是中国政策驱动的长期趋势，2025-2027年有望保持15-25%增速
- **AI算力建设**：2024-2026年中国AI基础设施建设爆发，带动服务器/GPU等硬件需求猛增，神州数码作为华为鲲鹏/昇腾生态分销和整机提供商受益

**竞争格局**：

| 维度 | 评级 | 说明 |
|---|---|---|
| 护城河 | 窄 | 头部分销商的规模效应、渠道网络覆盖、供应链金融服务是壁垒，但整体护城河不深。下游渠道关系是核心资产。 |

## 公司质量

**优势**：
1. **规模效应明显**：1400亿+收入体量带来极强的供应链议价能力和资金优势
2. **渠道网络深厚**：覆盖全国数万家渠道伙伴，是稀缺的分销基础设施
3. **品牌代理关系稳固**：与华为、IBM、微软、思科等顶级IT厂商保持长期合作
4. **转型方向正确**：云计算/AI/信创是市场正确方向，公司也在持续投入
5. **研发投入**：2025年研发费用约3.93亿（占收入0.27%），体量不大但方向正确

**劣势**：
1. **盈利质量极差**：净利率不到0.5%，公司利润对价格/利率/坏账极敏感
2. **高负债高杠杆**：资产负债率79.4%，2025年底短期借款高达164亿
3. **经营现金流极不稳定**：2025年经营现金流为-24.3亿（大幅流出），2024年为+25亿（大幅流入），年度波动剧烈。Q1 2026经营现金流-24.98亿。这一点非常危险
4. **归母净利润连续两年大幅下滑**：2024年-35.8%，2025年-30.5%，利润下降速度超过收入增长速度
5. **应收账款和存货规模巨大**：应收135亿+存货190亿=325亿，占流动资产的69%，如果发生大额坏账或存货跌价，利润表将直接受重创
6. **转型业务体量仍然很小**：云计算和自有品牌等高利润业务占比估计不足10%，短期内难以改变整体利润率

## 增长驱动

1. **AI算力建设带来的服务器/IT设备分销需求增长（短期驱动）**：2025收入增12.2%，部分受益于AI热潮。但分销环节利润极低，营收增长不必然带来利润增长
2. **信创国产化（中期驱动）**：神州鲲泰信创产品线增速较快，且利润率远高于分销
3. **云计算MSP服务（中长期）**：云管理服务利润率高，客户粘性强，但目前体量小
4. **海外市场拓展**：公司也在尝试海外分销业务，但规模尚小
5. **行业整合**：小分销退出，头部集中可能带来份额提升

**核心问题**：收入增长≠利润增长。2025年收入增长12.2%，但归母净利润下降30.5%。增长的质量存疑。

## 估值

### 1. 相对估值（PE/PB）

**基于实际盈利（2025年）**：
- PE = 294亿 / 5.23亿 ≈ **56x**（使用总市值）
- PE = 294亿 / 7.03亿（扣非归母）≈ **42x**
- PB = 294亿 / 110亿（估）≈ **2.7x**
- PS = 294亿 / 1438亿 ≈ **0.2x**

**基于券商一致预期（2026E）**：
- 券商预期2026年EPS约1.25-2.20元（差异大），取均值约1.50元
- 2026E PE = 26.82 / 1.50 ≈ **18x**（乐观假设下）
- 使用开源证券预测EPS 1.25元→ PE=21x；东吴预测2.20元→PE=12x

**同业对标**：
- IT分销同行PE普遍在15-30x（取决于利润稳定性和增长预期）
- 考虑到神州数码利润连续下滑且不稳定，其合理PE应低于行业均值，约15-22x

### 2. 绝对估值（简易PB-ROE估值）

使用戈登增长模型简化版：
- 当前ROE 5.05%，假设长期可持续ROE 6%（保守）
- 要求回报率10%
- 假设长期增长率3%
- 合理PB = (ROE - g) / (r - g) = (6%-3%)/(10%-3%) = 0.43x
- 这得出极端低的估值，说明当前ROE无法支撑2.7x PB。

**调整后**：
- 若ROE恢复到8%（2024年水平），合理PB = (8%-3%)/(10%-3%) = 0.71x
- 每股净资产15.21元 → 合理价 ≈ 10.8元
- 若ROE恢复到10%（2023年水平），合理PB = 1.0x，合理价 ≈ 15.2元

### 3. 合理市值区间

**方法一：PE × 正常化盈利**
- 正常化年利润：约6-8亿（取2023-2025年均值偏低）
- 合理PE 15-22x → 市值区间 90-176亿 → 每股 ¥8-16

**方法二：PB × 净资产**
- 每股净资产15.21元
- 历史PB区间 0.8-3.5x
- 合理PB 1.0-1.5x（考虑较低的ROE和下降趋势）→ 每股 ¥15-23

**方法三：EV/EBIT**
- EBIT（营业利润）≈ 7.53亿（2025年）+ 财务费用 ≈ 12.2亿
- EV ≈ 市值294亿 + 短期借款164亿 - 货币资金83亿 ≈ 375亿
- EV/EBIT ≈ 375/12.2 ≈ **31x**，明显偏贵

**综合合理区间**：¥16-22/股，对应市值约175-240亿

# 长期精选原则

本层把广泛研究收敛为少数值得持续关注的企业。先判断生意是否值得拥有，再结合当时价格讨论投入资金是否合理。选得少源于证据和取舍，不源于固定数量要求。

## 优先理解

- 有可解释且难以复制的客户价值，竞争优势能经多年经营结果验证。
- 收入和利润能转换为普通股现金，增长所需资本和治理约束能够识别。
- 留存收益有可靠的再投资用途；缺少好用途时，管理层愿意合理返还现金。
- 关键经营假设数量有限、能被事实检验，允许普通误差而不轻易颠覆整套拥有理由。

成熟企业、合理成长和有成本优势的周期企业都可研究，不以消费/制造、国企/民企、成长/价值标签决定资格。快速变化业务只有在机制和证据足够清楚时才进入精选；优秀经营者并不自动拥有优秀商业模式。

## 保持克制

低估值不能弥补无法识别的普通股归属或重大治理问题；高质量也不能使任何价格合理。估值与回报模型都是带条件的判断，不按数值统一排序，不使用主观概率或综合分数制造精确结论。

对强依赖未兑现新业务、不断融资、单个事件或多项乐观假设的企业，先明确关键证据。缺证不等于证伪；但不能靠小仓位、长时间等待或更漂亮的估值模型补足认知。

不同公司如果依赖相同需求、商品、政策、信用或融资机制，应一起看共同风险。比较可以选择现金或继续等待，不强迫每天找到买入对象。

## 维护纪律

执行方法见[长期精选流程](../prompts/selection/long-term-selection.md)。结果只维护[当前文本](current.md)，历史由 Git 保留。旧入选不构成新证据；对报告失效、竞争变化、资本配置异常与关键预测偏差及时重新比较。

精选是研究成果的上层使用，不认证公司的永久质量，不覆盖正式研究，也不承担账户管理或自动执行。

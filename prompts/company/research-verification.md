# 单公司研究核验附录

本文件是[统一深研提示词](standard-deep-research.md)的必读组成部分，集中保存来源、财务、普通股归属、模型复算、慢变量画像及验收要求。

文件归档与大小预算执行[研究文件与模型交付规范](../../docs/research-artifacts.md)（单文件 <= 1 MiB，单公司单周期模型附件 <= 2 MiB）。

## 一、来源、时点与原证核验

- **一手资料优先**：使用最新年报、半年报、季报、交易所公告与同行正式披露；产业判断核验客户、供应商及官方统计。新闻、数据库摘要只作补充。
- **身份与口径核实**：确认下载附件的发行人、报告期、单位（元/千元/万元）、币种、正负号及本期/上期列序；不把甲平台编号拼到乙平台 URL。
- **期间清晰**：累计、单季、上年同期与上一季度分别标注；无法可靠拆出单季时写清局限。
- **Q1/Q3 附注继承核验**：一季报或三季报缺少完整附注时，确认报告明确标注“承接最近一期 H1/FY 已核实结构，仅更新本期新披露事实”；不得对未披露子表做无依据细拆，也不得出现“基准已更新而情景/敏感到旧状态”的割裂。

## 二、财务质量、普通股归属与重要性门槛

- **普通股权益桥**：核对已发行与库存股、已归属未登记奖励、期权/可转债稀释、少数股东权益、永续债及未交割强制付款义务；确认金融资产本金与利息收益、已分配股利与终值现金、已投入在建工程与未来扩产预算不重复计价。
- **增量资本配对**：新增固定资产、研发与营运资本投入必须与对应期间的增量经营利润配对（如 Y1→Y5 利润差配 Y1 末→Y5 末资本差）；禁止只算收入增长不算资本占用，也禁止把“高毛利率”直接等同于“高资本回报”。
- **重要性门槛**：按对核心价值的真实影响分配检查深度。对于影响低于核心价值 **3%–5%** 的细项，使用合理量级预算并说明边界即可；禁止把过多篇幅和小数位数浪费在无法验证的尾差上。
- **金融与特殊行业口径**：银行重点核普通股净资产、可持续 ROE、信用损失、监管资本留存及稳态关系 `g = (1 - payout) × ROE`；资源类重点核储量寿命、品位/成本分位、剥离/弃置义务与资本开支周期；平台/科技重点核股份支付稀释与研发/算力资本化边界。

## 三、四类估值框架与模型复算

- **方法主次一致**：至少采用两种方法并明确主次，保证双方普通股口径、稀释股数、币种与时间基准统一；中枢差超过 25% 时解释核心经济分歧。
- **可复算交付**：凡可数值建模的公司，交付可读 Python 模型与必要输入（`YYYY-XX.py`、`YYYY-XX-input.json`、`YYYY-XX-output.json`），含守恒断言与至少一项经同一正式计算函数跑通的简化手算特例。
- **四情景联动核验**：`structural_bear`、`cyclical_bear`、`base_low`/`base_high`、`bull` 须满足非负且单调非递减关系（`structural_bear <= cyclical_bear <= base_low <= base_high <= bull`），且 `base_low`/`base_high` 与 `value_range` 一致（允许 0.01 舍入容差）。重大情景须同时调整对应盈利、资本投入、融资成本与付款约束，不以单一折扣代替结构受损路径。
- **终值与过渡期**：五年是持有人接口而非护城河终点；高成长/拐点期企业可用第 6–10 年显性过渡再收敛至稳态，同时扣除匹配增长所需的再投资资本；披露终值在主估值中的现值占比。

## 四、V1 持有人模型合同与港股通扩展

每份候选须提交非空 `return_model_note`：
- 当采用 `dividend_dcf_v1` 或 `buyback_total_yield` 可靠建模时，提交完整的 `return_model`（`schema_version: 1`, `method: "annual_common_equity_irr_v1"`, 5 年每股现金分配与独立 `year_5` 终值，`year_3` 可选）。
- 当公司处于重投入期（如 `growth_terminal_matrix` 早期成长型）或关键路径无法约束时，允许 `return_model: null`，并在 `return_model_note` 中交代原因及替代终态矩阵依据；不得把公开市场回购或未分配现金直接充当现金分配，但应在 `capital_return_profile.annual_net_buyback_per_share` 中如实记录预计净注销规模。
- 港股与 A/H 双上市标的须核对 `research/markets/ah-southbound-bridge.json`，提交 `capital_return_profile.southbound_dividend_tax_rate`（内地个人港股通口径，以最新派息公告为准）。

## 五、慢变量画像与成品验收五关

协调器验收须确认以下五关全部通过，且绝不允许将协调反馈或用户对话泄漏进报告与展示字段：

1. **长期商业判断**：删去估值数字后，是否仍能讲清生意如何赚钱、优势如何维持或拐点依据何在、最强反证是什么，以及为何给出 `covered` 或 `ignore`。
2. **证据与重要性**：支配价值的 2–3 个假设是否有原证约束？是否守住了重要性门槛、避免了 Q1/Q3 附注盲猜与 9 位小数伪精确？
3. **模型与四情景**：可复算模型、现金/权益桥与手算特例是否通过？四情景是否单调一致、与正文一致且真正联动资本与付款约束？
4. **慢变量结构化完整性**：`decision_profile`（`track`、`valuation_framework`、`industry_topic`、`business_quality`、`capital_allocation`、`predictability`、`downside_risk`、`exposure_tags`、`thesis_breakers`）与 `scenarios` 是否完整、可客观证伪且零股价/买点词汇污染？
5. **独立读者可读性**：按[写作规范](../research-writing.md)检查正文与摘要，确保结论先行、因果连贯、无工作旁白与重复免责声明。

# 历史模型输出格式说明

研究交付统一执行[研究文件与模型交付规范](research-artifacts.md)。新交付使用可读模型、必要输入和简明可再生结果，大小预算按该规范执行。

早期三季报材料使用过 `trading_os_lossless_json_xz_v1`、XZ 分片及验证 ZIP 载荷。这些格式用于保存全量运行状态，已不作为常规模型、测试或网页构建的交付要求。原“全部年份、情景和过程输出必须逐字节保留”的要求停止使用；不得继续以压缩、编码或分片扩张仓库。

整理旧材料时，先辨认当前采用参数、必要输入和真正执行计算的源码，再与报告及结构化结果核对。全量历史输出、失败运行、缓存和快照可保全到工作目录或独立档案；常规复算应使用当前源码树。清理不得静默改变数学、回填空值或把旧失败标记为通过，实质错误沿现有完整研究流程修订。

需要读取原始归档时单独选择维护操作，检查来源、长度和解压范围；普通研究交付无需恢复该归档。此页仅解释迁移边界，不另建发布清单或审批环节。

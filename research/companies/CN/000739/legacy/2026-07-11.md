# 普洛药业（CN:000739）深度研究：CDMO 向上、API 筑底，但买点要等安全边际

## 结论版

### 1. 今日结论

截至 2026-07-11，本研究对普洛药业给出 **watch（观察）**，不是立即重仓买入。公司质量不差，核心看点是小分子 CDMO 项目漏斗、API+制剂一体化、横店体系下的低成本制造和环保合规能力；但当前股价已经隐含 CDMO 持续兑现与 API 周期修复，安全边际一般。

我的判断是：**合理价值区间 18.5-22.5 元/股，买入区间 14.8-16.5 元/股，24 元以上开始降预期或减仓，27 元以上除非有明确订单/利润上修，否则不追。** 2026-07-11 通过东方财富行情接口查询，普洛药业最新价约 18.00 元/股，总市值约 208.5 亿元；行情源为二级数据，非交易所原始行情，置信度中。

逻辑止损不只看价格：若连续两个报告期出现 CDMO 收入增速低于 10%、毛利率跌破 40%、商业化在手订单无增长，或 API 价格战导致公司综合毛利率继续下台阶，应重新评估，即使股价未跌破买入成本也要止损。

### 4. 核心判断

普洛药业不是纯 CDMO，也不是纯原料药。2025 年收入仍以原料药中间体为主，但利润弹性越来越依赖 CDMO。公司 2025 年年报披露：营业收入 97.84 亿元，同比下降 18.62%；归母净利润约 8.91 亿元，同比下降 13.62%；经营性现金流净额 12.20 亿元，同比增长 0.95%。下降主要来自原料药中间体周期和价格压力，而 CDMO 业务逆势增长。

业务结构上，2025 年原料药中间体收入 61.65 亿元，占收入 63.02%，同比下降 28.74%，毛利率 13.53%；CDMO 收入 21.98 亿元，占收入 22.46%，同比增长 16.66%，毛利率 45.24%；药品收入 11.50 亿元，占收入 11.75%，同比下降 8.42%，毛利率 61.55%。这意味着公司估值的关键变量已经从“低估值原料药制造”切换为“CDMO 增长能否覆盖 API 下行”。

最值得重视的正面证据是：截至 2025 年末，公司 CDMO 在研项目 1311 个，同比增长 32%；商业化阶段（含临床三期）项目 398 个，同比增长 12%；研发阶段项目 913 个，同比增长 42%；API 项目 152 个，同比增长 31%；已与 713 家国内外创新药企业签订保密协议，新增 141 家；三年内将交付的商业化在手订单金额超过 60 亿元。来源为公司 2025 年年度报告，置信度高。

最大争议是：这些项目和订单能否持续转化为利润。2025 年 CDMO 毛利率提升到 45.24%，但 API 毛利率仅 13.53%，公司整体仍被低毛利原料药拖累。如果 API 需求和价格继续疲软，CDMO 要保持 20% 以上增长才足以支撑估值扩张。

| 情景 | 2026-2028 关键假设 | 合理估值 | 对应股价 |
|---|---|---:|---:|
| 悲观 | API 价格继续下行，CDMO 增速降至 10%-12%，综合净利 8.5-9.5 亿元 | 16-18 倍 PE | 12-15 元 |

绝对估值采用简化 DCF：以 2026 年自由现金流 9-10 亿元、未来五年复合增速 8%-12%、永续增速 2%、折现率 9%-10% 测算，股权价值大致落在 190-250 亿元，折合每股约 16.5-21.5 元。考虑 CDMO 商业化期权，给予 18.5-22.5 元合理价值区间。该 DCF 对终值和 CDMO 增速敏感，置信度中。

相对估值看，普洛药业应介于传统特色原料药公司与高成长 CDMO 公司之间：高于华海药业、天宇股份等周期性 API 估值，低于药明康德、凯莱英等平台型 CXO 溢价。若市场按“CDMO 成长股”定价，会给 23 倍以上；若重新按“API 周期制造”定价，则 15-18 倍更合理。

## 研究过程

### 1. 公司定位与商业模式

普洛药业注册地位于浙江省东阳市横店江南路 399 号。公司主营业务覆盖创新药研发生产服务（CDMO）、原料药中间体、药品研发生产销售以及进出口贸易。公司最终控制方为东阳市横店社团经济企业联合会；横店集团控股有限公司为母公司，2025 年年报披露其直接持有普洛药业 28.57%，并通过一致行动方间接持有 19.94%。来源：公司 2025 年年度报告，置信度高。

横店集团背景对普洛药业的意义不是简单“背书”，而是工业组织能力。原料药和 CDMO 都是高 EHS、高合规、高周转、高工程化的制造业务，长期竞争不只靠研发故事，还靠车间、工程、安全环保、质量体系、成本管控和客户审计能力。普洛在横店本部、上海浦东、美国波士顿设有 CDMO 研发中心；2025 年年报披露 CDMO 研发人员超过 900 人。这个配置使公司更像“制造型 CDMO”，而不是轻资产研发服务公司。

### 2. 业务结构拆分

2025 年公司收入结构非常清晰：

| 业务 | 2025 收入 | 同比 | 收入占比 | 毛利率 | 研究含义 |
|---|---:|---:|---:|---:|---|
| 原料药中间体 | 61.65 亿元 | -28.74% | 63.02% | 13.53% | 仍是收入底盘，但处于周期底部和竞争压力中 |
| CDMO | 21.98 亿元 | +16.66% | 22.46% | 45.24% | 估值弹性核心，毛利率显著高于 API |
| 药品 | 11.50 亿元 | -8.42% | 11.75% | 61.55% | 高毛利但体量较小，受集采和产品结构影响 |
| 其他 | 2.16 亿元 | +30.03% | 2.20% | 未拆足 | 包含医美化妆品原料等新业务，暂不作为主估值基础 |

来源：普洛药业 2025 年年度报告。上述数据说明，普洛当前最大矛盾是“收入底盘偏周期、利润增量偏成长”。如果只看收入，会低估 CDMO 的利润贡献；如果只看 CDMO，会高估公司整体质量，因为 60% 以上收入仍暴露在低毛利 API 周期里。

### 3. CDMO：订单漏斗是主线

CDMO 是本次研究最核心的资产。公司 2025 年披露 CDMO 收入 21.98 亿元，同比增长 16.66%；毛利 9.94 亿元，同比增长 28.54%；毛利率 45.24%，同比上升 4.18 个百分点。这个组合质量较好：收入增长不是靠牺牲毛利率换来的，而是收入与毛利率同向改善。

项目漏斗方面，公司在研项目 1311 个，同比增长 32%；商业化阶段（含临床三期）项目 398 个，同比增长 12%；研发阶段项目 913 个，同比增长 42%。API 项目 152 个，同比增长 31%，其中 15 个进入商业化阶段，41 个处于验证阶段，96 个处于小试研发阶段。公司同时披露，三年内将交付的商业化在手订单金额超过 60 亿元。

我的理解是：这些数字构成了普洛药业估值从 API 向 CDMO 重估的核心证据。若 60 亿元在三年内顺利交付，年化约 20 亿元量级，接近当前 CDMO 年收入规模；若新商业化项目继续放量，CDMO 板块可能从“增长业务”变成“利润中枢”。但这里也有两个未核验点：第一，公司未逐项披露订单客户、药物阶段和取消条款；第二，在手订单并不等于最终收入和利润，交付节奏、客户研发成败、监管审批、汇率都会影响兑现。

### 4. 原料药：不是坏业务，但周期位置仍压估值

原料药中间体 2025 年收入下降 28.74%，毛利率降至 13.53%。公司解释包括外部宏观环境复杂、行业周期底部徘徊、相关品种需求疲软、行业竞争激烈。这个表述比较重要：它不是一次性扰动，而是行业供需和价格周期。

普洛在 API 端仍有优势品种和全球销售网络。年报披露，公司 API 包括头孢系列、青霉素系列、精神类、心脑血管类、兽药原料药中间体等，产品远销 70 余个国家和地区；国外市场主要分布于欧洲、北美、东亚日韩、南亚印巴、东南亚、南美等区域。公司还披露拥有 11 套污水生化处理系统、年处理能力 540 万吨，15 套废气蓄热氧化系统等环保设施。来源：2025 年年报，置信度高。

API 业务的买方看点不是高成长，而是“底部现金牛+合规产能”。环保、安全、注册和客户审计抬高进入门槛，小厂退出或海外供应链重构时，头部企业会受益。但 2025 年数据说明，至少到年报时点，价格压力还没有完全消失。

### 5. 制剂：提供协同，不单独给高估值

2025 年药品业务收入 11.50 亿元，同比下降 8.42%；毛利率 61.55%，同比提升 0.74 个百分点。公司披露拥有 120 多个制剂品种，主要包括抗感染、心脑血管、精神类、抗病毒类等；2025 年共有 8 个国内制剂产品获批上市，1 个制剂产品安非他酮缓释片获得美国 FDA 注册批准；完成 14 个 API 品种 DMF 申报及 19 个制剂品种 ANDA 申报。

制剂业务的战略价值在于 API+制剂一体化，可以提高 API 客户粘性，也能为部分品种延伸价值链。但从买方角度，我暂时不把制剂作为独立重估主线，原因是集采、医保控费和仿制药竞争仍会压制估值，且当前体量不足以决定公司整体利润趋势。

### 6. 行业与竞争

普洛所处赛道有三层竞争：

第一层是传统特色原料药，核心竞争者包括华海药业、天宇股份、司太立、奥翔药业等。竞争维度是注册能力、成本、环保合规、客户认证、产品组合和价格周期。

第二层是 CDMO/CXO，竞争者包括凯莱英、博腾股份、九洲药业、药明康德合全药业、联化科技等。普洛相对优势是原料药制造底盘、成本和工程能力，短板是平台品牌和全球大客户广度仍需验证。

第三层是 API+制剂一体化，竞争者包括华海药业、浙江医药、部分特色仿制药公司。普洛的优势是“原料药+CDMO+制剂”组合，风险是资源分散，资本开支和管理复杂度更高。

3-5 个重点可比：

| 公司 | 相对普洛的意义 | 普洛相对位置 |
|---|---|---|
| 九洲药业 | 小分子 CDMO 与特色 API 可比 | 普洛 CDMO 增速和项目数有看点，但品牌溢价通常低于九洲 |
| 博腾股份 | CDMO 周期弹性可比 | 普洛收入结构更分散，波动可能小，但 CDMO 纯度也较低 |
| 凯莱英 | 高端小分子 CDMO 标杆 | 普洛估值不应直接对标凯莱英高峰期倍数 |
| 华海药业 | API+制剂一体化可比 | 普洛 CDMO 占比和订单漏斗更有弹性 |
| 天宇股份 | 原料药周期可比 | 普洛业务更综合，抗单一品种周期能力更强 |

### 7. 财务质量

2025 年公司营业收入 97.84 亿元，同比下降 18.62%；归母净利润约 8.91 亿元，同比下降 13.62%；扣非归母净利润约 7.69 亿元，同比下降 21.86%；经营性现金流净额 12.20 亿元，同比增长 0.95%；基本 EPS 0.7723 元；加权 ROE 约 13.22%；期末总资产 123.18 亿元，归母净资产约 63.38 亿元。来源：2025 年年报，置信度高。

2026 年一季度，东方财富数据中心显示公司营业总收入 24.47 亿元，同比下降 10.36%；归母净利润 2.49 亿元，同比增长 0.19%；扣非归母净利润 2.43 亿元，同比增长 18.15%；基本 EPS 0.2152 元。该数据源标注报告期 2026-03-31、公告日期 2026-04-21。由于本次未取得交易所公告 PDF 原文，置信度中。

财务结论：普洛现金流比利润更稳，说明制造业务仍有现金创造能力；但收入下滑幅度较大，利润稳定主要依赖成本、费用和结构改善。若 2026 年后续季度收入仍下降，市场会降低对 CDMO 增长的定价。

### 8. 治理与横店集团背景

横店集团背景带来两面性。正面是产业资源、园区制造、能源环保、公用配套、工程管理和长期资本支持；负面是关联交易和集团体系内治理折价。年报披露多项同一最终控制方关联方，如热电、水务、污水处理、酒店、医院、影视、东磁等。2025 年披露横店集团控股有限公司直接及间接合计控制普洛药业约 48.51%。来源：2025 年年报，置信度高。

我暂未看到需要直接否定投资的治理红旗，但估值上不应给过高治理溢价。跟踪重点是关联采购定价、公用工程成本、少数股东损益、董事高管是否持续稳定，以及资本开支回报率。

### 9. 海外客户、汇率与政策

海外是普洛的重要变量。2025 年国外收入 43.36 亿元，占收入 44.32%，同比下降 19.53%。公司披露 CDMO 国外市场主要分布在欧洲、北美、日本等国家和地区；API 国外市场覆盖欧洲、北美、日韩、东南亚、南美等。来源：2025 年年报。

海外收入带来两类风险：一是汇率，公司年报明确提示出口业务主要以外币结算，汇率波动会带来汇兑损益；二是地缘与供应链政策，全球供应链重构既可能给中国制造型 CDMO 带来份额，也可能带来客户合规审查和订单迁移风险。

国内政策方面，制剂业务面对集采和医保控费，API 业务面对环保安全监管，CDMO 面对全球创新药融资周期和监管审计。普洛的优势是合规产能和客户审计经验，年报披露 2025 年接受国内外客户审计 242 次；但一旦出现环保、安全或质量事件，估值会迅速收缩。

### 10. 风险清单

1. API 价格周期继续下行，原料药毛利率跌破 12%。
2. CDMO 商业化订单交付不及预期，在手订单取消或递延。
3. 海外客户拓展受地缘政治、监管审查或供应链本土化影响。
4. 汇率大幅波动导致汇兑损益侵蚀利润。
5. 环保、安全生产、质量体系出现事故或监管处罚。
6. 医药政策压制制剂价格，API+制剂一体化收益低于预期。
7. 资本开支过快，新增产能利用率不足。
8. 横店集团关联交易或治理折价扩大。
9. 竞争者降价抢单，CDMO 毛利率从 45% 回落。
10. 市场按传统 API 周期股重新定价，估值倍数下移。

### 11. 跟踪指标

- CDMO 收入同比增速：低于 10% 是预警，20% 以上是确认。
- CDMO 毛利率：40% 以下需重新评估，45% 以上说明结构较强。
- 商业化阶段项目数和三年内在手订单：是否继续增长。
- API 毛利率：13% 是当前低位参考，若回升至 15%-17% 会改善估值。
- 国外收入占比与汇兑损益：判断海外客户和汇率影响。
- 经营性现金流净额/净利润：低于 0.8 倍需警惕回款和库存。
- 研发费用率：2025 年研发投入占收入 6.74%，若过度下降会影响长期竞争力。
- 环保、安全、FDA/客户审计公告：任何重大负面都应立即复查。
- 资本开支和在建工程：判断订单是否带来有效利用率。
- 关联交易金额和定价说明。

### 12. 复查重点

下一次必须复查 2026 年中报，重点不是单看净利润，而是看三个问题：第一，CDMO 是否继续高于公司整体增长；第二，API 毛利率是否见底；第三，经营现金流是否继续覆盖净利润。如果这三个问题同时为正，当前 18 元附近可以从观察转为小仓买入；如果只有利润增长但收入继续下滑，应把利润改善视为低质量修复。

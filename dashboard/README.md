# Trading OS 可视化研究台

这是 `coverage/cn-a/research_state.jsonl` 和正式研报的只读可视化投影。它不维护第二套研究状态，也不修改研究队列、自选池或研报正文。

## 产品结构

- **研究决策台**：第一屏回答“今天先看什么”，把 `covered` 公司按复核优先级排序；同页下方可切换到 5,552 家公司的全市场状态表。
- **研报库**：独立阅读工作台，左侧按公司、代码、行业和状态搜索，正文区阅读当前或历史正式版本，右侧显示章节目录。
- **行动信号**：顶部集中显示已覆盖、进入复核区、候选研究和等待更新四类需要关注的状态。

隔离在 `legacy/` 的旧稿不会进入目录、排序或研报搜索。

## 复核优先级

默认排序不是投资评级，也不输出买入动作：

```text
复核优先级 = 55% × 关注价距离 + 35% × 合理价值区间位置 + 10% × 报告新鲜度
```

现价进入关注区时优先展示；没有价格线的事件型公司保留在机会池，但不会被伪造一个“低估”结论。页面始终展示关注价、合理价值区间和排序说明，方便追溯。

## 行情策略

- 腾讯行情是现价主源；
- 腾讯缺失时，自动使用东方财富备援；
- 两个外部源均不可用时，页面退回研究状态中最近一次经过验证的收盘价，并明确标注日期。

行情只用于页面展示和复核排序，不会触发或修改仓库中的每日收盘状态机。

## 本地运行

在 `dashboard/` 目录执行：

```bash
npm install
npm run dev
```

启动和正式构建前会自动从仓库唯一事实源生成只读目录。运行 `npm test` 会同时验证构建、主要页面和数据投影。

## 后续产品路线

首版刻意不做组合、仓位和交易功能。更值得追加的是：公告变化收件箱、研报版本差异、价格触发历史和可保存的个人筛选视图。它们都应继续以现有状态文件为唯一事实源。

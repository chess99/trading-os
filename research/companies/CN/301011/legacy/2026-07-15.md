# 华立科技（301011）初始深度研究：不追高，等待利润修复被验证

## 结论先行

投资结论：观察，不买入。华立科技是 A 股稀缺的商用游戏游艺设备与 IP 衍生品公司，具备“设备发行 + IP 卡片/衍生品 + 合作运营 + 自营场地”的产业链闭环，2025 年仍能实现约 9.97 亿元收入和约 0.69 亿元归母净利润。但 2026Q1 收入同比下降 17.27%，归母净利润亏损 1048.23 万元，说明设备更新、游乐场运营成本和 IP 衍生品增速之间的平衡尚未稳住。

估值结论：以 2026-07-15 新浪行情收盘后字段显示的最新价 14.36 元/股、公司 2025 年报分红预案口径总股本 154,352,959 股估算，市值约 22.16 亿元；对应 2025 年归母净利润 PE 约 32.1 倍、对应 2026Q1 期末归母净资产 PB 约 2.33 倍。结合相对估值、DCF 与情景估值，当前合理价值区间约 11.5-15.5 元/股，买入区间约 9.0-11.0 元/股，18.0 元以上应考虑减仓。当前价格大致落在合理区间中部，但没有足够安全边际。

核心矛盾：这是“好资产雏形”而不是“已证明的高 ROE 成长股”。真正的买点需要看到 2026 年中报或三季报确认：IP 衍生品维持增长、游乐场运营毛利率改善、经营现金流转正，且净利润恢复到年化 7000-9000 万元以上。

## 业务画像

华立科技的业务不是单纯“卖街机”。公司披露自己是国内商用游戏游艺设备发行与运营综合服务商，业务覆盖设备设计、研发、生产、销售、合作运营、自营游乐场及动漫 IP 衍生品。

第一条线是游戏游艺设备销售，典型产品包括《雷动摩托 X》《极品飞车》《明日行动》《音乐魔方》《太鼓之达人》《舞萌 DX》等。该业务决定公司行业地位和渠道粘性，但也受下游门店资本开支、爆款设备周期和海外授权套件供给影响。2025 年销售量 8161 台，同比 -18.62%；2026Q1 设备收入继续下滑 32.47%，说明该业务目前处于压力段。

第二条线是动漫 IP 衍生品。公司通过向游乐场门店投放动漫卡通设备，并持续销售卡牌、手办等 IP 衍生品获取收入。2025 年该板块收入同比增长 12.97%，毛利率 40.31%，是当前利润结构里最值得跟踪的部分。公司 2025 年推出《三国幻战》TCG 卡牌，并完成对潮玩与 IP 创意设计公司 PlayLab 的并购，意图把渠道从游乐场延伸到零售终端。

第三条线是运营服务。设备合作运营毛利率高、收入增长快，但规模仍小；游乐场运营规模更大，却在 2025 年和 2026Q1 分别录得 -5.94% 和 -33.54% 毛利率，是利润拖累项。若自营场地不能从展示窗口转为稳定现金流单元，它会削弱设备与 IP 业务的 ROIC。

## 行业判断

行业需求来自三类场景：购物中心体验消费、亲子娱乐和年轻人线下社交。政策层面对规范经营和文旅消费有支持，但游戏游艺设备需要内容审核、机型公示和电子标识，监管边界清晰，灰色设备和未审核设备不能作为长期需求假设。

行业的核心不是总量高速扩张，而是内容和 IP 驱动的结构升级。传统设备更新依赖门店资本开支，天然有周期；卡牌、音游、IP 衍生品则更接近“线下内容运营”，有更高复购率和社群黏性。华立科技如果能把《舞萌 DX》《太鼓之达人》这类代理发行能力，叠加宝可梦、三国幻战、我的世界等 IP 衍生品运营能力，盈利质量会改善。

但行业也有显著天花板：线下点位有限，设备折旧和租金刚性高，爆款生命周期不稳定，进口/代理 IP 分成条款未公开。与纯线上游戏公司相比，华立科技更重资产、更慢周转；与传统文旅设备公司相比，又更依赖内容更新和年轻玩家社群。

## 护城河

华立科技的护城河主要有四层。

第一是渠道和点位网络。公司长期服务游艺游乐场所、主题乐园、购物中心门店，并通过设备合作运营和自营门店获得一线运营数据。该数据能反哺产品选型和研发，但是否能形成数据壁垒仍需更多证据。

第二是 IP 与代理资源。公司年报列示了《太鼓之达人》《舞萌 DX》《宝可梦明耀之星》《我的世界地下城》《三国幻战》等产品或衍生品。近期宝可梦线下游艺合作若能落地，将增强公司在高价值 IP 方眼中的渠道价值。

第三是行业标准和合规能力。公司披露其参与《游戏游艺机产品规范》等国家/行业标准和多项团体标准起草，并拥有 160 项专利、196 项软件著作权、217 项美术作品登记。对监管要求较高的商用游艺设备行业，合规经验本身是门槛。

第四是产业链闭环。设备销售、IP 衍生品、合作运营、自营门店可以相互导流。但这也是双刃剑：闭环越完整，管理复杂度越高；一旦自营场地亏损扩大，闭环会从优势变成利润黑洞。

## 增长路径

短期增长看 2026 年下半年设备收入能否企稳。2026Q1 设备销售收入下降 32.47%，如果中报仍未修复，全年利润中枢要下调。

中期增长看 IP 衍生品的复购。2025 年 IP 衍生品收入 3.69 亿元，毛利率 40.31%，已经接近设备销售规模。若该板块维持 10%-20% 增速，并保持 38% 以上毛利率，公司利润弹性会明显好于收入弹性。

长期增长看海外和高势能 IP。2025 年境外收入 1.68 亿元，同比 +25.00%，毛利率 40.04%，优于境内。海外能否持续增长，取决于代理权、渠道伙伴和本土合规。宝可梦线下游艺合作是潜在重要变量，但截至本报告日，收入确认节奏、投放规模、分成方式均未核验。

## 财务质量

2025 年公司收入小幅下滑但仍有利润，经营现金流净额 1.03 亿元高于净利润，表面质量尚可；但现金流同比下滑 52.03%，且公司解释主要因支付供应商货款、职工薪酬及经营费用增加。2026Q1 经营现金流仍为 -3882 万元，季节性与备货因素存在，但仍需警惕。

利润结构的好坏分明。IP 衍生品和设备合作运营毛利率较高，能够支撑估值；游乐场运营毛利率持续为负，2026Q1 进一步恶化至 -33.54%，是最大扣分项。若管理层把自营门店作为展示和数据资产，市场可以容忍小亏；若亏损规模扩大，则应按零售/游乐场重资产模式降估值。

研发投入 2025 年为 4163 万元，占收入 4.17%，研发人员 96 人，占员工比例 14.14%。这对设备、卡牌玩法、虚幻引擎竞速产品、亲子体感产品有支撑，但研发费率仍不高，公司更像内容发行和运营平台，不应按高研发软件公司估值。

供应链集中度偏高。2025 年前五大供应商采购额 4.19 亿元，占年度采购总额 60.24%，第一大供应商占 23.88%。公司部分核心部件和海外套件采购周期较长，若授权方、进口部件、汇率或供应商议价变化，毛利率可能波动。

## 治理与股东

股权结构集中。2026Q1 末香港华立国际持股 41.85%，苏本立为其实际控制人并直接持股 1.86%，苏本立与香港华立国际为一致行动关系。集中控制有利于长期战略执行，但也要求投资者持续观察关联交易、担保、并购和股权激励是否公平。

外部产业股东有一定价值。鈊象电子持股 2.77%，新迅达持股 1.91%。鈊象电子是台湾游戏游艺内容与机台公司，作为股东对产业协同有想象空间，但具体合作深度未核验，不能简单视为强绑定。

2025 年公司存在股份支付，扣除股份支付影响后的净利润为 7560.54 万元；2026Q1 扣除股份支付影响后仍亏损 829.90 万元。股权激励能否真正绑定增长，应看收入、利润和现金流目标，而不是只看股价弹性。

1. 鈊象电子（IGS，3293.TWO）：台湾商用游戏游艺机与内容公司，华立科技年报将其列为行业相关公司，且其为华立科技股东。其优势在内容研发和产品生命周期，华立优势在大陆渠道和合规落地。

5. 线下场地运营商，如城市英雄、风云再起、星际传奇、永旺幻想、天空之城等：这些更偏下游渠道与场地运营，既是客户也可能在自有设备、IP 活动和门店运营上构成竞争。华立自营游乐场扩大后，与客户之间的边界需要观察。

## 估值

相对估值：以 2025 年归母净利润 6905 万元、市值约 22.16 亿元计算，PE 约 32.1 倍；以 2026Q1 期末归母净资产 9.51 亿元计算，PB 约 2.33 倍。考虑 2026Q1 已亏损，不能用静态 PE 机械判断便宜。若公司恢复到 8000-9000 万元净利润，当前对应 24.6-27.7 倍 PE，仍需要 IP 成长来证明。

绝对估值：采用保守 FCFE/DCF 框架，假设 2026 年为修复年，2027 年起自由现金流恢复到 7000-9000 万元，长期增速 2%-3%，权益资本成本 10%-11%，得到权益价值约 17-24 亿元，对应约 11.0-15.5 元/股。若游乐场运营继续亏损、营运资本占用扩大，DCF 下沿应降到 9 元附近。

情景估值：

- 悲观：2026 年收入继续下滑，游乐场运营亏损扩大，归母净利润仅 3000-4500 万元，给 18-22 倍 PE，权益价值约 5.4-9.9 亿元，对应 3.5-6.4 元/股。
- 基准：2026 年下半年修复，2027 年净利润回到 8000-9000 万元，给 23-27 倍 PE，权益价值约 18.4-24.3 亿元，对应 11.9-15.7 元/股。
- 乐观：IP 衍生品和海外持续增长，游乐场运营止亏，2027 年净利润 1.2-1.4 亿元，给 25-30 倍 PE，权益价值约 30-42 亿元，对应 19.4-27.2 元/股。

交叉验证后，本次给出合理价值区间 11.5-15.5 元/股，买入区间 9.0-11.0 元/股，减仓区间 18.0-22.0 元/股。当前价格处于合理区间内，不满足深度买方安全边际要求。

## 安全边际

安全边际来自三个折扣：一是 2026Q1 亏损对全年盈利可见度的折扣；二是游乐场运营负毛利的折扣；三是 IP 授权和爆款生命周期不确定性的折扣。

若以基准合理价值中枢约 13.5 元/股看，当前 14.36 元没有折价。只有价格跌至 11 元以下，或中报确认利润修复且合理价值上移到 18 元以上，才会出现值得行动的风险收益比。

## 主要风险

1. 设备销售继续下滑：下游门店投资意愿弱，导致设备销售收入和工厂利用率下降。
2. 自营游乐场亏损扩大：租金、人工、折旧和客流不足可能持续拖累利润。
3. IP 授权不确定：核心 IP 授权续约、分成条款、投放节奏未完全公开。
4. 供应商集中：前五大供应商采购占比 60.24%，若核心部件供应或价格波动，毛利率承压。
5. 监管与内容审核：游戏游艺设备需符合内容审核和电子标识要求，政策执行变化会影响新品上线。
6. 商誉/并购整合风险：PlayLab 并购后的协同尚需验证，潮玩零售渠道延伸可能带来库存风险。
7. 小市值流动性与估值波动：股价可能受主题、IP 消息和情绪驱动，偏离基本面。

## 跟踪指标

- 2026 年中报：收入是否恢复同比增长，归母净利润是否回正。
- IP 衍生品收入：是否维持双位数增长，毛利率是否保持 38% 以上。
- 游乐场运营毛利率：是否从 2026Q1 的 -33.54% 明显修复，全年能否接近盈亏平衡。
- 设备销售：销售量、库存量和设备毛利率是否企稳。
- 经营现金流：中报和三季报经营现金流是否转正，且不依赖应付账款扩张。
- 宝可梦合作：是否披露正式产品上线、投放门店数、商业模式和收入确认方式。
- 海外收入：境外收入增速是否维持 20% 左右，毛利率是否保持高于境内。
- 供应商集中度：前五大供应商占比是否下降，核心套件采购是否更稳定。

## 操作计划

当前评级为观察。价格低于 11 元且未出现基本面恶化时，可建立 1%-2% 试探仓；价格低于 9.5 元且中报确认经营现金流改善、IP 衍生品继续增长时，可提高到 3% 上限。若价格高于 18 元但盈利修复未被验证，应减仓或不参与；若价格高于 22 元，除非宝可梦等新 IP 已经实质贡献利润，否则风险收益比明显恶化。

若 2026 年中报仍亏损、游乐场运营毛利率低于 -15%、设备销售继续双位数下滑，则评级应从观察下调至不买。

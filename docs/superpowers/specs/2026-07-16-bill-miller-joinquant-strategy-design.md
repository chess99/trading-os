# 比尔·米勒风格聚宽纯量化策略设计

日期：2026-07-16

## 目标

在聚宽策略环境中实现一份可以直接回测的单文件 Python 策略。策略不尝试机械复刻
投资人的主观判断，而是把比尔·米勒式价值投资中可观测、可回测的部分转化为规则：

- 不把低 PE、低 PB 当作买入结论；
- 以市场价格隐含预期和可实现基本面之间的差异作为主要收益来源；
- 同时衡量自由现金流、资本回报、再投资效率和会计脆弱性；
- 允许高估值、暂时亏损和非传统价值公司进入候选池；
- 使用集中持仓、低换手和基于基本面而非价格的退出纪律。

交付物放在 `strategies/joinquant/bill_miller_quant.py`。它是聚宽平台专用、可独立复制
运行的策略，不并入 `src/trading_os/`，因为当前 Python 包只负责研究资产管理，不提供
本地交易或回测引擎。

## 核心取舍

### 保留的米勒式逻辑

1. 股票是未来现金流的所有权，而不是静态估值倍数。
2. 高估值不自动排除，低估值也不自动入选。
3. 市场可能把临时问题永久化，也可能把成长过度确定化。
4. 组合应集中于赔率最高的少数标的，不以贴近指数权重为目标。
5. 价格下跌不触发机械止损；基本面恶化、赔率消失或出现更优机会才触发退出。

### 舍弃或代理化的逻辑

- 护城河、管理层诚信、技术替代和政策影响无法仅凭聚宽结构化数据可靠判断，策略不
  伪造这些结论。
- 管理层资本配置用增量资本回报、现金分红、融资依赖和股本扩张代理。
- 市场叙事用相对估值、历史估值、价格回撤和基本面变化之间的背离代理。
- 情景概率不由主观打分给出，改用分位数排名和风险惩罚表达不确定性。
- 不为每家公司建立精细 DCF；使用可横截面比较的反向估值代理，避免模型假设主导结果。

## 运行范围

### 历史股票池

每次调仓以调仓日前一个交易日为观察日，通过 `get_all_securities(['stock'], date=...)`
取得当时已经上市的 A 股，避免使用今天的股票列表回测过去。股票必须满足：

- 上市至少 500 个自然日，使最近三年财务趋势有基本可用性；
- 非 ST、`*ST`、退市整理或已退市标的；
- 调仓时未停牌；
- 最近 20 个交易日日均成交额不低于 2,000 万元。

小市值、阶段性亏损、低换手和短期下跌不是硬排除理由。成交额门槛只用于保证组合在
默认回测资金规模下具备基本可成交性。

### 公司模型

候选公司分为三类，各自内部排名，最后合并：

1. **普通非金融企业**：使用自由现金流、资本回报、估值和会计质量模型。
2. **金融企业**：银行、保险、券商使用 PB、ROE、盈利质量和杠杆代理模型，不套用
   普通企业的自由现金流公式。
3. **亏损成长企业**：最近一期净利润或自由现金流为负，但收入增长、毛利率和现金储备
   满足生存条件的企业，使用 EV/Sales、增长质量、毛利率趋势和现金跑道模型。

模型分类只决定评分口径，不预先分配固定仓位。最终仍按可比的 0 到 100 综合分竞争。

## 数据时点纪律

- 初始化时调用 `set_option('avoid_future_data', True)` 和
  `set_option('use_real_price', True)`。
- 所有财务查询使用观察日 `date`，不使用可能提前泄漏未披露财报的 `statDate`。
- 历史趋势使用 `get_history_fundamentals(..., watch_date=观察日)`；如果策略环境兼容性
  或批量限制导致该接口失败，则退化为按观察日查询最近可见数据，不使用未来报告期补齐。
- 当天收盘后才更新的估值字段不用于当天开盘前的决策。
- 调仓在每月第一个交易日 10:00 执行，排序使用前一个交易日可见的数据和行情。

## 特征工程

所有横截面特征先把无穷值转换为空值，再进行 5%/95% 分位缩尾。有效样本不足 20 只
时不计算该特征。之后在公司模型内部转换为 0 到 100 的百分位分数；风险指标反向计分。

### 普通非金融企业

自由现金流定义为：

```text
FCF = 经营活动现金流净额
      - 购建固定资产、无形资产和其他长期资产支付的现金
```

使用以下特征：

- FCF 收益率：最近年度 FCF / 总市值；
- 现金利润转换率：经营现金流 / 归母净利润；
- 三年 FCF 稳定性：最近三年正 FCF 年数占比；
- ROIC 代理：税后经营利润 / 平均投入资本；
- ROE 和 ROA；
- 收入三年复合增长率；
- 增量资本回报：三年营业利润变化 / 三年投入资本变化；
- 净负债率；
- 应收账款增速减收入增速；
- 存货增速减收入增速；
- 扣非净利润 / 归母净利润；
- 当前 PE、PB、PS、PCF 相对同行和自身经营质量的合理性；
- 最近 12 个月相对行业收益与基本面变化的背离。

当分母为负、接近零或经济含义失真时，对应特征记为空值，不用极端数值奖励公司。

### 金融企业

金融企业不计算普通企业 FCF 和净负债率。使用：

- PB 的行业内反向百分位；
- ROE、ROA；
- 扣非盈利质量；
- 净利润三年稳定性和增长率；
- 经营现金流仅作弱质量信号，不作为硬门槛；
- 当前 PB 相对“ROE 水平和增长率”残差，作为市场预期差代理；
- 最近 12 个月回撤与 ROE 变化之间的背离。

不同金融子行业只在自身二级行业内比较，避免银行、券商和保险直接横比。

### 亏损成长企业

亏损成长模型必须同时满足：

- 最近年度营业收入为正；
- 最近三年收入复合增长率为正；
- 毛利率为正，且最近一年没有下降超过 10 个百分点；
- 货币资金能够覆盖最近年度现金消耗至少 18 个月；
- 资产负债率低于 70%；
- 最近一年没有出现收入增长而经营现金流和毛利率同时显著恶化。

评分特征包括 EV/Sales 代理、收入增长率、毛利率水平和趋势、现金消耗改善率、现金跑道、
股本稀释风险及 12 个月价格回撤。负 PE 不参与评分，也不被当作低估值。

## 评分模型

每个模型输出以下五个子分数：

| 子分数 | 权重 | 含义 |
|---|---:|---|
| 市场预期差 | 35% | 价格所反映的悲观程度是否超过基本面恶化程度 |
| 长期经济质量 | 25% | 现金流、利润率、增长质量和经营稳定性 |
| 资本回报 | 15% | ROIC、ROE、ROA 或金融企业相应代理 |
| 会计与资产负债表风险 | 15% | 应收、存货、扣非、杠杆、融资及稀释风险 |
| 基本面未坏的逆向程度 | 10% | 股价回撤而核心经营指标保持稳定的程度 |

```text
综合分 = 0.35 × 市场预期差
       + 0.25 × 长期经济质量
       + 0.15 × 资本回报
       + 0.15 × 会计质量
       + 0.10 × 逆向程度
```

一个子分数至少需要半数底层特征有效，否则该公司本次不参与排名。缺失特征按该模型
有效样本的中位数处理，避免单纯因为数据缺失得到高分或低分。

## 风险否决

满足任一条件时，公司不能新买入；已持仓公司在可交易时退出：

- ST、退市风险或已暂停上市；
- 最近一期总负债超过总资产；
- 普通企业最近三年经营现金流全部为负且收入没有持续增长；
- 普通企业经营现金流、毛利率和收入三项中至少两项同比显著恶化；
- 应收账款或存货增速连续显著高于收入增速；
- 亏损成长企业现金跑道不足 18 个月；
- 财务数据不足以计算至少三个子分数。

风险否决不包含固定跌幅止损。

## 组合构建

- 目标持仓数：20 只；有效候选不足时允许持有现金。
- 初始建仓：从综合排名前 20 中建立最多 20 个仓位。
- 后续新买入：只从综合排名前 15 中按顺序补充；如果没有合格新标的，允许组合暂时
  少于 20 只并持有现金。
- 继续持有：仍在前 40 且未触发风险否决。
- 退出：跌出前 40、风险否决、或因估值上升使综合分显著下降。
- 单股目标权重下限 2%，上限 8%。
- 单个聚宽一级行业目标权重不超过 25%。
- 金融企业合计权重不超过 30%，亏损成长企业合计权重不超过 20%。
- 权重基础值为综合分减去入选阈值后的正值，再按下行风险调整；调整后的权重归一化，
  依次应用单股和行业约束。无法分配的资金保留为现金。

下行风险由最近 252 个交易日波动率、最大回撤、资产负债表风险和财务波动共同构成。
策略不调用依赖付费权限或版本差异较大的聚宽组合优化器，以保证脚本可移植性。

## 交易执行

- `initialize` 设置中证全指 `000985.XSHG` 为基准、真实价格、未来数据保护、滑点和 A 股
  手续费，注册月度调仓函数。
- 调仓前使用 `get_current_data()` 排除停牌、ST、涨跌停不可成交标的。
- 先卖出退出标的，再按目标权重买入或调整持仓。
- 涨停股票不买入，跌停股票不假设能够卖出；未成交仓位留到下一次月度调仓，不在盘中追单。
- 使用 `order_target_value` 下单，目标市值低于一手时跳过。
- 单次调仓异常记录到日志；单只股票数据异常只淘汰该股票，不中断整个组合计算。

## 文件与代码边界

### `strategies/joinquant/bill_miller_quant.py`

单文件包含以下部分：

1. 参数常量和聚宽生命周期函数；
2. 历史股票池、可交易性和行业分类；
3. 财务数据获取与标准字段转换；
4. 无聚宽依赖的纯计算函数；
5. 三类公司评分器；
6. 候选合并、持仓缓冲和权重约束；
7. 下单与日志。

聚宽平台要求策略为单文件，因此不把生产策略拆成多个模块。纯计算函数保持对普通 Python
数据结构和 pandas 对象工作，便于本地测试。

### `tests/test_bill_miller_joinquant_strategy.py`

测试通过 `importlib` 导入策略文件，只验证无聚宽运行时依赖的纯计算部分。聚宽 API 调用
集中在边界函数中，本地不伪造完整平台。

## 测试策略

本地单元测试覆盖：

- 分位缩尾和百分位评分正确处理空值、无穷值、相同值和小样本；
- 自由现金流、现金跑道、ROIC 代理和增长率的边界情况；
- 三类模型的有效性门槛、风险否决和综合分；
- 初始前 20 建仓、后续前 15 新买、前 40 保留的持仓缓冲；
- 单股、行业、金融和亏损成长仓位约束；
- 候选不足时保留现金；
- 聚宽脚本能被 Python 编译，且没有仓库内包依赖。

本地验证命令：

```bash
pytest tests/test_bill_miller_joinquant_strategy.py -q
ruff check strategies/joinquant/bill_miller_quant.py tests/test_bill_miller_joinquant_strategy.py
python -m py_compile strategies/joinquant/bill_miller_quant.py
```

平台验收需要把策略文件复制到聚宽，至少运行一次覆盖多个财报期的日频回测。建议初次验证区间
为 2016-01-01 至最近可用交易日，并与中证全指、低 PE/PB 基线和质量价值基线比较：年化
收益、最大回撤、换手率、持仓集中度、行业暴露、盈利归因和分年度表现都必须检查。不能只用
全区间收益率判断策略有效。

## 非目标

- 不接入外部新闻、公告文本、研报、LLM 或本仓库公司研究结论；
- 不实现分钟级择时、技术指标交易、止损止盈或融资融券；
- 不宣称该策略能够复刻比尔·米勒的主观投资能力；
- 不恢复仓库已经移除的通用回测、实盘和数据提供商框架；
- 不根据一次回测结果自动调整权重或筛选阈值。

## 完成标准

1. 聚宽策略文件可直接复制到策略编辑器并通过语法检查。
2. 本地纯计算测试和 Ruff 检查通过。
3. 策略严格使用历史时点股票池和当时可见财务数据。
4. 普通、金融、亏损成长三类企业均有明确且不同的评分口径。
5. 组合遵守持仓缓冲、单股上限、行业上限和类型上限。
6. 数据不足、候选不足和不可交易状态不会导致策略整体崩溃或强行满仓。

# Trading OS 可视化研究台

这是仓库研究资产的只读附属展示，不是 Trading OS 的主要产品。它不维护第二套研究状态，也不修改研究队列、自选池、研究日志或正式报告。

## 产品结构

- **价值区间视图**：列出 active `covered` 公司，机械展示实时价格与 `value_range` 下沿、中枢的比值；
- **全市场状态表**：浏览全部公司的当前研究状态；
- **研报库**：搜索公司并阅读当前或历史正式报告。

`legacy/` 旧稿不会进入目录、排序或研报搜索。

## 价格展示边界

默认排序只使用：

```text
当前实时价格 / value_range.low
```

有实时行情和价值区间的公司按这一比值从低到高排序；缺少任一项的公司放在后面。页面同时展示 `当前价格 / value_range 中枢` 和“低于区间下沿 / 区间内 / 高于区间上沿”的机械描述。

这里没有复核分数、关注价、深度复核价、价格触发器或买入信号。“低于区间下沿”只陈述两个数字的关系，不代表安全边际充分，也不授权资本投入。

## 行情策略

- 腾讯行情是实时价格主源；
- 腾讯缺失时使用东方财富备援；
- 两个外部源均不可用时显示 `—`。

行情不会写回仓库，也不会触发研究、修改研究状态或创建任务。仓库中没有可供回退的收盘价运行状态。

## 本地运行

在 `dashboard/` 目录执行：

```bash
npm install
npm run dev
```

启动和正式构建前会从仓库唯一事实源生成只读目录。`npm test` 会验证构建、页面和数据投影。

## 后续产品路线

可以继续增加公告变化收件箱、研究日志浏览、正式报告版本差异和个人筛选视图。它们都应继续读取现有仓库资产，不得反向引入第二套状态、组合动作或价格触发体系。

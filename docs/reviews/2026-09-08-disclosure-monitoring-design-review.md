# 财报检查、非财报审阅与价值质量池：可行性审阅

日期：2026-09-08。代码和池快照：`df93923ceaf493b23f572a0ff9b39a9398b07ebb`。本次是只读核查、历史回放与方案讨论，没有实现或启用新的监控，没有改变公司研究或质量池。用户已手动暂停旧扫描任务。

## 判断

财报发现能够机械化，已有接口和数据足以支撑，但目前代码还不是可以无人维护的可靠检测器。非财报重要性不能靠关键词可靠解决，应将关键词降为辅助路由，保留公司背景下的语义审阅。现有独立价值质量池适合承接低频商业质量筛选，建议年报后主复核、半年报后补充复核，不必每季度重做全市场；当前名单的池外遗漏和材料深度仍需补足。

## 一、财报机械化：验证了什么

本次直接调用现有巨潮抓取实现，按公司和自然日读取历史窗口，成功定位三个交易所样本的已知半年报全文条目及链接：

|---|---|---|
| 美的集团，深交所 | 1225531404 | 2026-08-29 |
| 贵州茅台，上交所 | 1225475868 | 2026-08-15 |
| 戈碧迦，北交所 | 1225514441 | 2026-08-26 |

另读取东方财富美的公告索引，其类别明确区分“半年度报告全文”（`001001001002001`）和“半年度报告摘要”（`001001001002002`），各有独立公告 ID。因此发现新报告不必理解公司经营，也不必让 Agent 阅读每份公告。

这是三个样本的在线索引查询验证，本次未下载并逐页核验 PDF，也不是全市场可用性证明。其中一个查询耗时约 32 秒，说明小窗口仍可能有明显延迟。东方财富是辅助索引，不等于与巨潮完全独立的底层事实来源；不能用两处都出现来代替核对原始披露。

### 历史回放发现

从临时留存公告包按 ID 去重，取得 56,834 条记录。对上次复盘归类的 620 条定期报告/财务披露失效日志进行探索性匹配：

- 539 条可以通过所引公告 ID 对应到全文标题；
- 17 条的引用指向摘要或董事会决议，同公司同日存在匹配的全文，可通过关联文档发现；
- 63 条原引用 ID 不在保留的临时公告包内，不能验证；
- 1 条是兖矿能源境外核心子公司的半年业绩，不能冒充上市公司本体新定期报告，需另走重要财务事件审阅。

这里的规则根据样本调整过，且只回放旧系统已发现的正例，没有独立验证所有负例和源端漏报；这些数字不能写成准确率或未来召回承诺。它们说明文档身份大部分可机械识别，也暴露了必须处理的实际差异：公司全称前缀、“中期报告”别名、英文翻译版、更正版，以及同批摘要和其他文件的关联。

### 可靠实现需要的约束

1. **识别证券、报告期、文档角色和版本。** 全文、摘要、审计意见、募集资金报告、预约披露、业绩说明会分别处理。中英文版属于同一次披露的不同语言版本，不能默认再次触发。更正公告要关联被更正文件；纯排版更正不必直接重研，财务数字更正或无法确定内容的更正进入复核。
2. **保存已研究的财报身份。** 仅比较公告日期与 `information_cutoff` 不够：同一天先完成研究、后发布财报，或旧年度财报后来更正，都可能判断错误。现有状态只有报告截止时间和来源，没有统一的已吸收财报期间/文档版本字段。落地时宜在既有研究结果合同中增加最小文档身份信息，由研究完成时写入；这不是逐句证据账本，也不保存价格。
3. **用缺口核对发现漏抓。** 增量发现加定期按公司/报告期核对；未取到和确认未披露分开。延期、暂停上市资格变化及异常公司进入待核实，而不是直接判作数据源正常。全市场证券身份应从独立上市资料更新，不能把质量池成员当证券范围。
4. **失败可恢复。** 复用现有按自然日、公司分块的分页校验；抓取成功片段可留运行缓存，失败只补缺口。抓取不改研究状态，不因研究工作区忙碌而放弃发现。需要写研究层时仍由协调器串行执行、去重、校验。现有 `last_successful_at` 表示全部裁决成功，不能拿下载进度替代；若增加断点元数据，应改现有检查点合同，避免另造一套研究事实源。
5. **报告身份去重不能只依赖近期 10,000 个公告 ID。** 财报季大量普通公告会挤出较早 ID。近期 ID 适合增量窗口，已研究财报必须按报告期和版本识别。定期回看更早窗口及本期应披露清单，用来发现迟到或补录。
6. **检测与状态动作分开。** 对有效 covered 报告，确认存在未吸收的新正式财报后可机械触发更新；已有 stale/candidate 任务只补充新事实而不重复排队。ignore 不应每季度全量转 candidate。已有正式 ignore 报告的合法重启路径目前仍有缺口：初筛不能覆盖正式报告，update 只接受 covered/stale，需要在实现前明确并修复。

建议频率为程序每天检查一次，财报季按需要增加；周末也可低成本执行。每周补查近期窗口，报告季结束后做本期缺口核对。不承诺实时，也不把一次 API 返回成功当作从未漏报。

## 二、非财报：具体如何避免关键词漏掉重要事件

我收紧上次“程序先筛重大事项”的说法：如果它指关键词白名单决定哪些公告允许模型看，这个方案不够可靠。

历史贝达药业的原始标题是“关于合作伙伴 EyePoint 公布……首项试验数据的公告”，没有直接写“失败”；药明康德标题只是“关于出售部分股票资产的公告”，没有金额。相反，“重大合同”“取得批件”可能只是常规经营。还不能把“董事会决议”“进展公告”“关联交易”整个类别自动丢弃，因为关键事实可能只出现在正文。

### 建议的工作方式

机械部分只负责获取、去重、文档类型和同一事项合并。对正在维护的公司，每天将新非财报公告按公司聚合，附上已有核心逻辑、风险及待验证事项的短背景，做一次批量语义初筛。关键词和官方公告类别只帮助排序，不作为唯一放行条件。

标题明确无关且有证据的重复程序信息可以结束；标题含糊、涉及核心业务或无法确定影响时，继续取正文。尤其对于监管回复、董事会决议和事项进展，不能因为标题泛化就自动判断不重要。文本提取失败或只拿到首页也不能当作已审阅。

进入正文审阅的事项，必须回答：新增事实是什么；旧报告是否已经吸收；影响的是收入/成本、普通股现金、股本、治理还是核心风险；为什么足以或不足以越过原有假设边界。由同一审阅执行者形成结果，经现有协调器合法写入，不增加复核 Agent 或经理角色。

日常不因“公告发生了”就写 monitor；明确不相关且没有研究含义的公告只需完成处理。需要保存研究审阅凭据、确实确认或观察原报告的事件才写 update。任何估值、利润、回报模型或正式结论变化仍走完整报告，不能补丁更新。

### 范围如何选择

本次快照有 325 家 covered、455 家 stale；质量池有 171 家，两者不是同一个范围。质量池中还包含 28 家 stale、4 家 candidate 和 1 家 ignore。入池不能自动激活研究，离池也不能自动停止研究。

我的推荐是：全市场保留机械公告获取；日常语义审阅优先维护已有有效报告，stale 公司继续捕捉重大新事实供其已有更新研究使用。池外新公司的普通融资、扩产等事实，在低频商业质量筛选时独立读取，不再自动变成完整深研任务。质量池自身仍遵守隔离规则。

这个推荐会改变现行“全部 active（含 ignore）公告逐条裁决，并可创建候选”的运行职责，必须先修改相关流程约定，不能悄悄缩小范围。如果用户仍希望及时发现任意池外公司突变，就应保留全市场标题的批量语义审阅；相应模型成本会更高，不能同时保证全市场及时发现和几乎不调用模型。

公告审阅也不能完整覆盖铜价、运价、竞品或海外监管动态。需要这些信息时，应针对已有研究中的关键经营变量另行指定公开数据源；不能宣称这套公司公告管线已经覆盖。

### 效果预期及验收

预期能大幅减少反复读取全市场状态、全部正式报告以及无关全文的工作；仍需要模型判断语义，不能预先给出节省比例或漏报率。更省调用的周度批处理会把最坏发现延迟拉长至一周，应作为明确取舍。

先做历史回放，再做 2—4 周只读观察：

- 将已核实的重要案例、普通公告及模糊标题放入评估集；上次 15 条非财报失效记录可作回归素材，但其中边界有争议的事件不直接充当标准答案。
- 检查重要事件能否进入正文审阅、最终触发是否正确、正文读取数量和发现延迟。
- 随机抽查被排除项，尤其是通用标题，防止只看已命中案例自证有效。
- 特别检查“拟议/受理/备案/批准/定价/完成”阶段变化，防止把每次进展都误判为新的根本变化。

尚未运行语义模型对照实验。本次不能为上述方案宣称已测得的准确率。

## 三、价值质量池是否适合低频筛选

已阅读筛选规范、池范围声明，抽查不同类型判断卡，并检查相关代码与现有测试。结构设计合适：竞争优势、普通股现金、反证及分层理由明确；特殊行业不乱套统一现金公式；独立证券范围、复看范围和材料深度有所披露；成员不会自动变研究任务；价格和估值与商业质量分开。

这层适合回答“哪些公司值得长期研究”，不能覆盖全部事件驱动的首次研究机会，例如低质量公司的重组或资产重估。若用户的目标是长期商业质量，接受这项取舍是合理的。

### 当前成果的三个限制

1. **名单维护比全市场新发现更充分。** 证券范围 5,555 家，实际复看 174 家（原池 167 家加 7 家近邻）；34 家缺旧财务基线。规范和结果都已诚实说明没有全市场同等深度复核。下一次不能只复看 171 家，否则新公司发现会长期围绕原名单打转。
2. **部分判断卡是结论提要，证据强度还不够。** 例如招商银行的长期低成本负债、长江电力的六库协同有明确可检验的机制，但卡片没有写出支持核心资格的代表期间或关键兑现指标。可在现有四项文本中补 1—2 个有区分力的事实，并为 B 层明确什么证据能够解决未决问题；不需要新建庞大打分表或逐句证据库。没有这些材料，不应仅凭卡片有字段就认定商业判断已经完成。
3. **日期代表本次复看，不代表逐家读完最新材料。** 共 332 个来源入口，其中 186 个是东方财富正文分页入口；这不等于来源无效，但第一页不是全文。现有范围声明明确没有逐家重新完整核验最新财报，应继续保留这一区分。校验通过只证明结构和投影符合约定。

### 建议频率

| 时间 | 工作范围 |
|---|---|
| 年报集中披露结束后，通常 5 月 | 年度主复核：现有成员、各行业近邻、缺基线与新上市公司；更新全市场压缩事实，检查遗漏，按需要展开材料 |
| 半年报集中披露结束后，通常 9 月 | 补充复核：现金兑现、治理与资本投入变化、B 层未决问题；再做一次池外遗漏和误入检查 |
| 一季报、三季报之后 | 只针对出现关键反证或能解决未决问题的公司复看，不重排全市场质量名单 |
| 两轮之间的已知重大事实 | 可以提前复看相关判断卡；未设置常态语义监测的范围，接受延迟到下一轮发现 |

这与现有规范“年报后全池、每半年行业反向遗漏与误入检查”基本一致。低频是商业判断的频率，原始披露和上市身份可以更频繁机械更新。

首次补全尚未覆盖的范围与后续周期维护应区分。建议先补 34 家基线缺口，并按行业安排池外复看；未来每次记录本轮实际看了哪些新公司及排除理由，避免把证券清单总数当成商业复核完成数。质量层不维护第二套长期研究状态或任务队列。

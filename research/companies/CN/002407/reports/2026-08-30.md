# 1. 一句话结论

多氟多是具备氟化工一体化、六氟磷酸锂规模和若干电子化学品技术期权的周期成长制造商，2026年上半年量利修复真实，但二季度利润率显著回落、自由现金流仍为负，电池扩张又同步推高应收、存货和债务，因此公司值得持续维护，却不能把一季度高盈利或电子材料远景直接当作稳态价值。

# 2. 核心投资逻辑

1. 新能源材料是当前价值核心。公司拥有六氟磷酸锂6.5万吨年产能，并把氟资源、氢氟酸、氟化锂、六氟磷酸锂和电池串成一体化链条。2026年上半年新能源材料收入25.92亿元、同比增长71.25%，毛利率35.34%、提高15.81个百分点，贡献约9.16亿元毛利，是利润扭转的主要来源。
2. 拐点有经营质量，但季度持续性不足。上半年归母5.12亿元、扣非4.96亿元，非经常损益仅0.16亿元；然而累计减一季度后，二季度收入38.20亿元、归母1.36亿元、扣非1.16亿元，较一季度3.76亿元归母和3.80亿元扣非明显回落。综合毛利率也由一季度约27.61%降至二季度约16.47%。
3. 电池贡献规模，不等于贡献高质量现金。新能源电池上半年收入23.96亿元、同比增长118.81%，毛利率11.91%；20GWh产能建设和放量伴随应收、存货、在建工程、应付票据和长期借款上升，当前仍是重资产、低利润率业务。
4. 电子信息材料是值得跟踪的增长期权。上半年收入2.65亿元、同比增长37.30%，但只占总收入3.77%；4万吨半导体级氢氟酸、4000吨现有及5000吨在建高纯硅烷、硼同位素等产品只有在形成可复核收入、利润和资本回报后，才能显著改变公司估值。
5. 当前普通股价值由锂盐周期中枢、电池资本效率和债务约束共同决定，而不是由单一产品高点决定。

# 3. 商业模式与竞争优势

公司业务分为氟基新材料、电子信息材料、新能源材料和新能源电池。氟基新材料包括氟化铝、冰晶石、无水氟化氢及光伏级氢氟酸，客户主要位于电解铝、光伏和精细化工；新能源材料以六氟磷酸锂、双氟磺酰亚胺锂等电解质材料为主，客户为电解液和电池产业链；新能源电池覆盖大圆柱、方形和钠离子电池；电子信息材料服务半导体和显示客户。

真正可验证的优势首先是一体化与工程化能力。六氟磷酸锂的氟、锂原料和生产工艺可以内部协同，公司产销量位于行业第一梯队；电子级氢氟酸达到UPSSS/G5等级并进入国内外头部晶圆厂，说明纯化和客户认证能力并非概念。其次是规模和客户关系，在需求回升时能提高开工、摊薄成本并守住份额。

这些优势并不等于稳定定价权。六氟磷酸锂高度标准化且价格透明，行业扩产和客户议价会迅速传导到毛利；半年报明确称上半年市场价格整体呈回落态势。电池业务同样需要持续研发、设备投入、客户认证和营运资金，11.91%的毛利率尚不足以证明其回报高于资本成本。增长是否创造价值，应由分部利润、现金回款和ROIC验证，而不是由收入增速验证。

# 4. 行业与竞争格局

公司引用ICC鑫椤数据称，2026年上半年全球电解液产量148万吨、同比增长47.2%，中国占全球95%以上；六氟磷酸锂产量17.2万吨、同比增长43%，前五家份额69%。需求由新能源汽车和储能共同驱动，行业经历低端产能出清后向头部集中，但新增有效产能和技术迭代仍可重新造成供给压力。

六氟磷酸锂利润处于低谷修复后的波动阶段，而不是已证明的稳定高景气中枢。2025年公司新能源材料毛利率21.74%，2026年上半年升至35.34%；与此同时，公司披露期内价格整体回落，且二季度综合毛利率较一季度下降约11.1个百分点。同比改善与环比降温同时成立，不能把累计同比当成单季趋势。

新能源电池竞争更激烈，头部厂商在技术、客户、良率、供应链和资金成本上拥有规模优势。多氟多依靠材料协同、大圆柱和细分场景取得放量，但收入翻倍后毛利率仍仅11.91%，说明利润归属尚未稳定。电子材料的竞争壁垒更高、验证周期更长，半导体级氢氟酸已有客户基础，但硅烷和硼同位素仍需以实际商业规模确认。

# 5. 财务质量与股东现金收益

2023—2025年收入分别为119.92、82.49和94.34亿元，归母净利润分别为5.12、-3.08和2.13亿元，扣非分别为4.71、-4.04和0.99亿元。利润随锂盐周期大幅波动，过去三年不能支持稳定复利假设。2025年经营现金流1.99亿元、购建长期资产现金支出10.57亿元，简化自由现金流约-8.58亿元。

2026年上半年收入70.36亿元、同比增长62.55%；归母5.12亿元、同比增长897.19%；扣非4.96亿元、上年同期亏损0.05亿元。全公司毛利率21.57%，非经常损益仅0.16亿元，研发投入3.58亿元且研发费用3.53亿元，资本化比例很低，利润拐点不是依靠非经常项目或大量研发资本化形成。

累计拆分显示，一季度收入32.16亿元、归母3.76亿元、扣非3.80亿元、经营现金流-6.88亿元；二季度收入38.20亿元、归母1.36亿元、扣非1.16亿元、经营现金流10.24亿元。二季度收入环比增加，利润却大幅下降，综合毛利率由约27.61%降至约16.47%，表明一季度高毛利不能简单年化。二季度现金流改善主要来自营运资金和票据结算，不能单独证明稳定自由现金流。

上半年经营现金流3.36亿元、购建长期资产现金支出4.85亿元，简化自由现金流约-1.48亿元。现金流补充表显示，净利润5.74亿元和折旧摊销约6.24亿元被存货增加7.06亿元、经营性应收增加12.71亿元吞噬，经营性应付增加8.81亿元部分对冲。公司解释经营现金流增长还受银行承兑汇票到期解付影响；这说明利润向现金的转化仍依赖结算时点。

# 6. 管理层、治理与资本配置

李世江为控股股东和实际控制人，直接持股10.29%，一致行动人包括李凌云、李云峰、杨华春、程立静和焦作多氟多实业集团。控制权稳定，但实控人直接持股比例不高。李世江所持股份质押比例约6.54%；实业集团和李凌云所持股份质押比例分别较高，虽占公司总股本比例有限，仍需关注一致行动体系的融资与治理安排。

# 7. 市场争议与隐含预期

乐观观点是，储能和新能源汽车需求快速增长，六氟磷酸锂有效产能向头部集中，公司一体化成本、客户长单和规模使材料利润进入新中枢；电池收入翻倍后良率和成本继续改善；半导体级氢氟酸、硅烷和硼同位素提供第二增长曲线。谨慎观点是，锂盐价格和毛利率已经在季度内回落，电池业务低毛利且重资产，电子材料规模太小，利润与现金流最终仍被营运资本、资本开支和债务吸收。

2026年8月28日收盘价36.94元，对应外部普通股权益市值约427亿元，约为6月末归母净资产的4.9倍。若以9—11.5亿元正常化归母利润衡量，对应约37—47倍；市场若使用24—28倍成长制造估值，则隐含可持续普通股利润约15—18亿元，显著高于2025年2.13亿元利润，也高于2026年二季度利润简单年化约5.45亿元。

这一价格要求多项乐观条件同时成立：六氟磷酸锂利润中枢明显高于2025年且不再快速下滑，电池收入转为可持续利润和现金，电子材料形成规模，同时净债务不继续恶化。市场可能低估一体化龙头在行业出清后的份额与技术期权，也可能正确反映需求增长；但当前对利润持续性和资本效率已经留出很小的失误空间。报告时点价格只用于解释隐含预期，不构成任何交易或资本配置指令。

# 8. 事实口径、正常化经营、估值方法及核心合理价值区间

事实层：当前总股本11.90432569亿股，其中回购专户3443.9271万股不享有分红，当前持续持有人普通股口径为11.55993298亿股；未来回购股若用于激励，完全稀释口径回到总股本。6月末归母净资产86.82亿元、少数股东权益26.18亿元；按现金及现金等价物43.36亿元和计息借款、租赁负债约95.46亿元计算，调整后净债务约52.1亿元。

经营层：H1归母5.12亿元，但Q1、Q2分别约3.76和1.36亿元，不能简单翻倍。结合六氟磷酸锂同比修复、期内价格回落、2025年到2026年的销量扩张、电池低毛利、研发和财务费用、营运资本与资本开支需求，当前周期中枢正常化归母利润取9—11.5亿元，正常化EBITDA取22—26亿元。基准ROE约10%—13%，只有自由现金流转正并控制债务后才具备持续性。

方法一——正常化PE，为核心方法。9—11.5亿元正常化归母利润给予22—25倍，普通股权益价值约198—287.5亿元；除以当前享有经济权益的11.55993298亿股，对应约17.1—24.9元。倍数反映锂盐龙头、电子材料期权和需求成长，也因周期波动、低自由现金流与治理风险低于纯电子材料公司。

方法二——EV/EBITDA交叉。22—26亿元正常化EBITDA给予12—13.5倍，对应企业价值264—351亿元；扣除约52.1亿元调整后净债务和26.18亿元少数股东权益，普通股权益约185.7—272.7亿元，对应每股约16.1—23.6元。该方法与方法一中枢差异约6%，主要因为PE法包含未来利润成长，而EV法对当前债务和资本密集度惩罚更直接。

综合两种方法，核心合理价值区间：17—24 元。保守情景约11—15元，对应锂盐毛利回落、电池利润停滞、正常化归母仅6—8亿元；较乐观情景约25—32元，要求正常化归母达到12—15亿元、自由现金流连续转正且净债务下降。电子材料商业化和硼同位素只在形成可复核利润后进入核心价值，当前只列为条件性上行。

# 9. 基准持有人回报模型输入

本次形成`annual_common_equity_irr_v1`五年模型，但不在报告中计算随价格变化的回报率。未来五年每股普通现金分配依次为0.20、0.22、0.25、0.28、0.32元，合计1.27元，只计持续持有人实际收到的现金；公开市场回购、会计利润和留存现金均不视为已经收到的分配。

分配从2025年度已实施0.20元每股出发，假设普通股利润逐步提高、分配率约20%—30%，同时资本开支和债务约束使分红提高保持缓慢。当前回购专户股份不参与分红，但回购用途为激励或员工持股，故第五年按11.90432569亿股完全稀释口径，假设没有额外增发、可转债或期权稀释。

第五年末普通股每股终值为18—28元，独立基于第五年12—15亿元正常化归母利润、18—22倍整体PE和11.90432569亿股完全稀释股数，对应约18.1—27.7元后取整。终值倍数低于报告时点市场倍数，反映公司进入更成熟阶段以及周期、债务和资本效率约束；整体PE已经包含届时留存、净债务和资本开支结果，五年已分配的1.27元不重复计入终值。没有可靠必要性独立估计第三年终值，因此不提交year_3。

# 11. 核心风险与证伪条件

1. 锂盐周期风险。六氟磷酸锂价格、开工率和毛利率变化会迅速影响利润。若新能源材料毛利率连续回到20%以下且销量增长不能对冲，9—11.5亿元正常化利润假设需要下修。
2. 电池扩张风险。电池收入占上半年34.05%，毛利率只有11.91%。若应收、库存、质保、资本开支和担保持续增加，而分部利润和经营现金流不能同步改善，收入增长将造成永久资本损失。
3. 财务杠杆和现金转化风险。调整后净债务约52.1亿元，H1自由现金流仍为负。若未来四个季度自由现金流持续低于零且有息债务继续明显增长，扩张将依赖再融资并威胁普通股价值。
4. 应收与减值风险。应收账款半年近乎翻倍，H1信用与资产减值合计约1.15亿元。主要客户回款恶化、坏账计提不足或存货价格下跌会同时损害利润、现金和净资产。
5. 治理与关联交易风险。预计关联交易18.68亿元，关联采购和设备预付款规模较大。若关联设备长期未交付、价格不公允、关联应收逾期或出现非经营性资金占用，治理判断将被推翻。
6. 技术期权风险。电子材料收入占比仍小，客户验证时间长；若高纯硅烷和硼同位素投产后不能形成利润，市场给予的技术溢价将落空。

最重要证伪条件是：新能源材料毛利率连续跌破20%，同时电池业务不能产生正自由现金流、调整后净债务继续增长。三者并存将说明本轮增长仍是借债扩产叠加短期周期反弹，而不是普通股经济回报的结构性提升。

# 12. 最终判断

报告时点价格为36.94元/股（腾讯行情，2026年8月28日收盘），外部普通股权益市值约427亿元；核心合理价值区间为17—24元/股。已形成五年持有人回报模型：未来每股现金分配0.20、0.22、0.25、0.28、0.32元，第五年末终值18—28元，关键口径是回购股未来可能重新进入完全稀释股本、第五年正常化归母12—15亿元且整体估值回归18—22倍。

条件性上行来自六氟磷酸锂价格在合理利润区间稳定、电池自由现金流转正、电子材料形成规模利润。三个最重要正面变量是新能源材料高毛利与一体化份额、上半年扣非扭亏且非经常项很小、电池与电子材料收入放量。三个最重要负面变量是二季度利润率快速回落、应收存货和债务同步上升、关联交易与重资产扩产。最重要证伪条件是材料毛利、电池现金流和净债务同时恶化。

最终去向：covered。多氟多值得持续维护，因为六氟磷酸锂周期、电子材料商业化和电池资本效率都可能显著改变普通股价值；但截至本报告时点，市场已经隐含远高于已验证利润的经营结果。

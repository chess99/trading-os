# 全 A 股价值优先重建计划（首个可执行波次）

**目标：** 不按旧行业、自选列表或市值顺序机械重做 5,516 家历史研究，而是先建立可复算的全市场重排机制，再从全部 `requires_rebaseline` 公司中冻结最值得投入研究资源的 12 家，逐家公司完成 v2 初研、半盲承保、必要的 challenger、组合综合和公司状态同步。

**本轮终点：** 一个新的全市场价值重建批次达到 `completed`，恰好覆盖 12 家冻结候选；12 家全部有独立初研和独立承保终态；组合报告使用不超过 3 个交易日的行情；公司状态、coverage、index、schedule、alerts 无漂移；向用户给出当前价、合理价值、买入区、评级、能否买及核心理由。

**非目标：** 本轮不承诺重建全部 5,516 家；不因完成数量降低证据标准；不把初筛分数当作买入评级；不把用户持仓、自选、成本或截图写入仓库。

## 一、不可变执行原则

1. 旧研究只用于发现待核验线索，不继承旧评级、旧合理价或旧操作。
2. 排名只决定研究顺序。只有组合层可以给 `buy_now`、仓位或处置动作。
3. 一家公司一个初研 agent；一家公司一个不同的半盲承保 agent。初研 agent 不能承保自己的公司。
4. 盲审只读取封存主张包和允许来源，不读取旧结论、合理价、买入区或仓位。
5. 重大分歧、会计质量疑点、治理风险、周期位置不明、估值方法相差超过 40%、新旧价值中枢相差超过 30%，或潜在前五大仓位，必须启动独立 challenger 和仲裁。
6. 无可靠共识时结论只能是 `failed`、`insufficient_evidence` 或 `stale`，不能为了凑满组合而通过。
7. 用户私有持仓只能在运行时作为“优先复核/集中风险提醒”的内存覆盖项；候选文件、prompt、报告、日志、meta、批次和提交中均不得出现持仓、成本或截图内容。
8. 所有网络数据记录真实来源、抓取时间和信息截止日；行情超过 3 个交易日不得综合。
9. 每个完整阶段单独提交，只暂存本阶段文件；提交前检查 `git diff --staged`。

## 二、任务 1：建立价值优先的重排资产和命令

### 目的

替换当前主要依据市值、成交额生成的旧优先级。新分数仍然只是资源调度分，不是公司质量或投资评级。

### 建议资产

- `src/trading_os/research_assets/rebaseline_ranking.py`
- `tests/test_rebaseline_ranking.py`
- `templates/rebaseline-ranking.schema.json`
- `automation/rebaseline_ranking.json`
- CLI：`python -m trading_os coverage rank-rebaseline`

### 输入

- `coverage/cn-a/companies.jsonl` 的最新全市场快照；
- `coverage/cn-a/research_queue.jsonl`；
- 公司 `meta.json` 中的信息截止日、报告时间线、承保状态和触发器；
- 可公开提交的最新财务摘要、分红、资本结构、行业和重大事项字段；
- 不读取或持久化私有持仓。

### 排名维度（总分 100）

| 维度 | 分值 | 解释 |
|---|---:|---|
| 价值错配信号 | 0–25 | 使用行业适配后的估值、自由现金流或资产价值信号，不用全市场统一 PE 阈值 |
| 经营与资本回报质量 | 0–20 | ROIC/ROE 的持续性、现金转换、竞争位置和资本配置 |
| 永久损失防护 | 0–20 | 净负债、偿债、稀释、治理、会计和尾部损失风险 |
| 信息更新紧迫度 | 0–15 | 新财报、业绩预告、并购重组、监管或价格变化是否已使旧结论失效 |
| 可验证催化与赔率 | 0–10 | 未来 6–18 个月有可验证催化，且悲观情景可界定 |
| 证据可得性 | 0–10 | 一手披露和行业数据能否支撑可复算研究 |

必须另列而非隐藏在总分中的扣分项：周期高位、治理疑点、关联交易、现金流长期背离、重大稀释、审计非标、退市风险和证券状态异常。

### 硬规则

- 只对普通 A 股和明确可研究证券排名；退市整理等硬排除继续保留结构化理由。
- 亏损、低流动性或小市值只能降低证据可得性或资源优先级，不能静默删除。
- 缺失数据不得按零分伪装成坏公司，必须记录 `missing_fields` 和置信度。
- 相同输入必须产生稳定顺序；平分时按信息更新紧迫度、永久损失防护、symbol 排序。
- 生成件保存输入快照哈希、算法版本、生成时间、每项分项分数和理由代码。
- 排名器不得输出 `buy_now`、合理价值、买入区或仓位。

### 测试

至少覆盖：稳定排序、缺失数据、行业适配、负 PE、金融企业不用工业 FCF、周期高位扣分、退市硬排除、私有字段拒绝写入、旧快照过期、同分排序和非法数值。

## 三、任务 2：刷新全市场公开快照并生成候选池

1. 刷新全部普通 A 股价格、市值、PE/PB、行业和成交数据；记录交易日和来源。
2. 对高排名候选补充最近一期年报/季报日期、业绩预告、分红、净负债或金融行业资本指标。
3. 验证快照覆盖率、重复 symbol、证券状态、时间戳和异常值。
4. 运行 `coverage rank-rebaseline`，得到全市场公开排名。
5. 从排名前 80 家形成候选池；逐项保留入池理由和关键缺失字段，不进行深度研究。

若无法获得可靠全市场新快照，本轮应停止在 `blocked_missing_evidence`，不得用 2026-07-06 旧快照假装最新排名。

## 四、任务 3：冻结首批 12 家

从前 80 家中按以下约束冻结 12 家：

- 排名优先，同时保证至少覆盖 5 个经济风险簇；
- 同一一级行业最多 3 家，同一经济风险簇最多 4 家；
- 至少 4 家具备可检验的现金流或资产价值折价；
- 至少 3 家因新财报、重大事项或价格变化需要紧急复核；
- 最多 3 家属于强周期或主要依赖商品价格判断；
- 不因用户持有而自动入选，只能在公开排名接近时提高研究先后顺序；该覆盖不落盘。

冻结前输出一份简短选择审计：入选 12 家、候补 12 家、每家公开理由、行业和风险簇。主 agent 检查不存在私有持仓信息后，创建新的 `value-rebaseline` run 并冻结候选。候选冻结后不得换股；失败公司保留在批次中并记录终态。

预期种子池可以包括中国移动、中国海油、中国平安、海康威视、恒瑞医药、宁德时代等，但它们没有保送资格；刷新后的公开排名和约束才是最终依据。

## 五、任务 4：12 家逐公司重建初研

每家公司由独立 agent 按 `playbooks/company-research.md` 完成：

1. 从一手披露重建业务、行业、竞争位置和资本配置理解。
2. 核验至少五年和最新报告期的利润、现金流、资产负债及稀释口径。
3. 区分报告利润、正常化利润和股东可获得现金流。
4. 至少使用两种适合行业的估值方法，给出 bear/base/bull、合理价值和由要求回报反推的买入区。
5. 明确市场当前隐含了什么增长、利润率、资本回报或周期假设。
6. 至少列出三项反方证据、失效条件、未来 6–18 个月催化和跟踪触发器。
7. 生成中文 v2 报告、结构化主张、来源清单和 seal；验证通过后才能准备盲包。

初研只能决定 `enter_underwriting`、`insufficient_evidence` 或结构化跳过理由，不能形成组合买入和仓位。

## 六、任务 5：半盲承保、挑战和仲裁

1. 为 12 家生成并扫描 claim packet；发现估值、评级、目标价或仓位泄漏立即阻断。
2. 每家公司派给不同于初研的独立承保 agent，重建盈利质量桥、现金流桥、正常化盈利和估值敏感性。
3. 封存盲评后揭示初研，只做差异审计，不允许事后迁就初研结论。
4. 根据政策自动决定是否 challenger；触发后使用第三个独立 agent，仲裁前不得共享双方身份偏好。
5. 每家公司形成 `passed`、`failed`、`insufficient_evidence` 或 `stale` 终态以及结构化 reason codes。
6. 任何 agent 失败只重试该公司当前阶段；已封存阶段不得重复生成或覆盖。

## 七、任务 6：组合综合和发布

1. 所有公司终态后抓取最新行情；行情必须覆盖 12 家且不超过 3 个交易日。
2. 严格验证批次后运行组合综合。
3. 五个条件全部满足才允许 `buy_now`：承保通过、证据未过期、价格进入买入区、横向排名入选、风险预算允许。
4. 候选不足时保持现金，不降低安全边际。
5. 报告完整列出 12 家的现价和时间、悲观价值、合理价值、买入区、承保状态、操作、目标仓位、核心理由和失效条件。
6. 运行 `review report`/`review finalize`，将最终承保状态同步回公司 meta，并封存 finalization receipt。
7. 重建 coverage、index、schedule 和 alerts；未承保通过的公司不得生成买入区提醒。

## 九、完成标准与停止条件

只有以下条件全部满足，Goal 才能标记完成：

- 新排名器、Schema、CLI 和测试已落地；
- 使用新鲜公开快照从全部 `requires_rebaseline` 公司重排，而非手工指定结果；
- 12 家候选已冻结且全部到达独立承保终态；
- 该批次状态为 `completed`，严格验证通过；
- 公司 meta 和四类生成件已同步且无漂移；
- 私有持仓信息没有进入 Git；
- 最终给出可执行的“现在买 / 等待什么价格 / 不买”结论；
- 本轮修改已经按边界提交，工作区没有夹带其他改动。

若某个外部数据源失败，应先尝试其他一手或权威来源；同一阻塞连续出现三轮且无法安全推进时，才按 Goal 规则标记 blocked，并明确缺什么、哪些公司受影响、恢复后从哪个封存阶段继续。

## 十、后续滚动机制（不属于首个 Goal 的完成条件）

首轮完成后按同一排名快照依次启动后续 12 家波次，但每逢以下任一情况先重排：

- 新季报或半年报集中披露；
- 候选价格相对研究价变动达到 10%；
- 重大并购、配股、监管、审计或治理事件；
- 上次全市场快照超过 30 个自然日。

已经完成 v2 承保的公司进入触发器维护，不因“还有旧公司未重建”而机械重复研究。剩余 `requires_rebaseline` 公司继续表示不可作为当前投资依据，而不是必须立刻按 symbol 顺序清零的技术债。

# 美股精选价值质量池

筛选复核日期：2026-10-23。方法：prompts/screening/international-value-quality.md。

以五至十年普通股所有者视角检验竞争优势、必要投入、现金归属与资本纪律；事实来自已读披露，长期判断为分析推断。

当前 **3 家**：核心 **2 家**，验证层 **1 家**。

本池只表达商业质量与持续研究价值，不表达买入、仓位、当前估值或单公司研究状态。

证券清单：2026-10-23，3 家。本轮重点复核 3 家；缺少旧财务基线 0 家。

美股主动收窄至企业软件、支付网络和会员零售，仅复核这3家，不代表美股全市场。微软读取FY2026年报业务、现金流及相关说明；Visa和Costco读取FY2025年报业务、现金、风险及三年比较。Costco补读FY2026快报；Visa未逐项重核FY2026季报。资料期间见来源标题，复核日不等于全部资料更新至当天。 基线日期表示本次整理日，各公司期间不同；基线只指已读关键材料，不表示完整多年财务数据库。 Costco另读FY2020会员与竞争章节，注意当年会员统计方法调整，未据会员绝对数直接计算跨期增长。 Visa另核FY2020现金流中的2018—2020比较，分配中存在债务融资，不将全额回购当作经营现金兑现。

遗漏检查：覆盖软件、支付和会员零售；医疗、工业、铁路、能源尚未覆盖。Alphabet、Mastercard、Walmart等近邻未逐家复核，尚未完成同业优劣排序。

误入检查：重点检验高增长伴随资本投入、客户激励和监管资本消耗；区分合并现金、母公司可用资金和实际分配。A层仍保留反证，B层必须写清升级条件；未据证券行情或单年利润增速选取。

## A：核心护城河池（2 家）

### 消费、品牌与网络（1 家）

#### COST 开市客 Costco · 会员仓储零售

- 竞争优势：长期判断：精选SKU、采购规模和低加价转化为会员节省，再由复购支持效率。FY2023—2025付费会员7,100万增至8,100万，2025美加续费率92.3%；续费指标有滞后且排除部分会员，不能等同全体即时留存。会员费也不是无成本利润。
- 普通股现金：FY2023—2025经营现金110.68、113.39、133.35亿美元；2025购建54.98亿，扣后78.37亿只是代理。需要维护门店、履行租赁、会员奖励与供应商付款，负营运资金在增速下降时可能反转。特别分配不可机械外推。
- 主要反证：最强反证是线下节省被其他渠道复制，而工资、配送和开店成本提高。提会费可能暂时掩盖会员质量变弱；新店销售增长不能自动证明单位资本回报。FY2026业绩含关税退款一次性利好，不能当持续经营改善。
- 分层理由：A：会员复购与采购效率形成自我强化，2020年美加续费91%、全球88%，与2025对照支持长期留存；疫情也带来居家消费顺风，不能视为全情景压力测试。未来5—10年仍须检验客流、续费、老店效率和新店回收。若续费持续恶化且依赖提费补偿，应降级。现金基线截至FY2025；已读FY2026业绩快报，未以快报替代2026完整现金与租赁复核。
- 来源：[FY2025年报：会员、经营讨论及现金投入，含2023—2025比较](<https://s201.q4cdn.com/287523651/files/doc_financials/2025/ar/COST-Annual-Report-2025.pdf>)；[FY2026业绩快报，2026-09-24；非完整年报复核](<https://www.sec.gov/Archives/edgar/data/909832/000090983226000084/costex9918-k92426.htm>)；[FY2020 10-K：业务、会员与口径变动，第3—5页](<https://www.sec.gov/Archives/edgar/data/909832/000090983220000017/cost-20200830.htm>)

### 基础设施、金融与资源（1 家）

#### V Visa · 支付网络

- 竞争优势：长期判断：发卡行、收单行和商户共同构成受理网络，反欺诈与争议处理提高跨境使用可靠性。FY2023—2025净收入连续增长提供商业化支持；电子支付行业增长之外，还须看每笔业务扣除客户激励后的经济利益。
- 普通股现金：FY2023—2025经营现金为207.55、199.50、230.59亿美元。客户激励是取得业务的真实成本，2025增长快于净收入；不能加回后声称现金改善。现金还要覆盖系统、诉讼、税款、收购和股权激励稀释；金融证券到期流入不算经营创造。
- 主要反证：最强反证是账户直连、即时支付或稳定币绕过网络，银行与大型商户借替代渠道要求更多让利；反垄断和费率监管可能改变收益分配。跨境旅游恢复也不能等同永久增长。
- 分层理由：A：跨国受理与风险服务难同时复制，2020年疫情冲击下经营现金104.40亿美元，低于2019的127.84亿，扣设备技术投入仍为正；这支持网络韧性，也证明跨境冲击会损害现金。替代支付威胁尚不足以证明跨境信任服务失效；若激励长期快于收入且净费率下滑、流量持续绕网，应降级。未来5—10年看净经济利益与现金，不以交易笔数单独判断。本轮财务基线至FY2025。
- 来源：[FY2025 10-K：业务、FY2023—2025收入与现金、客户激励、法律事项](<https://www.sec.gov/Archives/edgar/data/1403161/000140316125000089/v-20250930.htm>)；[FY2020年报：FY2018—2020现金流及疫情冲击，现金表第69页](<https://s1.q4cdn.com/050606653/files/doc_financials/annual/2020/Visa-Inc.-Fiscal-2020-Annual-Report.pdf>)

## B：质量研究池（1 家）

### 科技与工业制造（1 家）

#### MSFT 微软 Microsoft · 企业软件与云

- 竞争优势：长期判断：办公流程、身份权限、开发工具和企业系统形成联合切换成本；客户需要兼容、安全与持续运维。既有软件分销能帮助新产品触达客户，但不能证明AI算力必有高资本回报。应区分成熟订阅业务与新基础设施。
- 普通股现金：FY2024—2026经营现金分别为1,185.48、1,361.62、1,829.35亿美元，同期购建设备444.77、645.51、1,159.48亿。现金减购建代理从740.71亿降至669.87亿；尚未扣融资租赁本金及其他必要投入。股票薪酬加回与回购抵消稀释需一并看。
- 主要反证：最强反证是软件仍有需求但竞争迫使持续承担庞大算力支出，新增现金回报下滑。客户集中、AI供应链与合作安排、信息安全及产品捆绑监管都可能损害议价能力；延长折旧年限不会增加现金。
- 分层理由：B：成熟业务优势清晰，但资本强度改变了整家公司现金质量。未来5—10年关注单位算力收入、设施利用率、客户续费及投入后每股现金；新增资本回报和融资租赁全口径长期兑现后才考虑A。不能仅以云收入增长升级。
- 来源：[FY2026年报：业务、财务回顾、FY2024—2026现金流及租赁说明](<https://www.microsoft.com/investor/reports/ar26/>)
